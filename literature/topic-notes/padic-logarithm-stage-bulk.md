# `2`-adic logarithms as a bulk-generation target

## Exact identification

PR #3's stage sequence

```text
u_m=(3^(-7*2^m)-1)/2^(m+2)
```

is the divided-exponential approximation to

```text
u_infinity=-(7/4)log_2(3).
```

See `LIT-KTHM-0030` for the exact formula and valuation.

## Why this matters

The branch previously treated

```text
u_(m+1)=u_m+2^(m+1)u_m^2
```

as a nonlinear Hensel mechanism whose newly exposed bit had to be generated. The logarithm formula gives additional structure:

- one fixed target constant;
- exact one-bit-per-level convergence;
- a standard convergent series;
- fast arithmetic algorithms;
- transcendence/nonperiodicity of the completed target;
- access to `p`-adic logarithmic-form estimates.

## Forward-generation versus preloading

There are two very different uses of the formula.

### Invalid shortcut

Store enough digits of `u_infinity` in the initial `2`-adic quotient and reveal them later. This proves only finite compatibility and converges to a nonordinary ghost.

### Valid target

Construct a forward macro that transforms a finite state carrying the first `m` digits into one carrying the first `m+1` digits, while transporting the same ordinary marked integer and obtaining the new digit from the live Collatz state.

The proof obligation should explicitly state where the new digit comes from.

## Candidate algorithms

### Log series

Since `9=1+8`,

```text
log_2(9)=sum_(n>=1) (-1)^(n+1) 8^n/n.
```

To obtain `B` binary digits, only finitely many terms contribute. This gives a simple exact reference implementation.

### Newton/exponential inversion

Solve

```text
exp_2(lambda)=3^(-14)
```

by Newton iteration, doubling precision. This is better for large exact experiments.

### Binary splitting

Evaluate the logarithm series by product trees to reduce intermediate multiplication cost.

## Arithmetic theorem targets

1. Express the stage connector digit as an explicit trace or residue of `log_2(9)`.
2. Determine whether the connector recurrence itself is a transducer for logarithm digits.
3. Use `p`-adic linear forms to bound accidental coincidences between log prefixes and finite affine libraries.
4. Prove that every finite-state generator of these digits has unbounded state complexity, or exhibit a counter-stack generator.
5. Compare the digit complexity with PR #20's repetition lower bounds.

## Literature boundary

Mahler's theorem proves transcendence of the completed logarithm; it does not prove computational or automata complexity of its binary digits. A transcendental `2`-adic can still be generated by a simple recurrence.
