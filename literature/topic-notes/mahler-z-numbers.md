# Mahler Z-numbers and the repository's 2-adic analogue

## Classical real problem

Mahler asks whether a positive real `xi` can keep every fractional part `{xi(3/2)^n}` in `[0,1/2)`. FLP generalize the interval and rational ratio, build a symbolic decoupling between integer and fractional parts, and prove a universal real range-width lower bound `1/p` for ratio `p/q`.

## Recent located work

Strauch (2022) proves a conditional asymptotic-distribution statement for the fractional-part sequence of any hypothetical classical Z-number. It does not settle existence and does not change the real/2-adic scope boundary, but it is a useful post-FLP reference showing that the classical problem remains active.

## Repository problem

The survivor set `V∞` is an attractor in `Z_2` for affine contractions associated with the partial `64→81` map. The question is whether that 2-adic set contains a positive ordinary integer in a lifting class.

## Exact relationship

The relationship is structural analogy:

- rational expansion ratio;
- an all-time digit/window constraint;
- symbolic coding of integer/carry data;
- tension between a completion and ordinary real/integer size.

It is not an equivalence to Mahler's classical Z-number problem.

## FLP non-transfer

FLP's `1/p` is a lower bound on Euclidean interval width of real fractional parts. A Haar-measure comparison in `Z_2` uses a different topology and different invariant notion. No theorem transfers the bound by replacing “interval length” with “2-adic measure.”

## Promising connection

FLP's decoupling method is more relevant than its numerical threshold. A productive comparison would identify:

- the repository's integer carry map;
- a companion compact-state map;
- a common symbolic itinerary;
- conditions under which that itinerary uniquely determines both components.

That could yield countability or sparsity statements adapted to the 2-adic setting.
