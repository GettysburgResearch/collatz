# Integer-first counterexample architecture

## Objective

A positive construction must begin with one ordinary finite integer or produce one through a finite certificate. It may not end at a compatible inverse-limit point and defer ordinary realization indefinitely.

## Three valid output forms

```text
A. positive nontrivial cycle:
   finite valuation word + divisibility + exact replay;

B. ordinary divergent invariant:
   one explicit positive initial state + finite rule + all-time closure
   + positivity + unboundedness/nonattainment of 1;

C. rigorously equivalent global witness:
   a theorem whose failure forces a nontrivial component, cycle, or
   nonterminating ordinary orbit, with every equivalence proved.
```

## Current closed architecture boundary

The proposed PR #33 / PR #34 Evertse boundary eliminates an architecture when it has:

```text
finite type catalogue;
bounded essential nondegenerate width;
finite internal prime alphabet;
subunit primitive endpoint product;
infinitely many distinct primitive stage points.
```

A new positive design should name its escape before implementation:

```text
UNBOUNDED ESSENTIAL WIDTH:
CRITICAL ENDPOINT PRODUCT:
CHANGING PRIME ALPHABET:
PERSISTENT DEGENERACY:
QUOTIENT REFUND:
CROSS-ARCHITECTURE HANDOFF:
```
