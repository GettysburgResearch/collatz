# LIT-KTHM-0027 — Graph-directed contractions produce a compact completion object

**Verdict:** `KNOWN — COROLLARY`; proof supplied.  
**Maps to:** PR #3's graph-directed return language and issue #4's IFS analogies.  
**Sources:** Hutchinson's contraction framework and Mauldin–Williams graph-directed constructions.

Let \(G=(V,E)\) be a finite directed graph in which each vertex has an outgoing edge. Let \(X\) be a complete metric space, and associate to each edge \(e:i\to j\) a contraction \(f_e:X\to X\) with Lipschitz constant at most \(r<1\). Assume all images lie in one common compact trapping set.

## Theorem

There is a unique family of nonempty compact sets \((K_i)_{i\in V}\) satisfying

\[
\boxed{K_i=\bigcup_{e:i\to j}f_e(K_j).}
\]

Finite compatible address prefixes converge to points in these sets.

## Proof

Let \(\mathcal K\) be the space of nonempty compact subsets of the trapping set with Hausdorff metric; it is complete. On the finite product \(\mathcal K^V\), define

\[
\Phi((A_j))_i=\bigcup_{e:i\to j}f_e(A_j).
\]

The Hausdorff distance between corresponding unions is at most \(r\) times the maximum coordinate distance, so \(\Phi\) is a contraction. Banach's fixed-point theorem gives a unique fixed family. Iterating from any compact family shows convergence of finite address constructions. ∎

## Critical non-application

The theorem constructs a compact object in the completion. It does **not** prove that the attractor contains an ordinary positive integer, that an address is generated by a deterministic Collatz selector, or that a `2`-adic limit has a finite archimedean boundary. This is precisely the finite-versus-adic gap the repository must continue to audit.
