# LIT-KTHM-0012 — Tao's logarithmic-density almost-boundedness theorem

**Source:** [@Tao2022], Theorem 1.3
**Inspection:** official full HTML
**Proof status:** BLACK BOX

## Statement

Let `Col_min(N)` denote the minimum value attained by the Collatz orbit of `N` in Tao's normalization. For every function `f(N)` tending to infinity,

```text
Col_min(N) < f(N)
```

for almost all positive integers `N` in logarithmic density.

## Mechanism summary

The proof combines first-passage reductions, approximate independence/mixing in a 3-adic model, and Fourier decay for a skew random walk. It is a major strengthening of classical almost-all stopping-time results.

## Native relevance

The theorem is the correct modern almost-all context for any claim about how exceptional an explicit counterexample mechanism would need to be.

## Non-applications

It does not prove the Collatz conjecture, construct a divergent orbit, give a natural-density-one statement in every normalization without translation, or settle whether a particular 2-adic coded survivor is an ordinary integer.
