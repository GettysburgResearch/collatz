# Candidate counterexamples

Last updated: 2026-07-21

There is currently **no candidate positive integer** and no finite symbolic construction that has been shown to define an infinite positive-integer Collatz trajectory.

## Candidate-adjacent mechanisms

The induced maps in `O-0001`, `O-0002`, and `O-0003` are counterexample mechanisms only in the following conditional sense:

> An infinite admissible orbit beginning from one finite integer in the specified lifting congruence class would lift to a positive Collatz counterexample by `T-0001`.

No such infinite orbit has been proved.

The stack family in `L-0002` produces arbitrarily long finite admissible trajectories. It is not assigned a `K-####` identifier because no single member is claimed to be a counterexample.

A future candidate file must satisfy every requirement in the project README, especially existence, integrality, positivity, infinite consistency, and exact translation to deterministic Collatz dynamics.
