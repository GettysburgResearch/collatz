## What counts as genuine progress

### Genuine exhaustive progress

The following theorem shapes materially reduce the project:

- a universal exclusion over every word/path in a specified infinite class;
- an exact least-root asymptotic;
- a full-denominator equality or contradiction;
- a finite enumeration after a proved global bound;
- a concrete counterexample to a submitted claim, followed by downstream repair.

### Genuine structural progress, but not existence progress

These are legitimate and reusable, but do not imply a counterexample:

- exact physical conjugacy;
- deterministic intrinsic state recovery;
- one-counter or mixed-radix normal forms;
- conditional growth, refund, prime turnover, and complexity;
- exact finite-prefix cylinders;
- proof-producing compilers.

### Treading-water indicators

A new result is unlikely to advance the full objective when it only changes one of the following while leaving the same least-root or full-denominator statement untouched:

```text
another coordinate for the inverse-limit point;
another finite prefix record;
another branch count or SCC;
another conditional drift bound;
another proper factor of D;
another near-integer without height closure;
another structured schedule excluded without an exhaustiveness theorem.
```

## Exact repeated missing inference

Across the ordinary architectures, the recurring invalid step is:

```text
for every N there exists x_N surviving N blocks
therefore there exists one x surviving every block.
```

This is false because the witnesses `x_N` may escape to infinity. The correct inference is:

```text
for every N there exists x_N <= B surviving N blocks
therefore one x <= B survives every block.
```

The uniform bound `B` is precisely the missing ordinary-extraction theorem.

Across the cycle architectures, the recurring invalid step is:

```text
C is divisible by many factors of D
and C/D is close to an integer
therefore D divides C.
```

The correct inference requires an exact remainder-height contradiction:

```text
a nonzero R=C-ND is divisible by more than its archimedean height permits.
```
