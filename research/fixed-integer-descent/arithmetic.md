# Binary run cores from signed carry cuts

**Status: PROPOSED, with elementary proofs and complete bounded replay.**
The unrestricted Collatz conjecture remains open. The main result is an
effective finite core for an ordinary orbit with a prescribed bound on
the number of binary one-runs. Long runs of ones are allowed in the
input. No ordinary integer is extracted from a compatible sequence of
changing finite witnesses.

## 1. Relation to the existing work

This extends the positive-shadow finite Hamming-core mechanism in
PR #141, frozen at
`5025ef464d4b6d4f4a412a3e33c3477de68dfa8b`,
[`research/ay-persistent-20261031/PROOF.md`, HC-1--HC-3](https://github.com/GettysburgResearch/collatz/blob/5025ef464d4b6d4f4a412a3e33c3477de68dfa8b/research/ay-persistent-20261031/PROOF.md).
That work bounds binary popcount along an entire orbit. Here a signed
lower shadow treats a long one-run as well as a long zero-run. The
homogeneous comparisons are consequently both `3^j u` and `3^j u-1`.
For example, `2^a-1` has one binary one-run and arbitrarily large
popcount. Thus bounded run count is a strictly broader representational
hypothesis than bounded popcount.

No external number-theoretic theorem is used. A targeted search for
bounded binary block-count Collatz results was not an exhaustive
priority audit. The power-of-three modular orbit, finite parity
identities, and the underlying Collatz encoding are not claimed as
new discoveries. This packet does not change the status of its source
PR or of the repository's general cycle-exclusion program.

## 2. Definitions and uniform homogeneous escape

Use the odd map

\[
U(n)=\frac{3n+1}{2^{v_2(3n+1)}}\qquad(n>0\text{ odd}).
\]

Physical trajectories stop at 1. In algebraic shadow calculations only,
use the same formula on every nonzero signed odd integer; the numerator
never vanishes. Let `r(n)` be the number of maximal one-runs in the
ordinary binary representation of `n>=0`, with `r(0)=0`. Equivalently,

\[
r(n)=\tfrac12\operatorname{popcount}(n\mathbin{\mathrm{xor}}2n).
\]

For an odd positive upper prefix `u`, `delta` in `{0,1}`, and `R>=1`, put

\[
h_R(u,\delta)=\min\{j\ge0:r(3^j u-\delta)>R\},\qquad
J_R=2^{2R+1}-1.
\]

**RC-1.** This minimum exists and is at most `J_R`, uniformly in `u`
and `delta`.

**Proof.** Set `m=2R+3`. The subgroup generated by 3 modulo `2^m`
consists exactly of the odd residues congruent to 1 or 3 modulo 8.
Its order is `2^(m-2)`: the valuation identity
`v2(3^(2^k)-1)=k+2` for `k>=1` proves the order, and the low-three-bit
restriction proves equality with the indicated subgroup. Hence the
orbit of any odd residue is one of its two cosets.

The first coset contains

\[
a=3+\sum_{i=2}^{R+1}4^i\equiv3\pmod8;
\]

the other contains

\[
b=1+\sum_{i=1}^{R+1}4^i\equiv5\pmod8.
\]

Both lie below `2^m`. Each of `a,a-1,b,b-1` has more than `R`
one-runs. Some `0<=j<=2^(m-2)-1` reaches the required residue.
Truncating to the low `m` bits cannot increase the number of one-runs.
Moreover, for an odd residue `z>=1`, subtracting 1 gives the low bits
of the full integer minus 1 without borrowing across the modulus.
Thus the same `j` proves the desired statement for the full ordinary
integer. QED.

The proof gives a finite worst-case bound, not a bound on the first
descent of the actual Collatz source. Complete modular orbits at a
higher precision can certify smaller constants; the core below uses
the exact `h_R` for each actual upper prefix.

## 3. Signed separated-cut identity

**RC-2.** Write one fixed positive odd integer as

\[
n=2^D u+v,\qquad u>0\text{ odd},\quad v\ne0\text{ odd},\quad
0<|v|<2^D.
\]

Let the signed shadow be `v_j=U^j(v)`, with odd valuations `a_j`,
`A_j=a_1+...+a_j`, and `P_j=2^A_j v_j`. If

\[
|P_h|<2^D,
\]

then, for every `0<=j<=h`,

\[
A_j<D,\qquad U^j(n)=2^{D-A_j}3^j u+v_j,
\]

and

\[
r(U^j(n))\ge
\begin{cases}
r(3^j u),&v>0,\\
r(3^j u-1),&v<0.
\end{cases}
\]

Sufficient bounds for the strict cut are

\[
4^h v<2^D\quad(v>0),\qquad
3^h|v|<2^D\quad(v<0).
\]

**Proof.** Exact affine composition gives

\[
P_{j+1}=3P_j+2^{A_j}.
\]

The shadow preserves its sign. Since `|v_j|>=1`, we have
`2^A_j<=|P_j|`. For a positive shadow, `P_j` increases and
`P_j<=4^j v`. For a negative shadow, its magnitude increases and

\[
2|P_j|\le |P_{j+1}|<3|P_j|,
\]

so `|P_j|<=3^j|v|`. Thus the terminal strict cut implies every earlier
one and `A_j<D`.

Induct on `j`. The upper term in `3U^j(n)+1` is divisible by
`2^(D-A_j)`. The shadow term has valuation `a_(j+1)<D-A_j`, because
`A_(j+1)<D`. Its valuation is therefore the actual valuation, yielding
the stated identity. The actual source remains positive; the signed
shadow is only an algebraic lower block, not a negative replacement
for the physical orbit.

For `L=D-A_j`, a positive shadow gives the binary concatenation
`2^L z+v_j`, `z=3^j u`, so the upper block's one-runs survive.
A negative shadow gives instead

\[
2^L(z-1)+(2^L+v_j),\qquad 0<2^L+v_j<2^L.
\]

Its upper block is `z-1`, proving the other run inequality. QED.

The strict cut is essential. For `D=2,u=v=1,h=1`, the relaxed
credit equality `4v=2^D` holds, but `n=5` maps to 1 and the claimed
separated valuation does not hold. The replay retains this control.

## 4. A finite core for every run cap

Parse an odd positive integer from its most significant bit into
alternating maximal one-runs and zero-runs. It starts and ends with a
one-run. A prefix just before a one-run is either zero or ends in zero;
a prefix just before a zero-run is odd.

Define the finite tree `A_R` as follows. Start with prefix `q=0` and
append a one-run. At each stage:

* Before a one-run, take `h=h_R(q+1,1)` and permit lengths
  `1<=ell<=floor(log2(3^h))`.
* Before a zero-run, take `h=h_R(q,0)` and permit lengths
  `1<=ell<=2h-1`.
* Retain as members every prefix ending with a one-run; continue
  alternating until at most `R` one-runs have been appended.

Here `floor(log2(3^h))` is an exact integer, computable as the bitlength
of `3^h` minus one. No floating-point logarithm is needed.

**RC-3.** For every `R>=1`:

1. `A_R` is finite and effectively computable.
2. If `r(n)<=R` and odd `n` is not in `A_R`, some actual `U^j(n)` has
   more than `R` one-runs, for `1<=j<=J_R`.
3. Every positive odd orbit whose one-run count stays at most `R`
   lies entirely in `A_R` and is eventually periodic, with reaching
   killed 1 counted as termination.
4. A positive ordinary Collatz orbit is eventually periodic if and
   only if its binary one-run count is bounded.

**Proof of the exit claim.** At the first inadmissibly long zero-run,
write the full input as `n=2^D q+v`, where the actual upper prefix `q`
is odd and `0<v<2^(D-ell)`. If `ell>=2h_R(q,0)`, then
`4^h v<2^D`. RC-2 and the definition of `h` give cap exit.

At the first inadmissibly long one-run, write

\[
n=2^D(q+1)+v,\qquad -2^{D-\ell}\le v<0.
\]

The upper integer `q+1` is odd. If
`ell>floor(log2(3^h_R(q+1,1)))`, then `3^h<2^ell`, so
`3^h|v|<2^D`; again RC-2 gives cap exit. The leading one-run is
covered by taking `q=0`; the terminal one-run is covered by `v=-1`.
Thus no endpoint case is omitted. RC-1 bounds both clocks by `J_R`.

For explicit finiteness, put

\[
D_1=\lfloor J_R\log_2 3\rfloor,\quad D_0=2J_R-1,\quad
B_R=R D_1+(R-1)D_0.
\]

Every tree member has bitlength at most `B_R`, and

\[
|A_R|\le\sum_{k=1}^R D_1^k D_0^{k-1}.
\]

A capped orbit cannot visit any state outside this finite core, by
the proved exit claim. It must therefore reach 1 or repeat. Conversely
an eventually periodic ordinary orbit has finitely many states and
hence bounded run count. Even steps only remove trailing zeros and
do not change the number of one-runs. QED.

`A_R` itself need not be forward invariant. The theorem concerns an
orbit that never leaves the cap; it does not delete outside-core
excursions from a physical replay.

### Height and recurrence consequences

If an odd source has bitlength greater than `B_R`, then

\[
\max_{0\le j\le J_R}r(U^j(n))>R.
\]

Indeed, either the input already exceeds the cap or it lies outside
the core. This is an explicit fixed-source height-to-complexity bound.

On a hypothetical escaping positive orbit, for each fixed `R` all
sufficiently late values exceed this height. Consequently every
sufficiently late window of `J_R+1` odd events contains a state with
more than `R` one-runs. Thus exceeding each fixed run cap eventually
has bounded gaps; mere unboundedness is not the only conclusion.
The time at which this becomes permanent is not bounded here.

### Independent direction of reconstruction

Let `B_R^1` be the odd sources whose paths reach 1 without exceeding
the run cap. RC-3 shows that this set is finite. Independently enumerate
it backward from 1. A target divisible by 3 has no odd predecessor.
Otherwise its first predecessor is

\[
m=(2^a q-1)/3,\qquad a=2\ (q\equiv1\pmod3),\quad
a=1\ (q\equiv2\pmod3).
\]

All others follow by `m -> 4m+1`. This concatenates `01` to an odd
binary word, so it increases the number of one-runs by exactly one.
Each inverse fan therefore has an exact finite cap cutoff. A visited
set handles the root self-loop and prevents repeat processing.

The separately constructed inverse set equals the entire forward
success set for each cap through six, not only its cardinality.
For cap five this checks all 12,564 success sources; their largest is
536878869. For cap six it checks all 157,728 success sources, with
largest element 68719605301. The inverse argument cannot find a disjoint cycle; the
complete forward core replay is what rules such a cycle out here.

The original elementary outside-core clocks are `J_5=2047` and
`J_6=8191`. The independent modular bounds in
[`modular_hitting.md`](modular_hitting.md) improve them to at most
13 and 21, respectively, without changing these adaptive trees.

**RC-5 (computer-assisted, with RC-1--RC-3 coverage).** Every positive

## 6. The uniform sparse-run descent strengthening is false

**RC-4 (exact obstruction).** There is no finite `K` such that every
positive odd source greater than 1 with one binary one-run descends
below its initial value within `K` odd events. In particular, there
is no universal guaranteed first-descent clock depending only on
the initial run count.

Take `n_a=2^a-1`, `a>=2`. It has one one-run, and

\[
U^j(n_a)=3^j2^{a-j}-1>n_a\qquad(1\le j<a).
\]

All these first `a-1` odd events have valuation one. In shortcut time,
`T^a(n_a)=3^a-1`. Thus a first descent, if it exists, takes at least
`a` odd events. This alone excludes any universal finite clock that
both guarantees and bounds descent for all one-run sources.

This does not assert a convergence theorem for the whole Mersenne
family. Its purpose is to reject the proposed uniform finite clock
without assuming whether a particular later descent exists.

The mechanism is visible already at `n=3`: it leaves run cap one at
`U(3)=5`, which is larger than the source. An exit certificate is not
a numeric-descent certificate. Raising the cap need not lower any
previous clock or repay any previous comparison debt.

## 7. Exact remaining obligation

The bounded-run theorem gives neither a run cap for an arbitrary
fixed positive source nor exclusion of the cycles in every `A_R`.
Those are the two still-open global tasks. A finite run-cap decision
can correctly return a nontrivial cycle if one exists; its proof of
termination is not a proof that its answer is always convergence.

The explicit Mersenne obstruction prevents a direct replacement of
the sparse-popcount first-descent forest by a uniform-clock
sparse-run version. Any successful global bridge must pay for run
cap increases while retaining one actual ordinary source and one
well-founded comparison. No such payment law is proved here.
