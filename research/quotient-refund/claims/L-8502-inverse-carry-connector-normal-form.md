# L-8502 — Ordinary inverse carry gives a causal connector normal form

**Claim ID:** `L-8502`  
**Status:** `PROPOSED`  
**Dependencies:** `D-8501`; elementary modular arithmetic  
**Scope:** every stabilized connector at a height divisible by `16`

## Setup

At source height `t`, put

\[
N=3^{7(t+1)},
\qquad
M=2^{11(t+17)}.
\]

Let

\[
\boxed{
r=[N^{-1}]_M,
\qquad
c=\frac{Nr-1}{M}.
}
\tag{1}
\]

Then

\[
0\le r<M,
\qquad
0\le c<N,
\qquad
Nr=1+Mc.
\]

For a source type `i` and target type `j`, define

\[
\boxed{
\omega_i=\frac{p_i+b_i r}{64},
}
\tag{2}
\]

\[
\boxed{
\delta_{ij}=[p_jr-p_ic]_{64}.
}
\tag{3}
\]

The numerator in (2) is divisible by `64`.

## Connector normal form

There is a unique `epsilon_(ij) in {0,1}` such that

\[
\boxed{
\eta_{t;i,j}
=-\omega_i+\frac{M}{64}\delta_{ij}+\epsilon_{ij}M
\in[0,M).
}
\tag{4}
\]

The canonical output is

\[
\boxed{
\theta_{t;i,j}
=
\frac{N\delta_{ij}-b_ic-p_j}{64}
+
\epsilon_{ij}N.
}
\tag{5}
\]

Thus the large connector seed is generated by:

```text
one ordinary inverse carry c,
one inverse residue r=(1+Mc)/N,
one six-bit cell delta_(ij),
one one-bit wrap epsilon_(ij).
```

No completed `2`-adic logarithm or inverse tape is required.

## Fixed-block carry update

At height `t+16`, write the corresponding data as `r',c',N',M'`. Put

\[
s=3^{112},
\qquad
u=2^{176},
\]

so that

\[
N'=sN,
\qquad
M'=u M.
\]

Define

\[
\bar c=[u^{-1}c]_N,
\tag{6}
\]

\[
H=\frac{1+u M\bar c}{N},
\tag{7}
\]

\[
q=[-H(u M)^{-1}]_s.
\tag{8}
\]

Then

\[
\boxed{
c'=\bar c+Nq,
\qquad
r'=\frac{1+M'c'}{N'}.
}
\tag{9}
\]

Here `0<=q<3^112`. One step appends one exact base-`3^112` carry digit. Equations (6)–(9) are a finite ordinary recurrence at a fixed block size, not an inverse-limit oracle.

## Proof

Because

\[
Np_i+b_i\equiv0\pmod{64}
\]

and `Nr≡1 mod64`, equation (2) is integral. Multiplying the connector congruence

\[
\eta\equiv(A_j-B_i)N^{-1}\pmod M
\]

through the definitions gives

\[
\eta
\equiv
-\omega_i+\frac M{64}(p_jr-p_ic)
\pmod M,
\]

which is (4). Since `0<=omega_i<M` and `0<=delta<64`, the unwrapped value lies strictly between `-M` and `M`, so one bit `epsilon` suffices.

Substitute (4) into

\[
B_i+N\eta=A_j+M\theta.
\]

Using `Nr=1+Mc` gives exactly (5). Its numerator is divisible by `64` because

\[
N\delta_{ij}
\equiv
Np_jr-Np_ic
\equiv
p_j+b_ic
\pmod{64}.
\]

For the carry update, (6) gives

\[
u\bar c\equiv c\pmod N,
\]

so (7) is integral. Equation (8) makes

\[
H+u Mq\equiv0\pmod s.
\]

Consequently

\[
1+u M(\bar c+Nq)
=N(H+u Mq)
\]

is divisible by `sN=N'`. This proves (9). The stated ranges make `r'` and `c'` the canonical inverse residue and carry. ∎
