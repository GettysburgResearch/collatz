# All-base regularity rigidity, including sparse-error approximators

**Status:** written proof. Builds on LOCAL_BLOCKS.md and, for exponent 0.84, the external published predecessor theorem.

A base-B automatic classifier is the output of a fixed finite deterministic automaton reading the canonical base-B expansion of a positive integer. No restriction to bases generated by 2 and 3. Finite output alphabet; the least-significant-first convention is equivalent by regular-language reversal.

## Theorem C (robust all-base obstruction)

Suppose a finite-alphabet function f has two different colors c,d with the following property: for each fixed M>=1 and 0<A<B', each color occupies at least C X^alpha/log(2X) disjoint intervals of M consecutive integers inside [AX,B'X] for all large X. Then for EVERY fixed base B>=2 and EVERY base-B automatic g (with the same or an enlarged output alphabet),

    #{1<=n<=X: f(n)!=g(n)} >= C_g X^alpha/log(2X)

for every sufficiently large X. If the assumed block bound has no log denominator, neither does the error bound.

Proof. If g has bounded runs of c, take M greater than their maximum; each disjoint c-block of f contains at least one disagreement. Otherwise g has arbitrarily long c-runs. Any interval of at least 2 B^k consecutive positive integers contains a full aligned interval [p B^k,(p+1)B^k) for some p>=1 (take a run of length at least 3 B^k if necessary). Thus for arbitrarily large k there is a prefix p whose state s after reading its canonical digits gives output c for EVERY suffix of length k (including leading zeros in the suffix).

There are finitely many states, so a single reachable s has this property at infinitely many k. Fix one positive canonical prefix p0 reaching s. Starting from {s}, iterate the map on subsets of states that takes their union of all one-digit successors. This finite deterministic iteration is eventually periodic. Hence the property that all reachable states have output c holds on at least one infinite arithmetic progression of lengths k with bounded gaps. For all such k, g is identically c on [p0 B^k,(p0+1)B^k).

Given any sufficiently large X choose the largest k of that progression with (p0+1)B^k<=X. Then B^k is comparable to X, with constants depending only on the classifier. Set Y=B^k and apply the d-block bound with M=1 in [(p0+1/4)Y,(p0+3/4)Y]. Every point of that color is an error. The lower bound follows for ALL large X, not merely along a subsequence. QED.

## Consequences

1. Let S be a nonempty proper set of positives with n in S iff T(n) in S. Both colors contain an odd ternary unit: strip initial twos, apply an odd shortcut, and strip subsequent twos. Membership is invariant throughout. Each color contains Anc(a) for its chosen fixed a. Theorem A supplies the hypotheses. Therefore no such S can be automatic in ANY integer base, and every fixed automatic approximation has the stated lower error count. This includes the basin C of 1 if it is proper.

2. **A complete sufficient criterion for Collatz:** there exist an integer base B>=2, a fixed finite automaton outputting an approximation g to the indicator of C, and an unbounded sequence X_j for which the mismatch count is o(X_j^eta), where eta=log(2)/log(64/3). With the external 0.84 input, the sufficient condition weakens to o(X_j^0.84/log(2X_j)). Conversely if Collatz holds, g=1 works with zero errors. Thus this is an equivalence, NOT a proof that such an approximation exists. There is no complexity-uniform lower constant over classifiers varying with X.

3. Without assuming Collatz, weighted stopping-time residues from Theorem B cannot be automatic in any base, even after allowing the same sparse errors. Indeed every residue modulo m occurs in the known convergent ancestor pool, so any two distinct residues give the needed colored blocks. The statement also applies to the indicator of a single residue (the complement contains another). If the weights have common gcd with m, reduce to the reachable cyclic subgroup first.

4. Individual ancestor sets Anc(y) for odd units y>1 are nonautomatic: choose another odd unit b whose ancestors are disjoint from Anc(y). If y reaches a power of two, choose a sufficiently large power of two not visited by y, then an odd unit ancestor b of that power with b's path avoiding y (e.g. use an inverse (2^e-1)/3 for an adequately large even e with 3∤ inverse; its path visits only powers of two after its first odd step). If y does not reach any power of two, use b=1. If y itself is a power of two and a unit, the only odd case is y=1, excluded here. In the first case choose the inverse b distinct from y; its forward path cannot hit y after its first step because y is odd >1, and y cannot hit b since otherwise y reaches the deliberately larger power. Two ancestor sets intersect only if one target lies on the other's orbit. Thus Anc(y) and its complement contain the two fixed ancestor pools. The proof extends to even targets when an incomparable unit target exists; we do not claim it for y=1,2,4,8 unconditionally.

5. Conditional on one failed five-comparison, RATIO_PRESSURE.md supplies the same two-color local thickening for its defect indicator (one color exact failures q in C,5q outside C; the other exact successes). Thus an all-base automatic approximator with o(X^(1/9)) errors along an unbounded sequence for that defect indicator would rule out any failed comparison, and hence settle Collatz by the source-qualified equivalence PR157. This conclusion does NOT rely on a natural density upper bound for the failed five-comparison set.

## Literature relationship and limit

The rStation preprint "Automaticity of saturated sets, ancestor sets, stopping times and forward-invariant sets of 3x±1 maps" (v2, https://rstation.ai/problems/collatz/papers/64/v2) treats base 2, base 3 and consequences in bases of the form 2^a3^b via Cobham-style arguments; the proof here instead uses exact macroscopic block gluing and finite-state monochromatic cylinders. We make no exhaustive literature-priority claim. In particular this proof treats arbitrary integer bases, including 5, and quantitative sparse-error approximators; exact nonautomaticity follows immediately. The predecessor exponent comes from Krasikov–Lagarias, https://arxiv.org/abs/math/0205002, not from the preprint.

The substantive closing gap remains: construct a *single fixed* finite classifier approximating the actual basin to the stated error threshold, or obtain a different uniform ordinary-source contradiction. Increasing finite certificate coverage with automaton size varying with cutoff cannot discharge this criterion.
