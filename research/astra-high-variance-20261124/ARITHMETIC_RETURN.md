# Equal odd clocks on the critically summable section

**Status.** Lean checks the equal-clock merger on literal shortcut steps. The residual projection and return dynamics have written proofs. Every marked positive odd source admits a representative in the decidable residual set of PR182 round 13 at the same specified odd clock. Mark-to-mark reductions therefore give a computable residual return map with a delay coordinate. Its settled states lie on one original ordinary orbit. Eventual periodicity of this return dynamics is equivalent to eventual periodicity of that source. Convergence to one and exclusion of an escaping residual path remain open.

Use \(U(q)=(3q+1)/2^{v_2(3q+1)}\) on positive odd integers, \(T\) for the shortcut map, and \(u\) for odd part. In octave \(d\) let \(I_d\) be the integer interval from \(2^d\) up to the smaller of \(2^{d+1}-1\) and \(2^d+\lfloor70\,2^d/(d+1)\rfloor\). Odd members are marked. Put \(R_d=(d+2)^3\). PR182 partitions all integers \(z\in I_d\) by \(U^{R_d}(u(z))\). A fiber containing an even member or an odd member with a successful bounded half script is discarded. Each other fiber contributes its minimum to the decidable set \(S\). The written translated-interval counting theorem then gives \(\sum_{s\in S}s^{-\theta}<\infty\) for \(\theta=H_2(\log 2/\log 3)\). The elementary results below use the fiber construction, not the analytic count. ## Equal-clock half merger

For a successful mixed script on \(n=2^{k+1}v-1>1\), compare it to \(x=(n-1)/2\) and put \(b=3^k v-1\). The rising prefixes use \(k+1\) odd shortcuts on the \(n\)-arm to reach \(3b+2\), and \(k\) on the \(x\)-arm to reach \(b\). Keep an orientation sign \(\delta\): \(+1\) when the \(n\)-arm is on \(3b+2\), and \(-1\) when it is on \(b\). The difference of cumulative odd shortcut counts, ordered \(n\)-arm minus \(x\)-arm, is exactly \(\delta\) at each return boundary. Initially it is \(+1\). An odd return uses one odd step on both sides. A six-step swap uses three odd shortcuts on the current \(b\)-arm and one on the \(3b+2\)-arm. Thus it adds \(-2\delta\) and exchanges orientation. Finally \(b=4w+2\) uses one odd shortcut on \(b\) and zero on \(3b+2\) before the common endpoint, cancelling \(\delta\). Projecting a literal shortcut trajectory with \(J\) odd inputs onto odd parts advances exactly \(J\) applications of \(U\), even if the literal start or end is even. Consequently \(U^J(n)=U^J(u(x))\) at a **common** odd clock. This argument uses the formal counts, in addition to the pre-existing meeting of the two trajectories. [Exact source transitions](https://github.com/GettysburgResearch/collatz/blob/9b02334f27ff59694a91fe7f018e0aaabad7620b/research/astra-round13-20261124/BAND_RETURN.md)

For at most \(d+1\) returns, \(J\le (k+1)+6(d+1)+2\le7(d+1)+2\le R_d\) when \(d\ge1\). The octave zero consists only of 1, which fails the grammar at \(b=0\) and contributes 1 to \(S\). Every other accepted source has \(x>0\), whose odd part is a mark below that octave by binary digit deletion.

## Residual projection at one clock

For every mark \(n\in I_d\) let \(r(n)\) be the least marked \(z\le n\) with \(U^{R_d}(z)=U^{R_d}(n)\). The finite exhaustive definition is computable. Then \(r(n)\in S\). Indeed any nonresidual mark \(z\) at octave \(e\le d\) has a smaller marked partner \(y\) with \(U^{R_e}(y)=U^{R_e}(z)\). If the fiber contains an even integer take its odd part below the octave. If it contains an accepted odd integer take the odd part of its half partner, also below the octave; the preceding lemma and the fiber equality both hold at \(R_e\). Otherwise take the fiber minimum strictly below \(z\). Since \(R_e\le R_d\), all of these equalities persist at \(R_d\). Applying this to \(z=r(n)\) would contradict its minimality. Equal-clock comparisons compose at their maximum horizon, including when representatives move through many octaves.

On an injective ordinary orbit, different marked visit times give different residual representatives. In fact if \(r(q_i)=r(q_j)\) for \(i<j\), advancing both comparisons to their largest clock would identify \(q_{i+R}\) and \(q_{j+R}\). The representatives are termwise no larger, so the marked-visit sum with critical power is finite. PR193 interval synchronization and injectivity already imply the same numerical summability by counting marked visits octave by octave. The representative identity is the stronger structural conclusion; it identifies the original synchronized component of each mark.

## A return dynamics whose observations stay on one ordinary trajectory

Use states \((s,L)\in S\times\mathbb N_0\). The settled value of a state is \(v=U^L(s)\). Find the first strictly positive \(k\) for which \(n=U^k(v)\) is marked. It exists by applying the actual forward marked-visit theorem to \(U(v)\). Set
\[
 (s',L')=(r(n),R_{\lfloor\log_2 n\rfloor}).
\]
This map is everywhere defined, deterministic, and computable by literal iteration and finite search. Its successive settled values satisfy the exact identity \(v'=U^{k+L'}(v)\). Hence they advance strictly along the original ordinary orbit. From any positive odd initial source, its first marked visit initializes the map by projection and settling, giving an ordinary tail of that same source.

If the original orbit is eventually periodic, the strictly advancing settled observations eventually belong to its cycle, so subsequent marked \(n\), deterministic representatives and delays take only finitely many possibilities. The return states are eventually periodic. Conversely, a repeated return state repeats its settled value at distinct ordinary odd clocks, forcing the ordinary orbit to be eventually periodic. The original orbit hits one precisely when the settled observations eventually equal one. In the escaping case the \(s\) coordinates themselves are pairwise distinct: each mark \(n_j\) occurs on the original orbit at a strictly later clock and maps to \(s_j=r(n_j)\). This assertion concerns the generated outputs; an arbitrary initial state can be omitted. Since \(S\) is critically summable, these residual coordinates satisfy \(\sum_j s_j^{-\theta}<\infty\).

## What remains

The delayed residual map records physical ordinary time and needs no conjecture about future meetings. Its residual coordinate is smaller than the *new mark*; the construction supplies no upper bound by the preceding residual coordinate. Also the search time and new delay are determined by the new mark, and settled states need not lie in \(S\). A sparse set with an injective path presents no counting contradiction by itself. For example an abstract set with one integer \(2^j+1\) in each large octave already has a finite sum at this power and can carry an infinite successor path. This example only tests the proposed summability inference. The ordinary dynamics remains essential. No proof of tight positive smooth-summand lengths for residual states or of recurrence of the delayed map has been obtained. The Std-only file [arithmetic_equal_clock.lean](arithmetic_equal_clock.lean) checks the literal terminal, odd, and six-step parity words; inducts over all successful scripts; and checks both the identical endpoint and the identical number of odd steps for the two raw physical sources. Its two public theorems compiled in Lean 4.34.1 with warnings as errors and reported only propext, Classical.choice and Quot.sound. The projection to odd parts and the induced return-map arguments remain written proofs.
