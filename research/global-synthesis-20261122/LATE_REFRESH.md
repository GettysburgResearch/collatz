## 2. Actual return composition still loses the common finite reference

PR180's
[RETURN_ATTACK.md](https://github.com/GettysburgResearch/collatz/blob/cfe70e02f246119a55fb5bf8fd573f148d746beb/research/lean-critical-20261122/RETURN_ATTACK.md)

reference with all logarithmic height moments. Every fixed return has a
finite \(L^p\) density with respect to that one reference for every finite
\(p>1\).

Its stronger composition theorem gives, for the actual positive-return
operator \(Q\) and entrance mass \(\rho\),
\[
 Q^k\rho\le K_0K_{**}\,
 \beta_{\,2+2^{-k},\,50^{-k}},
\]
with a constant independent of \(k\). Every original label, collision and
entrance residual is retained. The reference on the right changes with
\(k\). Its limit is the full marked occupation measure for original
weights \(n^{-2}\); periodic marked atoms become infinite, and an escaping
marked ray would force infinite total nonperiodic occupation.

Thus the displayed constant does not establish domination by one finite
reference at every depth. The sufficient single-reference energy estimate
in that note remains unproved.

The companion
[POTENTIAL_ATTACK.md](https://github.com/GettysburgResearch/collatz/blob/cfe70e02f246119a55fb5bf8fd573f148d746beb/research/lean-critical-20261122/POTENTIAL_ATTACK.md)

on first entrance into **any** periodic orbit. On this domain it proves

 S=\sum_{j\ge0}L^j:\ell^1\longrightarrow\ell^1_s,\qquad
 \|(I-Q_X)Sa\|_{1,s}
 \le\frac{5s}{s-39/40}X^{39/40-s}\|a\|_1
 \quad(s>39/40).

The output norm weights height \(q\) by \(q^{-s}\). This is a genuine
all-time source-preserving estimate. It does not bound the positive
minimum \(m(n)\) in our ordinary-mass theorem. The note also proves that
\(L\) is not closable on this output space, using an explicit family
already known to converge. Compactness here is not a common-space
compact-resolvent argument.

The original PDU source used in [ORDINARY_MASS.md](ORDINARY_MASS.md) and

## 3. A specific invariant escape label, with an exact approximation target

PR182's
[canonical escape label](https://github.com/GettysburgResearch/collatz/blob/9dacd610ba7735e89e2e29e4ab01795983317980/research/lean-dyadic-descent-20261121/CANONICAL_ESCAPE_LABEL.md)
uses the existing ordinary harmonic reference \(\nu\), immigration mass
\(d\), and an escaping unit component \(\mathcal C\) to define
\[
 F_{\mathcal C}=
 \frac{\sum_{n\in\mathcal C}d(n)}
      {\lim_{k\to\infty}\nu(U^kq)}\in(0,1).
\]
It extends this to a bounded exact shortcut-invariant label on all
positive ordinary integers, zero on every eventually periodic component
and positive on every escaping component.

The
[polynomial-phase rigidity theorem](https://github.com/GettysburgResearch/collatz/blob/9dacd610ba7735e89e2e29e4ab01795983317980/research/lean-dyadic-descent-20261121/INVARIANT_CORRELATION.md)
then gives a precise target: ordinary Besicovitch approximation of this
particular label by finite polynomial-phase sums would force it to be
constant and hence zero. The construction proves no such approximation.
Assigning zero to every periodic component also leaves cycle exclusion
separate.

The
[canonical Green bound](https://github.com/GettysburgResearch/collatz/blob/9dacd610ba7735e89e2e29e4ab01795983317980/research/lean-dyadic-descent-20261121/HARMONIC_CAPTURE_BRIDGE.md)
uses the same nonperiodic unit domain and killing convention. It keeps
the unchanged seed \(a_0(n)=h(n)/n\), time zero, and all collisions:
\[
 3\bigl(\nu(q)-\lambda(q)h(q)\bigr)
 \le\sum_{k\ge0}L^ka_0(q)
 \le4\bigl(\nu(q)-\lambda(q)h(q)\bigr).
\]
It yields complete fixed-target occupation and a summable collision
budget weighted by \(q^{-s}\), \(s>39/40\).

Two exact scope distinctions matter when combining this with our route.
First, the high-floor improvement requires the minimum of the **whole
predecessor domain**. A later endpoint on one escaping orbit still has
the original source as an ancestor, so a growing forward-suffix minimum
cannot be substituted. Second, the inverse occupation cost is comparable
to \(1/q\); its total budget does not bound the number of continuation
steps at increasingly high ancestors. A moving-target contact rate or
spatial tightness estimate is still needed.

The same distinction appears in PR183's new ordinary spectral channels:
an exact critical residue identifies escaping components, but its
vanishing is not supplied by boundedness or by the channel decomposition.

## 4. Finite-period profiles are now excluded at every real exponent

PR175's
[ADDENDUM_ALL_EXPONENTS.md](https://github.com/GettysburgResearch/collatz/blob/75e4c3be98db839646ffbb76fc0ac33649747c99/research/lean-global-closure-20261121/ADDENDUM_ALL_EXPONENTS.md)
concerns the real growth exponent \(p\) in a proposed finite-period
leading profile
\[
\frac{F(n)}{n^pL(n)}-a(n\bmod M)\longrightarrow0
\quad\text{along positive odd }n
\]
for a nonnegative inverse-excessive function. It is distinct from the
integer cycle-block exponents in Section 1.

Together with its
[fixed-resolution obstruction](https://github.com/GettysburgResearch/collatz/blob/75e4c3be98db839646ffbb76fc0ac33649747c99/research/lean-global-closure-20261121/FIXED_RESOLUTION_ENVELOPE_OBSTRUCTION.md),
it forces every relevant residue coefficient to vanish for every real
\(p\), under the stated affine slow-variation hypothesis. At the critical
exponent \(p=1\), two distinct actual inverse histories at the same odd
depth force \(a(1)\ge2a(1)\). The cited arithmetic-progression theorem then
propagates zero.

This excludes nonzero fixed-period leading profiles. It does not exclude
upper majorants or zero normalized profiles, and supplies no upper bound
for an irregular or changing-resolution canonical envelope.
