## Statement

Let T: N_0 -> N_0 be the shortcut Collatz map (T(n) = n/2 for n even, (3n+1)/2 for n odd), let G be its functional graph on N_0 with weak components ("components"), and let F: l^inf(N_0) -> l^inf(N_0) be the linear operator (Fa)_m = a_{T(m)}. A "cycle of length p" is a set of p distinct vertices z_0,...,z_{p-1} with T(z_i) = z_{(i+1) mod p}. Call a forward orbit (T^k(m))_{k>=0} DIVERGENT if it never enters a cycle (equivalently, all T^k(m) are pairwise distinct). Let P = { p >= 1 : T has a cycle of length p } (so {1,2} is a subset of P, from the cycles {0} and {1,2}), let mu_p = { lambda in C : lambda^p = 1 }, and let sigma_p(F|l^inf) = { lambda in C : there is a in l^inf(N_0), a != 0, Fa = lambda a }. Then: (1) For every component C containing a cycle of length p and every lambda in C\{0}: there exists a in l^inf, supp(a) contained in C, a not identically 0 on C, with Fa = lambda a, IF AND ONLY IF lambda^p = 1; the eigenvector may be taken as a_m = lambda^{-d(m)} on C (0 off C), where d: C -> Z/pZ is the canonical depth function with d(T(m)) = d(m) - 1 (mod p). (2) A component C is cycle-free iff it contains a divergent orbit (iff every orbit in it is divergent); every cycle-free component supports, for EVERY lambda with |lambda| = 1, an eigenvector a in l^inf with supp(a) in C, a nowhere zero on C, namely a_m = lambda^{-d(m)} for a genuine depth function d: C -> Z with d(T(m)) = d(m) - 1. (3) If lambda is not a root of unity and a (any complex sequence, bounded or not) satisfies a_{T(m)} = lambda a_m for all m, then a vanishes identically on every cycle-containing component. (4) sigma_p(F|l^inf) ∩ S^1 = (Union over p in P of mu_p) ∪ D, where D = S^1 if T has a divergent orbit and D = empty set otherwise; moreover sigma_p(F|l^inf) ∩ S^1 = S^1 iff T has a divergent orbit. (5a) The Collatz conjecture (G has exactly the two components {0} and C1) holds iff sigma_p(F|l^inf) ∩ S^1 = {+1, -1}; unconditionally {+1,-1} is contained in sigma_p(F|l^inf) ∩ S^1. (5b) sigma_p(F|l^inf) ∩ S^1 contains some lambda that is not a root of unity iff T has a divergent orbit. (5c) If a primitive q-th root of unity with q >= 3 lies in sigma_p(F|l^inf), then either T has a cycle of length p divisible by q (hence p >= q >= 3, a cycle distinct from {0} and {1,2}) or T has a divergent orbit; in either case the Collatz conjecture is false.

## Proof

# T-9703: Unit-circle point-spectrum trichotomy for F on l^inf(N_0)

## 0. Conventions

- `T(n) = n/2` (n even), `(3n+1)/2` (n odd) on `N_0`; note `T(0)=0`, `T(1)=2`, `T(2)=1`.
- `(Fa)_m = a_{T(m)}`. For `a` in `l^inf`, `sup_m |a_{T(m)}| <= sup_m |a_m|`, so `F` maps `l^inf` to `l^inf` with operator norm `<= 1` (in fact `= 1`: `F1 = 1`). `sigma_p(F|l^inf)` = set of `lambda` admitting `a in l^inf`, `a != 0`, `Fa = lambda a`.
- A **cycle of length p** is a set of `p` **distinct** vertices `z_0, ..., z_{p-1}` with `T(z_i) = z_{(i+1) mod p}` (indices mod `p`). Then `p` is the minimal period of each `z_i` (distinctness). The known cycles `{0}` (p=1) and `{1,2}` (p=2) exist.
- An orbit `(T^k(m))_{k>=0}` is **divergent** if it never enters a cycle.
- `mu_p = {lambda : lambda^p = 1}` (note `mu_p` is a subset of `S^1` automatically).

Throughout, "component" means weak (undirected) component of the functional graph `G`.

## 1. Lemma 1 (components = grand orbits)

Define `m R n` iff `T^j(m) = T^k(n)` for some `j,k >= 0`. Then `R` is an equivalence relation whose classes are exactly the weak components of `G`.

*Proof.* Reflexive (`j=k=0`) and symmetric are clear. Transitive: if `T^j(m) = T^k(n)` and `T^{j'}(n) = T^{k'}(l)`, apply `T^{j'}` to the first: `T^{j+j'}(m) = T^{j'}(T^k(n)) = T^k(T^{j'}(n)) = T^{k+k'}(l)` (powers of `T` commute). Each edge `m -- T(m)` joins `R`-equivalent vertices (`T^1(m) = T^0(T(m))`), so undirected connectivity refines `R`. Conversely if `T^j(m) = T^k(n)` then the undirected walk `m, T(m), ..., T^j(m) = T^k(n), ..., T(n), n` connects `m` to `n`. Since weak components are the classes of the equivalence generated by edges, the two partitions coincide. ∎

## 2. Lemma 2 (componentwise reduction)

(i) `T` maps every component `C` into itself and `N_0 \ C` into itself. (ii) If `Fa = lambda a` with `a in l^inf` and `C` is a component, then `b := a * 1_C` (restriction, extended by 0) satisfies `Fb = lambda b` and `b in l^inf`. (iii) Consequently `lambda in sigma_p(F|l^inf)` iff some component `C` supports `b in l^inf`, `b != 0`, `supp(b) ⊆ C`, `Fb = lambda b`.

*Proof.* (i) `m` and `T(m)` are adjacent, hence in the same component; and if `m ∉ C` but `T(m) ∈ C` then adjacency would force `m ∈ C`, contradiction. (ii) For `m ∈ C`: `T(m) ∈ C`, so `b_{T(m)} = a_{T(m)} = lambda a_m = lambda b_m`. For `m ∉ C`: `T(m) ∉ C`, so `b_{T(m)} = 0 = lambda b_m`. (iii) "if": extend by zero — that IS the eigenvector. "only if": pick `m_0` with `a_{m_0} != 0` and take `C` = component of `m_0`; then `b = a·1_C != 0`. ∎

## 3. Lemma 3 (cycle structure of a component)

Let `C` be a component.

(a) `C` contains at most one cycle.
(b) If `C` contains a cycle `Z`, then the forward orbit of **every** `m ∈ C` enters `Z` (in particular no orbit in `C` is divergent).
(c) `C` is cycle-free iff `C` contains a divergent orbit, iff **every** orbit in `C` is divergent. Moreover an orbit is divergent iff `k -> T^k(m)` is injective.

*Proof.* First the last claim of (c): if `T^s(m) = T^t(m)` with `s < t`, then `x = T^s(m)` satisfies `T^{t-s}(x) = x`; taking `p` minimal with `T^p(x) = x`, the set `{x, T(x), ..., T^{p-1}(x)}` consists of distinct vertices (minimality) and is a cycle of length `p`, which the orbit of `m` has entered. Conversely, entering a cycle at time `k` gives `T^{k+p}(m) = T^k(m)`, so the orbit is not injective. Hence divergent ⟺ injective orbit.

(a) Let `Z, Z'` be cycles in `C`, `z ∈ Z`, `z' ∈ Z'`. By Lemma 1, `T^j(z) = T^k(z')` for some `j,k`. But `T^j(z) ∈ Z` and `T^k(z') ∈ Z'` (cycles are `T`-invariant), so `Z ∩ Z' != ∅`. A cycle is the full forward orbit of any of its points, so a common point forces `Z = Z'`.

(b) Given `m ∈ C` and `z_0 ∈ Z`, Lemma 1 gives `T^j(m) = T^k(z_0) ∈ Z`.

(c) If `C` has a cycle, (b) shows no orbit in `C` is divergent. If `C` is cycle-free, then for every `m ∈ C` the orbit of `m` cannot enter any cycle: a cycle met by the orbit of `m` would consist of vertices `T`-reachable from `m`, hence (Lemma 1) lie in `C`, contradiction. So all orbits in `C` are divergent; in particular some orbit is. Conversely if `C` contains a divergent orbit and also a cycle, (b) contradicts divergence. ∎

## 4. Lemma 4 (depth mod p on a cycle component — the cocycle crux)

Let `C` be a component containing the (unique) cycle `Z = {z_0, ..., z_{p-1}}`, `T(z_i) = z_{(i+1) mod p}`, vertices distinct. Say `(k, i)` is a **certificate** for `m ∈ C` if `k >= 0` and `T^k(m) = z_i`. By Lemma 3(b) every `m ∈ C` has a certificate.

**Claim:** `d(m) := (k - i) mod p` is independent of the certificate, so `d: C -> Z/pZ` is well defined; it satisfies the cocycle identity `d(T(m)) ≡ d(m) - 1 (mod p)`, and `d(z_i) ≡ -i`.

*Proof of well-definedness.* Let `(k,i)` and `(k',i')` be certificates for the same `m`, WLOG `k <= k'`. Then
`z_{i'} = T^{k'}(m) = T^{k'-k}(T^k(m)) = T^{k'-k}(z_i) = z_{(i + k' - k) mod p}`.
Since `z_0, ..., z_{p-1}` are **distinct**, equal cycle vertices have equal indices mod `p`: `i' ≡ i + k' - k (mod p)`, i.e. `k' - i' ≡ k - i (mod p)`. (This is the whole content of path-independence in a functional graph: forward determinism means any two ways of reaching the cycle from `m` differ by extra travel *around* the cycle, which shifts `k` and `i` by the same amount mod `p`. Distinctness of the `z_i` — i.e. minimality of the period — is essential; `d` mod a non-minimal period would be ill-defined... rather, mod a proper multiple `p'` of `p` the argument fails exactly because `z_{i}` with indices mod `p'` are not distinct labels.)

*Cocycle.* If `(k,i)` is a certificate for `m` with `k >= 1`, then `(k-1, i)` is a certificate for `T(m)`, so `d(T(m)) ≡ (k-1) - i = d(m) - 1`. If `k = 0` (i.e. `m = z_i`), then `(0, (i+1) mod p)` is a certificate for `T(m) = z_{(i+1) mod p}`, so `d(T(m)) ≡ -(i+1) = d(m) - 1`. `d(z_i) ≡ -i` via certificate `(0,i)`. ∎

**Signed-path invariance (cocycle form).** For any undirected walk `m = v_0, v_1, ..., v_r = n` in `C` (each step an edge traversed forwards, `T(v_j) = v_{j+1}`, sign `ε_j = +1`, or backwards, `T(v_{j+1}) = v_j`, sign `ε_j = -1`), the cocycle identity gives in either case `d(v_{j+1}) ≡ d(v_j) - ε_j (mod p)` (forwards: directly; backwards: `d(v_j) ≡ d(v_{j+1}) - 1`, i.e. `d(v_{j+1}) ≡ d(v_j) + 1`). Telescoping: `d(n) ≡ d(m) - Σ ε_j (mod p)`. Hence the signed edge count of **every** undirected walk between two fixed vertices is congruent mod `p` to `d(m) - d(n)`; in particular every closed walk has signed count `≡ 0 (mod p)`, and the cycle itself is a closed walk of signed count exactly `p`.

## 5. Lemma 5 (Z-valued depth on a cycle-free component)

Let `C` be cycle-free, fix a base point `b_0 ∈ C`. By Lemma 3(c), the forward orbit of `b_0` is injective. Say `(j,k)` is a certificate for `m ∈ C` if `T^j(m) = T^k(b_0)`; every `m ∈ C` has one (Lemma 1).

**Claim:** `d(m) := j - k ∈ Z` is certificate-independent; `d(T(m)) = d(m) - 1` and `d(b_0) = 0`.

*Proof.* Let `(j,k)`, `(j',k')` be certificates, WLOG `j <= j'`. Then `T^{k'}(b_0) = T^{j'}(m) = T^{j'-j}(T^j(m)) = T^{j'-j+k}(b_0)`; injectivity of the orbit of `b_0` gives `k' = j' - j + k`, i.e. `j' - k' = j - k`. Cocycle: if `j >= 1`, `(j-1, k)` certifies `T(m)`: `d(T(m)) = j-1-k = d(m)-1`; if `j = 0` then `m = T^k(b_0)` and `(0, k+1)` certifies `T(m) = T^{k+1}(b_0)`: `d(T(m)) = -(k+1) = d(m) - 1`. `d(b_0) = 0` via `(0,0)`. ∎

(As in Lemma 4, telescoping gives: every undirected walk from `m` to `n` has signed edge count exactly `d(m) - d(n) ∈ Z`; every closed walk has signed count `0`. Note `d` is unbounded in both directions: `d(T^k(b_0)) = -k`, and along the doubling chain `d(2^k b_0) = k` since `T(2x) = x` forces `d(2x) = d(x) + 1`; also `0 ∉ C` because `{0}` is a cycle, so `2x != x` on `C`.)

## 6. Theorem, parts (1)-(3)

**(1) Cycle component, existence.** Let `C` contain a cycle of length `p` and let `lambda^p = 1` (hence `|lambda| = 1`). With `d` from Lemma 4, `lambda^{d(m)}` is well defined for `d(m) ∈ Z/pZ` because `lambda^p = 1`. Set `a_m = lambda^{-d(m)}` for `m ∈ C`, `a_m = 0` otherwise. Then `|a_m| ∈ {0,1}`, so `a ∈ l^inf`, `‖a‖_inf = 1`, and `a` is nowhere zero on `C` (in particular `a != 0`; `C != ∅`). Eigen-equation: for `m ∈ C`, `a_{T(m)} = lambda^{-d(T(m))} = lambda^{-(d(m)-1)} = lambda · a_m`; for `m ∉ C`, `T(m) ∉ C` (Lemma 2(i)) and both sides are `0`. So `Fa = lambda a`.

**(1) Cycle component, nonexistence + (3).** Let `lambda != 0` with `lambda^p != 1`, and let `a` be ANY complex sequence (boundedness not needed) with `a_{T(m)} = lambda a_m` for all `m`. By induction, `a_{T^k(m)} = lambda^k a_m` for all `k >= 0`. For `z` on the cycle: `T^p(z) = z`, so `a_z = lambda^p a_z`, i.e. `(lambda^p - 1) a_z = 0`, forcing `a_z = 0`. For arbitrary `m ∈ C`, pick `k` with `T^k(m) ∈ Z` (Lemma 3(b)): `lambda^k a_m = a_{T^k(m)} = 0`, and `lambda != 0` gives `a_m = 0`. So `a ≡ 0` on `C`. This proves the "only if" of (1) (an eigenvector supported in `C` and not identically zero on `C` forces `lambda^p = 1`), and proves (3): if `lambda` is not a root of unity then `lambda^p != 1` for every `p >= 1` and `lambda != 0` (roots of unity are the only... rather: `lambda = 0` is excluded since `0` is trivially a "root" case — in fact `0 ∉ S^1` and moreover `lambda = 0` is never an eigenvalue of `F` at all: `a_{T(m)} = 0` for all `m` makes `a` vanish on `range(T) = N_0`, since every `n = T(2n)`); hence any solution of the eigen-equation vanishes identically on every cycle-containing component. ∎

**(2) Cycle-free component.** The equivalence "cycle-free ⟺ contains a divergent orbit ⟺ all orbits divergent" is Lemma 3(c). Let `|lambda| = 1` and `d: C -> Z` as in Lemma 5. Set `a_m = lambda^{-d(m)}` on `C`, `0` off `C`. Then `|a_m| = |lambda|^{-d(m)} = 1` on `C` (this is where `|lambda| = 1` is essential, since `d` is unbounded both ways), so `a ∈ l^inf`, `‖a‖_inf = 1`, `a` nowhere zero on `C`. The eigen-equation holds exactly as in (1): on `C`, `a_{T(m)} = lambda^{-d(m)+1} = lambda a_m`; off `C` both sides vanish. ∎

## 7. Theorem, part (4): assembly

Let `P` be the set of cycle lengths of `T` and `D = S^1` if a divergent orbit exists, `D = ∅` otherwise. Claim: `sigma_p(F|l^inf) ∩ S^1 = (⋃_{p∈P} mu_p) ∪ D`.

**⊇:** For `p ∈ P`, a cycle of length `p` lies in some component `C` (unique cycle of `C`, Lemma 3(a)); part (1) provides, for each `lambda ∈ mu_p ⊆ S^1`, an `l^inf` eigenvector. If a divergent orbit exists, its component `C` is cycle-free (Lemma 3(c)); part (2) provides an eigenvector for every `lambda ∈ S^1`.

**⊆:** Let `lambda ∈ S^1`, `a ∈ l^inf`, `a != 0`, `Fa = lambda a`. By Lemma 2(iii) pick a component `C` with `a` not identically zero on `C` (the restriction is again an eigenvector). If `C` contains a cycle, of length `p` say, then by part (1)'s nonexistence direction, `lambda^p = 1`, so `lambda ∈ mu_p` with `p ∈ P`. If `C` is cycle-free, then `C` contains a divergent orbit (Lemma 3(c)), so `D = S^1` and `lambda ∈ D`.

**Full-circle criterion:** if a divergent orbit exists, the RHS is `S^1`, so `sigma_p ∩ S^1 = S^1`. If none exists, `sigma_p ∩ S^1 = ⋃_{p∈P} mu_p`, a countable set (countable union of finite sets — `P ⊆ N` even if infinite), hence a proper subset of the uncountable `S^1`. So `sigma_p(F|l^inf) ∩ S^1 = S^1` **iff** a divergent orbit exists. ∎

## 8. Lemma 6 (classification of 1- and 2-cycles of T)

**Fixed points:** `n` even: `n/2 = n` ⟹ `n = 0`. `n` odd: `(3n+1)/2 = n` ⟹ `n = -1 ∉ N_0`. So `0` is the only fixed point.

**2-cycles** (`T^2(n) = n`, `T(n) != n`): four parity cases. (i) `n` even, `n/2` even: `n/4 = n` ⟹ `n = 0`, excluded (`T(0)=0`). (ii) `n` even, `n/2` odd: `(3(n/2)+1)/2 = n` ⟹ `3n + 2 = 4n` ⟹ `n = 2`, and `n/2 = 1` is odd: valid, giving `{2,1}`. (iii) `n` odd, `(3n+1)/2` even: `(3n+1)/4 = n` ⟹ `n = 1`, and `T(1) = 2` is even: valid, same cycle `{1,2}`. (iv) `n` odd, `(3n+1)/2` odd: `(3(3n+1)/2 + 1)/2 = n` ⟹ `9n + 5 = 4n` ⟹ `n = -1 ∉ N_0`. So the only cycles of length 1 or 2 are `{0}` and `{1,2}`. ∎

Also: **the component of 0 is exactly `{0}`.** `T(m) = 0` forces `m = 0` (`m` even: `m/2=0` ⟹ `m=0`; `m` odd: `(3m+1)/2 = 0` has no solution in `N_0`), so by induction `T^j(m) = 0` ⟹ `m = 0`; by Lemma 1, `m ~ 0` iff `T^j(m) = 0` for some `j`, iff `m = 0`. (Note `{0}` is the unique **finite** component; every component containing some `n >= 1` contains the pairwise-distinct chain `n, 2n, 4n, ...` since `T(2x) = x`. Nothing in Sections 1-7 assumed components are infinite, so `C = {0}` is covered by the general cycle-component case with `p = 1`: `d ≡ 0`, eigenvector `δ_0`, eigenvalue `lambda = 1` only.)

## 9. Corollaries (5a), (5b), (5c)

**(5a)** Unconditionally `{1, -1} ⊆ sigma_p(F|l^inf) ∩ S^1`: `1 ∈ mu_1` (cycle `{0}`), `-1 ∈ mu_2` (cycle `{1,2}`), and `{1,2} ⊆ P`.

(⟹) Assume the conjecture: the components are exactly `{0}` and `C1` (component of 1). Any cycle `Z`: if `Z` meets `{0}` then `Z = {0}` (the forward orbit of a cycle point is its cycle, and orbit of `0` is `{0}`); if `Z` meets `{1,2}` then `Z = {1,2}` likewise; otherwise `Z` lies in `{0}` or `C1` as a set, and `Z ⊆ C1` would put two distinct cycles (`Z` and `{1,2}`) in one component, contradicting Lemma 3(a), while `Z ⊆ {0}` forces `Z = {0}`. So `P = {1,2}`. A divergent orbit would lie in a cycle-free component (Lemma 3(c)), distinct from both `{0}` and `C1` (which contain cycles) — a third component, contradiction. Hence by (4), `sigma_p ∩ S^1 = mu_1 ∪ mu_2 = {1,-1}`.

(⟸) Assume `sigma_p ∩ S^1 = {1,-1}`. No divergent orbit exists (else `sigma_p ∩ S^1 = S^1` by (4)). Every `p ∈ P` satisfies `mu_p ⊆ {1,-1}`, and for `p >= 3`, `e^{2πi/p} ∈ mu_p` has strictly positive imaginary part `sin(2π/p) > 0`, so `e^{2πi/p} ∉ {±1}`; hence `P ⊆ {1,2}`. By Lemma 6 the only cycles are `{0}` and `{1,2}`. Since no orbit is divergent, every orbit enters a cycle (definition of divergent), i.e. enters `{0}` or `{1,2}`. Orbits entering `{0}`: `T^j(m) = 0` ⟹ `m = 0` (Section 8). So every `n >= 1` has an orbit entering `{1,2}`, hence `n ∈ C1` (Lemma 1). Thus the components are exactly `{0}` and `C1` (distinct, nonempty): the conjecture holds. ∎

**(5b)** (⟸) If a divergent orbit exists, (4) gives `sigma_p ∩ S^1 = S^1`, which contains non-roots of unity (roots of unity are countable, `S^1` is not; concretely `e^{iθ}` with `θ/2π` irrational). (⟹) If `lambda ∈ sigma_p ∩ S^1` is not a root of unity, take an eigenvector `a != 0` and a component `C` with `a` not identically `0` on `C` (Lemma 2). By (3), `C` cannot contain a cycle; by Lemma 3(c), `C` contains a divergent orbit. ∎

**(5c)** Let `lambda` be a primitive `q`-th root of unity, `q >= 3`, `lambda ∈ sigma_p(F|l^inf)` (automatically `lambda ∈ S^1`). Pick a component `C` carrying the eigenvector as above. If `C` contains a cycle of length `p`, part (1) forces `lambda^p = 1`, so `q = ord(lambda)` divides `p`; hence `p >= q >= 3` and the cycle is neither `{0}` nor `{1,2}`. If `C` is cycle-free, a divergent orbit exists. In the first case the conjecture fails by (5a)(⟹)'s cycle classification (a cycle of length `>= 3` would make `P != {1,2}`, contradicting the structure forced by the conjecture — explicitly, its component is a third component or would give two cycles in one component); in the second case the divergent orbit's cycle-free component is a third component. Either way the Collatz conjecture is false. ∎

## 10. Remarks / edge cases handled

- `n = 0`: component `{0}` is the unique finite component, a `p = 1` cycle component; all lemmas apply verbatim (no infinitude of components was ever used).
- `{1,2}`: `p = 2` cycle component; yields `lambda = ±1` and nothing else on that component.
- `lambda = 0` is never an eigenvalue of `F` (surjectivity of `T`: `n = T(2n)`), so restricting to `S^1` loses nothing near `0`.
- Empty sums / vacuous cases: a certificate always exists (Lemmas 3(b), 1), so `d` is total on its component; walks of length `0` give `d(m) - d(m) = 0`, consistent.
- Component vs forward orbit: all "reachability" steps go through Lemma 1 (grand orbits), never assuming the forward orbit of `m` visits all of `C`.
- The nonexistence directions ((1) only-if, (3)) hold for arbitrary, not necessarily bounded, solutions of the eigen-equation; the existence directions produce eigenvectors of `sup`-norm exactly `1` that are nowhere zero on their component.
- Nothing anywhere assumes the Collatz conjecture; `P` and the divergence predicate are treated as unknowns.
