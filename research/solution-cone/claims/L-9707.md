# L-9707 — Radial growth of indicator series: Abelian bounds, failure of the converse, and the component-partition identity

**Conventions.** S ⊆ Z_{≥1} unless stated otherwise; A_S(x) := #(S ∩ [1,x]) for real x ≥ 1 (so A_S(x) ≤ ⌊x⌋ ≤ x always, and A_S is nondecreasing); f_S(r) := Σ_{n∈S} r^n, which converges for 0 ≤ r < 1 by comparison with the geometric series. "log" is natural log. We use only: ln y ≤ y − 1 (all y > 0); Bernoulli's inequality (1−x)^m ≥ 1 − mx (x ∈ [0,1], m ∈ Z_{≥1}); 1 − x ≤ e^{−x} (all real x); the definition Γ(1+β) = ∫_0^∞ u^β e^{−u} du; geometric series; and rearrangement/grouping of series with nonnegative terms (Tonelli for double series).

## Part 1. Abelian lower bound (Theorem 9707.1)

**Theorem 9707.1.** Let S ⊆ Z_{≥1}, c > 0, 0 < β ≤ 1, x_0 ≥ 1 real, and suppose A_S(x) ≥ c x^β for **all real** x ≥ x_0. Put r_0 := max(1/2, 1 − 1/x_0). Then for all r ∈ [r_0, 1):
f_S(r) ≥ c e^{−3} (1−r)^{−β}.
Since e^{−3} > 1/21, also f_S(r) ≥ (c/21)(1−r)^{−β}.

**Proof.** Fix r ∈ [r_0, 1) and set ε := 1 − r ∈ (0, 1/2], N := ⌈1/ε⌉ ∈ Z_{≥1}.

*Step 1 (the hypothesis applies at N).* Since r ≥ 1 − 1/x_0 we have 1/ε ≥ x_0, hence N ≥ 1/ε ≥ x_0, and the hypothesis gives A_S(N) ≥ c N^β ≥ c (1/ε)^β = c ε^{−β} (using N ≥ 1/ε and β > 0).

*Step 2 (truncate and bound below).* Every n ∈ S with n ≤ N satisfies r^n ≥ r^N (as 0 < r < 1). Dropping the terms n > N (all nonnegative):
f_S(r) ≥ Σ_{n∈S, n≤N} r^n ≥ A_S(N) · r^N ≥ c ε^{−β} r^N.

*Step 3 (r^N ≥ e^{−3}).* Write r^N = exp(−N ln(1/r)). From ln y ≤ y − 1 with y = 1/r: ln(1/r) ≤ (1−r)/r = ε/r ≤ 2ε, because r ≥ 1/2. Also N ≤ 1/ε + 1. Hence
N ln(1/r) ≤ (1/ε + 1)·2ε = 2 + 2ε ≤ 3 (as ε ≤ 1/2),
so r^N ≥ e^{−3}. Combining Steps 2–3 gives f_S(r) ≥ c e^{−3} ε^{−β}. ∎

*Edge cases.* If S is finite or empty, the hypothesis fails for large x, so the theorem is vacuously fine. The proof never used β ≤ 1 (it holds for any β > 0), but since A_S(x) ≤ x, the hypothesis with β > 1 is unsatisfiable for large x anyway; we state 0 < β ≤ 1. Empty truncated sums cannot occur in Step 2 since A_S(N) ≥ c ε^{−β} > 0.

## Part 2. Abelian upper bound, log-free with Gamma constant (Theorem 9707.2)

**Lemma 9707.2a (partial summation).** For any S ⊆ Z_{≥1} and r ∈ [0,1):
f_S(r) = (1−r) Σ_{n=1}^∞ A_S(n) r^n, and both sides are finite.

*Proof.* Finiteness: A_S(n) ≤ n, and Σ n r^n < ∞. Write 1_S(n) = A_S(n) − A_S(n−1) (with A_S(0) := 0). For M ≥ 1:
Σ_{n=1}^M 1_S(n) r^n = Σ_{n=1}^M A_S(n) r^n − Σ_{n=1}^M A_S(n−1) r^n = Σ_{n=1}^M A_S(n) r^n − Σ_{n=1}^{M−1} A_S(n) r^{n+1}
= A_S(M) r^M + Σ_{n=1}^{M−1} A_S(n)(r^n − r^{n+1}).
As M → ∞: A_S(M) r^M ≤ M r^M → 0, and the last sum increases to Σ_{n=1}^∞ A_S(n) r^n (1−r) (nonnegative terms). The left side increases to f_S(r). ∎

**Lemma 9707.2b (unimodal sum–integral comparison).** Let g : (0,∞) → [0,∞) be nondecreasing on (0, m] and nonincreasing on [m, ∞) for some m > 0, with ∫_0^∞ g < ∞. Then
Σ_{n=1}^∞ g(n) ≤ ∫_0^∞ g(x) dx + 2 sup_{x>0} g(x).

*Proof.* Classify each integer n ≥ 1: (a) if n + 1 ≤ m, then g is nondecreasing on [n, n+1] ⊆ (0,m], so g(n) ≤ ∫_n^{n+1} g; (b) if n − 1 ≥ m, then g is nonincreasing on [n−1, n] ⊆ [m,∞), so g(n) ≤ ∫_{n−1}^n g; (c) otherwise m − 1 < n < m + 1, and there are at most two such integers (an open interval of length 2), each with g(n) ≤ sup g. The intervals used in (a) are pairwise disjoint subsets of (0, m], those in (b) pairwise disjoint subsets of [m, ∞); the two families overlap only in the null set {m}. Hence Σ g(n) ≤ ∫_0^m g + ∫_m^∞ g + 2 sup g. ∎

**Theorem 9707.2.** Let S ⊆ Z_{≥1}, C > 0, 0 < β ≤ 1, x_1 ≥ 1 real, and suppose A_S(x) ≤ C x^β for all real x ≥ x_1. Then for **all** r ∈ (0,1):
f_S(r) ≤ [C(Γ(1+β) + 2) + x_1²] (1−r)^{−β}.
If x_1 = 1 the constant is C(Γ(1+β)+2), and the proof shows the leading term is C Γ(1+β)(1−r)^{−β} plus terms of strictly lower order — no logarithm appears.

**Proof.** Fix r ∈ (0,1) and let t := ln(1/r) > 0, m_1 := ⌈x_1⌉ − 1 ≥ 0.

*Step 1 (split via Lemma 2a).* For 1 ≤ n ≤ m_1 use A_S(n) ≤ n; for n > m_1 we have n ≥ ⌈x_1⌉ ≥ x_1, so A_S(n) ≤ C n^β. Bounding the second range by the sum over ALL n ≥ 1 (extra terms nonnegative):
f_S(r) = (1−r) Σ_{n≥1} A_S(n) r^n ≤ (1−r) [ Σ_{n=1}^{m_1} n r^n + C Σ_{n=1}^∞ n^β r^n ].

*Step 2 (initial segment).* Σ_{n=1}^{m_1} n r^n ≤ Σ_{n=1}^{m_1} n = m_1(m_1+1)/2 ≤ x_1(x_1+1)/2 ≤ x_1² (using m_1 ≤ x_1 and x_1 ≥ 1). If x_1 = 1 then m_1 = 0 and this sum is empty (= 0).

*Step 3 (main sum via Lemma 2b).* Apply Lemma 2b to g(x) := x^β e^{−tx} = x^β r^x. Then g′(x) = x^{β−1}e^{−tx}(β − tx), so g is nondecreasing on (0, β/t] and nonincreasing on [β/t, ∞): unimodal with peak m = β/t and sup g = (β/t)^β e^{−β}. The integral is, substituting u = tx,
∫_0^∞ x^β e^{−tx} dx = t^{−1−β} ∫_0^∞ u^β e^{−u} du = Γ(1+β) t^{−1−β}.
Since 0 < β ≤ 1 < e, (β/e)^β ≤ 1, so sup g ≤ t^{−β}. Lemma 2b gives
Σ_{n≥1} n^β r^n ≤ Γ(1+β) t^{−1−β} + 2 t^{−β}.

*Step 4 (convert t to 1−r).* From 1 − x ≤ e^{−x} with x = 1−r: r ≤ e^{−(1−r)}, i.e. t = ln(1/r) ≥ 1−r. Hence t^{−1−β} ≤ (1−r)^{−1−β} and t^{−β} ≤ (1−r)^{−β}. Assembling:
f_S(r) ≤ (1−r) x_1² + C Γ(1+β)(1−r)(1−r)^{−1−β} + 2C(1−r)(1−r)^{−β}
= x_1²(1−r) + C Γ(1+β)(1−r)^{−β} + 2C(1−r)^{1−β}.
Since 0 < β ≤ 1 and 0 < 1−r < 1: (1−r) ≤ 1 ≤ (1−r)^{−β} and (1−r)^{1−β} ≤ 1 ≤ (1−r)^{−β}. Therefore f_S(r) ≤ [C Γ(1+β) + 2C + x_1²](1−r)^{−β}. ∎

*Remark (sharpness of the constant).* The leading constant C Γ(1+β) is the correct Abelian constant: if A_S(x)/x^β → C then f_S(r)(1−r)^β → C Γ(1+β) (classical; not needed and not used here). No log(1/(1−r)) factor occurs anywhere.

## Part 3. Explicit failure of the Tauberian converse without regularity (Theorem 9707.3)

**Construction.** M_1 := 2, M_{k+1} := M_k^4; explicitly M_k = 2^{4^{k−1}} (M_1 = 2, M_2 = 16, M_3 = 65536, …). Let
S* := ∪_{k≥1} B_k, B_k := {n ∈ Z : M_k < n ≤ 2M_k} (so #B_k = M_k),
and r_k := 1 − M_k^{−2}, so (1−r_k)^{−1/2} = M_k and r_k ↑ 1.

The blocks are pairwise disjoint: 2M_k = 2 M_k < M_k^4 = M_{k+1} for M_k ≥ 2. Write A := A_{S*}.

**Basic sums.** For j ≥ 1: M_j / M_{j+1} = M_{j+1}^{−3/4} ≤ 16^{−3/4} = 1/8 (since M_{j+1} ≥ M_2 = 16). Hence Σ_{j=1}^k M_j ≤ M_k Σ_{i≥0} 8^{−i} = (8/7) M_k.  (†)

**(ii) Exponent-1 subsequence.** S* ∩ [1, 2M_k] ⊇ B_k, so A(2M_k) ≥ M_k = (2M_k)/2 for every k ≥ 1. ∎

**(iii) Exponent-1/4 subsequence.** S* ∩ [1, M_{k+1}] = B_1 ∪ … ∪ B_k (block k+1 starts at M_{k+1}+1). By (†): A(M_{k+1}) = Σ_{j≤k} M_j ≤ (8/7)M_k ≤ 2 M_k = 2 M_{k+1}^{1/4}. ∎

**(i) Radial growth of exact order (1−r)^{−1/2} along r_k.** Fix k ≥ 2 (so M_k ≥ 16) and write r = r_k.

*Lower bound.* Keeping only block B_k (all terms nonnegative), and using r^n ≥ r^{2M_k} on B_k:
f_{S*}(r) ≥ M_k · r^{2M_k} = M_k (1 − M_k^{−2})^{2M_k} ≥ M_k (1 − 2M_k · M_k^{−2}) = M_k(1 − 2/M_k) ≥ (7/8) M_k,
by Bernoulli's inequality and M_k ≥ 16. Since M_k = (1−r_k)^{−1/2}: f_{S*}(r_k) ≥ (7/8)(1−r_k)^{−1/2}.

*Upper bound.* Split at M_{k+1}. Blocks j ≤ k: each term r^n ≤ 1, so their contribution is ≤ Σ_{j≤k} M_j ≤ (8/7)M_k by (†). Blocks j ≥ k+1: every element is > M_{k+1}, so their contribution is at most the full geometric tail
Σ_{n > M_{k+1}} r^n = r^{M_{k+1}+1}/(1−r) ≤ M_k² · r^{M_k^4} = M_k² (1 − M_k^{−2})^{M_k^4} ≤ M_k² e^{−M_k^{−2}·M_k^4} = M_k² e^{−M_k²} ≤ 1,
using 1 − x ≤ e^{−x} and the fact that y e^{−y} ≤ e^{−1} < 1 for y = M_k² ≥ 4 (indeed y e^{−y} is decreasing for y ≥ 1 and 4e^{−4} < 1). Hence
f_{S*}(r_k) ≤ (8/7)M_k + 1 ≤ 2 M_k = 2(1−r_k)^{−1/2} (since M_k ≥ 16 gives 1 ≤ (6/7)M_k). ∎

**(iv) Exact oscillation exponents and impossibility of a single power law.**

*limsup = 1.* Upper: A(x) ≤ x gives log A(x)/log x ≤ 1 for x ≥ 3 (and A(3) = 1 > 0 since 3 ∈ B_1; A is ≥ 1 from x = 3 on, so the ratio is defined). Lower: at x = 2M_k, log A(x)/log x ≥ log(x/2)/log x → 1 by (ii).

*liminf ≤ 1/4.* At x = M_{k+1}, by (iii): log A(x)/log x ≤ (log 2 + (1/4)log x)/log x → 1/4.

*liminf ≥ 1/4.* Claim: A(x) ≥ (x/2)^{1/4} for all real x ≥ 4. Let k := max{ j ≥ 1 : M_j < x } (well-defined: M_1 = 2 < 4 ≤ x and M_j → ∞); then M_k < x ≤ M_{k+1}. Case x ≥ 2M_k: A(x) ≥ A(2M_k) ≥ M_k = M_{k+1}^{1/4} ≥ x^{1/4}. Case x < 2M_k: then x < 2M_k forces k ≥ 2 (else x < 4), and A(x) ≥ A(M_k) = Σ_{j≤k−1} M_j ≥ M_{k−1} = M_k^{1/4} > (x/2)^{1/4}. The claim gives log A(x)/log x ≥ (1/4)(1 − log 2 / log x) → 1/4. Hence liminf = 1/4 exactly.

*No single power law.* Suppose 0 < c ≤ C, β ∈ (0,1], X ≥ 1 with c x^β ≤ A(x) ≤ C x^β for all x ≥ X. Upper bound at x = 2M_k (k large): M_k ≤ A(2M_k) ≤ C 2^β M_k^β ≤ 2C M_k^β, so M_k^{1−β} ≤ 2C for all large k, forcing β ≥ 1 (else M_k^{1−β} → ∞), i.e. β = 1. Lower bound at x = M_{k+1} (k large): c M_{k+1} = c M_{k+1}^β ≤ A(M_{k+1}) ≤ 2 M_{k+1}^{1/4}, so M_{k+1}^{3/4} ≤ 2/c for all large k — impossible. Contradiction. In particular β = 1/2 fails in both directions on infinitely many scales. ∎

**Conclusion of Part 3.** S* satisfies (7/8)(1−r_k)^{−1/2} ≤ f_{S*}(r_k) ≤ 2(1−r_k)^{−1/2} on the explicit sequence r_k → 1⁻, yet its counting function oscillates between exponents 1/4 and 1 (exactly, by (iv)). Therefore no Tauberian converse of the form "subsequential radial growth of order (1−r)^{−β} ⇒ counting of order x^β" holds without a regularity hypothesis.

*[LIT-NOTE, not used in any proof]* This does not contradict Karamata's Tauberian theorem, which requires the FULL limit f_S(r)(1−r)^β → L as r → 1⁻ (plus nonnegative coefficients) to conclude A_S(x) ~ L x^β / Γ(1+β); our f_{S*} has different growth on other r-scales, so the full limit fails. Regularity is exactly what is missing.

## Part 4. The component-partition identity and the (conditional) application row

### 4a. Components partition N_0; the exact identity Σ_C f_C = 1/(1−z)

**Lemma 9707.4a-1 (grand orbits = weak components; partition).** Define m ~ n iff T^j(m) = T^k(n) for some j, k ≥ 0. Then ~ is an equivalence relation on N_0, its classes are exactly the weak components of G, and hence the components partition N_0.

*Proof.* Reflexivity (j = k = 0) and symmetry are immediate. Transitivity: if T^j(m) = T^k(n) and T^{j'}(n) = T^{k'}(p), apply T^{j'} to the first equation: T^{j+j'}(m) = T^{j'}(T^k(n)) = T^k(T^{j'}(n)) = T^k(T^{k'}(p)) = T^{k+k'}(p), using that iterates of a single map commute. So ~ is an equivalence relation and its classes partition N_0.

Classes ⊆ components: if m ~ n via T^j(m) = T^k(n) =: w, then the directed paths m → T(m) → … → w and n → … → w make m and n connected in the undirected graph. Components ⊆ classes: if v_0 = m, v_1, …, v_L = n is an undirected path, each edge {v_i, v_{i+1}} satisfies v_{i+1} = T(v_i) or v_i = T(v_{i+1}); either way v_i ~ v_{i+1} (take (j,k) = (1,0) or (0,1)); transitivity gives m ~ n. Hence the classes and the weak components are the same sets. ∎

**Lemma 9707.4a-2 (the component of 0; infinitude of the others).** The component of 0 is exactly {0}; every other component is infinite.

*Proof.* T(m) = 0 with m ∈ N_0 forces m even and m/2 = 0 (the odd case would need 3m + 1 = 0), so m = 0; by induction T^j(m) = 0 ⇒ m = 0. Thus m ~ 0 means T^j(m) = T^k(0) = 0, so m = 0. For n ≥ 1, the component of n contains the pairwise distinct chain n, 2n, 4n, 8n, … (each 2^i n is a T-preimage of 2^{i−1} n, hence ~ n), so it is infinite. (Note: the chain argument fails only at n = 0, and indeed {0} is the unique finite component.) ∎

**Proposition 9707.4a-3 (exact identity).** The set of components of G is at most countable, and for every r ∈ [0,1):
Σ_{C component} f_C(r) = 1/(1−r),
a sum of nonnegative terms (finite or countably infinite, unconditionally convergent). The same identity holds for complex |z| < 1 by absolute convergence.

*Proof.* The components are nonempty pairwise disjoint subsets of the countable set N_0, hence at most countably many; by Lemma 4a-1 they partition N_0. For r ∈ [0,1), the double family {r^n : n ∈ C, C component} has nonnegative terms, so by Tonelli for double series (grouping a nonnegative series by a countable partition of its index set preserves the sum):
Σ_C f_C(r) = Σ_C Σ_{n∈C} r^n = Σ_{n∈N_0} r^n = 1/(1−r).
For complex |z| < 1 the series Σ_{n≥0} z^n converges absolutely, and absolutely convergent series may be grouped by any countable partition of the index set. ∎

### 4b. Unconditional bound on any other component

**Corollary 9707.4b.** f_{{0}}(r) = 1, and for every component D with D ≠ C1 and D ≠ {0}, and every r ∈ [0,1):
0 ≤ f_D(r) ≤ (1−r)^{−1} − f_{C1}(r) − 1.
In particular this bounds the indicator series of any hypothetical cycle-free ("divergent") component, and of any hypothetical additional cycle component. (If no such D exists — i.e. if the Collatz conjecture holds — the statement is vacuously true; nothing here assumes either alternative.)

*Proof.* f_{{0}}(r) = r^0 = 1. C1, {0}, D are three distinct components, hence pairwise disjoint (Lemma 4a-1); drop all other nonnegative terms from Proposition 4a-3: f_{C1}(r) + 1 + f_D(r) ≤ 1/(1−r). ∎

### 4c. Shortcut vs standard map: C1 is the literature's counting set

**Lemma 9707.4c.** Let C_std(n) := 3n+1 (n odd), n/2 (n even), on Z_{≥1}. Then
C1 = { n ∈ Z_{≥1} : ∃ i ≥ 0, C_std^i(n) = 1 }.

*Proof.* First, C1 ⊆ Z_{≥1} since the component of 0 is {0} (Lemma 4a-2) and C1 ≠ {0} (1 ∉ {0}).

*Claim A: m ∈ C1 ⟺ ∃ j ≥ 0 with T^j(m) = 1.* (⇐) T^j(m) = 1 = T^0(1) gives m ~ 1. (⇒) m ~ 1 means T^j(m) = T^k(1) for some j, k; the T-orbit of 1 is 1, 2, 1, 2, …, so T^j(m) ∈ {1,2}; if T^j(m) = 2 then T^{j+1}(m) = 1.

*Claim B: for n ≥ 1, (∃ j : T^j(n) = 1) ⟺ (∃ i : C_std^i(n) = 1).* Note T(n) = C_std(n) if n is even, and T(n) = C_std(C_std(n)) if n is odd (C_std(n) = 3n+1 is even and C_std(3n+1) = (3n+1)/2 = T(n)). Define i_0 := 0 and i_{j+1} := i_j + 1 (T^j(n) even) or i_j + 2 (T^j(n) odd); by induction T^j(n) = C_std^{i_j}(n) for all j ≥ 0. The strictly increasing sequence (i_j) has gaps of size 1 or 2, so every i ≥ 0 is either some i_j, or i = i_j + 1 inside a gap of size 2; in the latter case C_std^i(n) = C_std(T^j(n)) = 3 T^j(n) + 1 with T^j(n) odd ≥ 1, so C_std^i(n) ≥ 4. Hence if C_std^i(n) = 1, then i = i_j for some j and T^j(n) = 1. Conversely T^j(n) = 1 gives C_std^{i_j}(n) = 1. Claims A + B prove the lemma. ∎

## Q-9707 — SEPARATION OPEN PROBLEM (the packet's Q-target; stated, explicitly NOT solved here)

For a component C of G define the radial exponent

## Gap audit (author)

(1) Lemma 9707.2b (unimodal comparison) is the place most likely to hide an off-by-one: the classification of integers into 'left of peak', 'right of peak', and 'near peak' must not double-count integrals and must catch every n. I handled the boundary by taking the near-peak window as the open interval (m−1, m+1) (at most 2 integers) and using disjoint integral intervals inside (0,m] and [m,∞); the constant 2·sup is deliberately generous.
