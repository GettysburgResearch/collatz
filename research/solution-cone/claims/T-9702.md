## Statement

Let T: ℕ₀ → ℕ₀ be the shortcut Collatz map (T(n)=n/2 for n even, T(n)=(3n+1)/2 for n odd), G its functional graph, 𝒞 the set of weak components of G, and for n ∈ ℕ₀ let C(n) ∈ 𝒞 be the component containing n. Let ℓ∞ = ℓ∞(ℕ₀; ℝ) with sup norm ‖·‖∞ and with the weak-* topology σ(ℓ∞, ℓ¹) induced by the pairing ⟨a,x⟩ = Σₙ aₙxₙ with the predual ℓ¹. Let F: ℓ∞ → ℓ∞ be (Fa)ₘ = a_{T(m)}, and K = { a ∈ ℓ∞ : Fa = a and aₙ ≥ 0 for all n ∈ ℕ₀ }. Call a nonzero a ∈ K a spanning vector of an extreme ray if the ray ℝ₊a = {λa : λ ≥ 0} satisfies: for all u, v ∈ K with u + v ∈ ℝ₊a, both u ∈ ℝ₊a and v ∈ ℝ₊a. Then: (1) K is a convex cone that is weak-* closed (hence also norm closed) in ℓ∞. (2) For every component C ∈ 𝒞, the indicator 1_C ∈ K, 1_C ≠ 0, and 1_C spans an extreme ray of K; moreover if 1_C = u + v with u, v ∈ K then u = α·1_C and v = (1−α)·1_C for some α ∈ [0,1]. (3) Every a ∈ K satisfies a = Σ_{C∈𝒞} c_C·1_C, where c_C ∈ [0, ‖a‖∞] is the (well-defined) constant value of a on C, the sum taken over any enumeration of the (at most countable) set 𝒞, converging coefficientwise (for each n exactly one term is nonzero) and also in the weak-* topology; and if a spans an extreme ray of K then exactly one c_C is nonzero, so a = c_C·1_C with c_C > 0 and ℝ₊a = ℝ₊1_C. No topological hypothesis is needed for this converse. Consequently C ↦ ℝ₊1_C is a bijection from 𝒞 onto the set of extreme rays of K. (4) The Collatz conjecture (in the frozen formulation: G has exactly two components, {0} and the component C₁ of 1) holds if and only if K has exactly two extreme rays; unconditionally K has at least the two distinct extreme rays ℝ₊1_{{0}} and ℝ₊1_{C₁}.

## Proof

# T-9702: Extreme rays of the nonnegative fixed cone K = {a ∈ ℓ∞ : Fa = a, a ≥ 0}

**Conventions.** ℓ∞ = bounded real sequences indexed by ℕ₀ = {0,1,2,…}, sup norm ‖a‖∞ = supₙ |aₙ|. Weak-* topology means σ(ℓ∞, ℓ¹) via the standard duality ℓ∞ = (ℓ¹)*, pairing ⟨a,x⟩ = Σₙ aₙxₙ. F is the linear operator (Fa)ₘ = a_{T(m)}; F maps ℓ∞ into ℓ∞ since ‖Fa‖∞ ≤ ‖a‖∞ (re-indexing). "Component" = weak component of the functional graph G (connected component of the undirected version). eₘ ∈ ℓ¹ denotes the m-th standard basis vector; the coordinate functional φₘ(a) = aₘ = ⟨a, eₘ⟩ is weak-* continuous by definition of σ(ℓ∞, ℓ¹).

**Definition (extreme ray).** For nonzero a ∈ K, the ray ℝ₊a = {λa : λ ≥ 0} is an *extreme ray of K* if for all u, v ∈ K with u + v ∈ ℝ₊a we have u, v ∈ ℝ₊a. We say a *spans* an extreme ray. (This is the standard face-of-dimension-one definition for cones; Lemma 0 below reconciles it with the "1_C = u + v" formulation in the task.)

---

## Lemma 0 (reduction to two-term splits of a itself)

*Let a ∈ K, a ≠ 0. Then ℝ₊a is an extreme ray of K if and only if: for all u, v ∈ K with u + v = a, both u, v ∈ ℝ₊a.*

**Proof.** (⇒) Immediate, since a = u + v ∈ ℝ₊a. (⇐) Let u, v ∈ K with u + v = λa, λ ≥ 0.
- If λ > 0: u/λ, v/λ ∈ K (K is a cone, proved in Part 1 below, which does not use this lemma), and u/λ + v/λ = a, so u/λ, v/λ ∈ ℝ₊a, hence u, v ∈ ℝ₊a.
- If λ = 0: u + v = 0 with uₙ ≥ 0 and vₙ ≥ 0 for every n (definition of K) forces uₙ = vₙ = 0 for all n, so u = v = 0 ∈ ℝ₊a. ∎

(The λ = 0 case is exactly where K ⊆ {a : a ≥ 0} is used; for a general cone containing a line this reduction would fail.)

## Lemma 1 (components = grand orbits)

*For m, n ∈ ℕ₀: m and n lie in the same component of G if and only if T^j(m) = T^k(n) for some j, k ≥ 0.*

**Proof.** Define the relation R by m R n ⇔ ∃ j, k ≥ 0 with T^j(m) = T^k(n).

*R is an equivalence relation.* Reflexive: j = k = 0. Symmetric: swap j and k. Transitive: suppose T^j(m) = T^k(n) and T^p(n) = T^q(r). Since T is a single-valued function, iterates commute: T^{j+p}(m) = T^p(T^j(m)) = T^p(T^k(n)) = T^k(T^p(n)) = T^k(T^q(r)) = T^{k+q}(r). So m R r.

*R contains the undirected edge relation.* If {m, n} is an undirected edge of G then n = T(m) or m = T(n); take (j,k) = (1,0) or (0,1).

*Same-component ⊆ R.* The same-component relation is the smallest equivalence relation containing the undirected edge relation (undirected connectivity = reflexive-transitive-symmetric closure of the edge relation); R is an equivalence relation containing the edges, so it contains same-component.

*R ⊆ same-component.* If T^j(m) = T^k(n) =: w, then m, T(m), …, T^j(m) = w is a directed path, hence an undirected path, from m to w; likewise n connects to w; so m and n are in the same component. ∎

## Lemma 2 (fixed vectors = component-constant vectors)

*For a ∈ ℓ∞: Fa = a if and only if a is constant on every component of G.*

**Proof.** (⇒) Fa = a means aₘ = a_{T(m)} for all m; by induction on j, aₘ = a_{T^j(m)} for all j ≥ 0 (base j = 0 trivial; step: a_{T^j(m)} = a_{T(T^j(m))} = a_{T^{j+1}(m)}). If m, n are in the same component, Lemma 1 gives j, k with T^j(m) = T^k(n), so aₘ = a_{T^j(m)} = a_{T^k(n)} = aₙ.

(⇐) For every m, the vertices m and T(m) are joined by an edge, hence lie in the same component, so aₘ = a_{T(m)} = (Fa)ₘ. ∎

**Notation.** 𝒞 is the set of components of G; 𝒞 is a partition of ℕ₀ into nonempty sets, hence 1 ≤ |𝒞| ≤ ℵ₀. For a ∈ ℓ∞ with Fa = a and C ∈ 𝒞, write c_C(a) (or c_C) for the common value of a on C — well defined by Lemma 2 since C ≠ ∅. C(n) denotes the component of n.

## Lemma 3 ({0} is a component, and |𝒞| ≥ 2)

*The singleton {0} is a component of G. The component C₁ of 1 is distinct from {0} (it contains 1, 2, 4, 8, …). Hence |𝒞| ≥ 2.*

**Proof.** Edges incident to 0: the out-edge 0 → T(0) = 0 (a self-loop). In-edges m → 0, i.e. T(m) = 0: if m is even, m/2 = 0 forces m = 0; if m is odd, (3m+1)/2 = 0 forces m = −1/3 ∉ ℕ₀. So the only vertex adjacent to 0 (in the undirected graph) is 0 itself, and {0} is a component. Since 1 ∉ {0}, C₁ ≠ {0}. (For each n ≥ 0, T(2n) = n, so 2n and n are adjacent; hence C₁ ⊇ {1, 2, 4, 8, …} is infinite, though only C₁ ≠ {0} is needed.) ∎

## Part (1): K is a weak-* closed (hence norm closed) convex cone

**Cone and convexity.** 0 ∈ K. Let a, b ∈ K and s, t ≥ 0. Then sa + tb ∈ ℓ∞, (sa + tb)ₙ = s aₙ + t bₙ ≥ 0, and F is linear — indeed (F(sa+tb))ₘ = (sa+tb)_{T(m)} = s a_{T(m)} + t b_{T(m)} = (sFa + tFb)ₘ — so F(sa+tb) = sFa + tFb = sa + tb. Thus sa + tb ∈ K. Taking s + t = 1 gives convexity; taking b = 0 gives the cone property. So K is a convex cone.

**Weak-* closedness.** For each m ∈ ℕ₀, eₘ and eₘ − e_{T(m)} lie in ℓ¹, so the functionals a ↦ ⟨a, eₘ⟩ = aₘ and a ↦ ⟨a, eₘ − e_{T(m)}⟩ = aₘ − a_{T(m)} are weak-* continuous. Then

K = ⋂_{m∈ℕ₀} { a : ⟨a, eₘ⟩ ≥ 0 } ∩ ⋂_{m∈ℕ₀} { a : ⟨a, eₘ − e_{T(m)}⟩ = 0 },

an intersection of preimages of the closed sets [0, ∞) and {0} under weak-* continuous maps. Each such preimage is weak-* closed, and arbitrary intersections of closed sets are closed. Hence K is weak-* closed. Since the norm topology on ℓ∞ is finer than σ(ℓ∞, ℓ¹), every weak-* closed set is norm closed; in particular K is norm closed. ∎ (1)

## Part (2): every component indicator spans an extreme ray

Fix C ∈ 𝒞. **1_C ∈ K, 1_C ≠ 0:** 1_C is bounded (values in {0,1}), nonnegative, and constant on every component (value 1 on C, value 0 on every other component — components are pairwise disjoint), so F1_C = 1_C by Lemma 2; and C ≠ ∅ gives 1_C ≠ 0.

**Extremality.** By Lemma 0 it suffices to treat splits of 1_C itself. Suppose 1_C = u + v with u, v ∈ K. By Lemma 2, u ≡ α := c_C(u) on C and v ≡ β := c_C(v) on C, with α, β ≥ 0 and α + β = 1 (evaluate at any n ∈ C; C ≠ ∅). For any other component C′ ≠ C, evaluating at any n ∈ C′: c_{C′}(u) + c_{C′}(v) = (1_C)ₙ = 0, and both summands are ≥ 0, so c_{C′}(u) = c_{C′}(v) = 0, i.e. u and v vanish off C. Hence u = α·1_C and v = β·1_C = (1−α)·1_C with α ∈ [0,1]. Both lie in ℝ₊1_C, so by Lemma 0, ℝ₊1_C is an extreme ray of K. ∎ (2)

## Part (3): decomposition, and every extreme ray is spanned by some 1_C

**(3a) Decomposition.** Let a ∈ K and for C ∈ 𝒞 set c_C := c_C(a), the constant value of a on C (Lemma 2). Picking any n ∈ C: c_C = aₙ ∈ [0, ‖a‖∞]. Since 𝒞 partitions the countable set ℕ₀ into nonempty sets, 𝒞 is at most countable; fix any enumeration 𝒞 = {C₁, C₂, …} (finite or infinite; every statement below is order-independent).

*Coefficientwise convergence.* Fix n ∈ ℕ₀. In the series Σᵢ c_{Cᵢ}(1_{Cᵢ})ₙ, exactly one index i has n ∈ Cᵢ (𝒞 is a partition), and that term equals c_{C(n)} = aₙ; all other terms are 0. A series with at most one nonzero term converges unconditionally to that term. Hence Σ_{C∈𝒞} c_C·1_C converges coefficientwise to a, in any enumeration order, with all partial sums Sₙ := Σ_{i≤N} c_{Cᵢ}1_{Cᵢ} satisfying 0 ≤ (S_N)ₙ ≤ aₙ ≤ ‖a‖∞ and S_N ∈ K (finite nonnegative combination of elements of K, Part 1).

*Weak-* convergence (bonus, giving convergence in the topology of Part 1).* Let x ∈ ℓ¹ and ε > 0. Absolute convergence of Σ|xₙ| gives a finite set F ⊆ ℕ₀ with Σ_{n∉F}|xₙ| < ε. Each element of F lies in some Cᵢ; F finite gives N₀ with F ⊆ C₁ ∪ … ∪ C_{N₀}. For N ≥ N₀, (a − S_N)ₙ = 0 for every n ∈ C₁ ∪ … ∪ C_N ⊇ F, and 0 ≤ (a − S_N)ₙ ≤ ‖a‖∞ everywhere, so |⟨a − S_N, x⟩| ≤ Σ_{n∉F} ‖a‖∞|xₙ| ≤ ‖a‖∞·ε. Hence S_N → a weak-*. (Norm convergence holds trivially when 𝒞 is finite; it is not claimed in general.)

**(3b) Extreme rays force a single component; no topological hypothesis needed.** Extremality (via Lemma 0) is a purely algebraic condition quantified over *two-term* splits a = u + v in K; the following argument uses only such finite splits, never the infinite series of (3a), so no topological hypothesis is required and the infinite decomposition cannot interfere with extremality.

Let a ∈ K span an extreme ray (in particular a ≠ 0). Suppose, for contradiction, that two distinct components C ≠ C′ have c_C > 0 and c_{C′} > 0. Split

a = c_C·1_C + (a − c_C·1_C).

The first summand is in K (Part 2 and c_C ≥ 0). The second summand b := a − c_C·1_C is in ℓ∞; it is constant on every component (value 0 on C, value c_{C″} on each C″ ≠ C), hence Fb = b by Lemma 2; and its values are 0 and c_{C″} ≥ 0, so b ≥ 0. Thus b ∈ K. By Lemma 0, c_C·1_C = λa for some λ ≥ 0. Since c_C > 0 and C ≠ ∅, c_C·1_C ≠ 0, so λ > 0 and a = (c_C/λ)·1_C. But then a vanishes at every n ∈ C′ (C, C′ disjoint), while aₙ = c_{C′} > 0 for n ∈ C′ — contradiction.

Hence at most one component has c_C > 0. If all c_C = 0 then a = 0 by (3a) (coefficientwise: aₙ = c_{C(n)} = 0), contradicting a ≠ 0. So exactly one component C has c_C > 0, and (3a) gives a = c_C·1_C, so ℝ₊a = ℝ₊1_C (as c_C > 0). ∎ (3)

**Bijection.** By (2) and (3b), C ↦ ℝ₊1_C maps 𝒞 *onto* the set of extreme rays of K. It is injective: if C ≠ C′ and ℝ₊1_C = ℝ₊1_{C′}, then 1_C = λ·1_{C′} for some λ > 0 (both nonzero); evaluating at any n ∈ C (disjoint from C′) gives 1 = λ·0 = 0, absurd. So C ↦ ℝ₊1_C is a bijection from 𝒞 onto the extreme rays of K; in particular the number of extreme rays of K equals |𝒞|.

## Part (4): Corollary

By the bijection, K has exactly two extreme rays ⇔ |𝒞| = 2. By the frozen formulation, the Collatz conjecture is exactly the statement that G has two components, {0} and C₁. By Lemma 3, {0} and C₁ are always two distinct components; hence |𝒞| = 2 ⇔ 𝒞 = {{0}, C₁} ⇔ the Collatz conjecture. Therefore:

**The Collatz conjecture holds if and only if K has exactly two extreme rays.**

Unconditionally, K always has at least the two distinct extreme rays ℝ₊1_{{0}} = ℝ₊e₀ and ℝ₊1_{C₁} (Lemma 3 + Part 2 + injectivity). ∎ (4)
