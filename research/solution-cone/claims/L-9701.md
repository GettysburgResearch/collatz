## Statement

Let T: N_0 -> N_0 be the shortcut Collatz map (T(n)=n/2 for n even, T(n)=(3n+1)/2 for n odd), and let F be the coefficient pullback operator (Fa)_m = a_{T(m)} on complex sequences a = (a_n)_{n>=0}. Then: (0) [Lemma] for every n in N_0, T^{-1}(n) = {2n, (2n-1)/3} with exactly 2 elements if n ≡ 2 (mod 3), and T^{-1}(n) = {2n} with exactly 1 element otherwise (in particular T^{-1}(0) = {0}); moreover T(m) <= 2m for ALL m >= 0, with equality iff m in {0,1}. (1) If limsup_n |a_n|^{1/n} <= 1 (i.e. f(z) = sum a_n z^n is holomorphic on the open unit disk D), then limsup_m |(Fa)_m|^{1/m} <= 1, so Ff is holomorphic on D; hence F: H(D) -> H(D) is well defined. (2) F maps l^infinity(N_0) into itself and is an isometry: ||Fa||_infinity = ||a||_infinity for every a in l^infinity; in particular the operator norm ||F||_{l^infinity -> l^infinity} = 1. (3) F maps l^2(N_0) into itself with ||Fa||_2^2 = sum_n c_n |a_n|^2 where c_n = #T^{-1}(n) in {1,2}; consequently ||F||_{l^2 -> l^2} = sqrt(2), and the norm is EXACTLY attained: ||F e_n||_2 = sqrt(2) for every n ≡ 2 (mod 3) (e.g. n = 2), while ||F e_n||_2 = 1 otherwise. (4) The Hilbert-space adjoint of F on l^2(N_0) (inner product <a,b> = sum_n a_n conj(b_n)) is the pushforward/transfer operator F* given by (F* b)_n = sum_{m: T(m)=n} b_m (a sum of at most 2 terms). (5) F: H(D) -> H(D) is continuous for the compact-open topology: for every 0 < r < 1 and every s with sqrt(r) < s < 1, sup_{|z|<=r} |(Ff)(z)| <= (1 - r/s^2)^{-1} sup_{|z|<=s} |f(z)| for all f in H(D).

## Proof

# L-9701: Well-definedness and exact norms of the coefficient pullback operator F

**Setting.** $T:\mathbb N_0\to\mathbb N_0$, $T(n)=n/2$ ($n$ even), $T(n)=(3n+1)/2$ ($n$ odd); so $T(0)=0$, $T(1)=2$, $T(2)=1$. For a complex sequence $a=(a_n)_{n\ge 0}$, define $(Fa)_m = a_{T(m)}$ for all $m\ge 0$. $F$ is linear (immediate from the definition, coordinatewise). We identify sequences with formal power series $f(z)=\sum_{n\ge0}a_nz^n$; the coefficients of a function holomorphic on a disk about $0$ are unique (Taylor), so $F$ is unambiguous on holomorphic functions.

---

## Part 0 (Lemma: preimage structure and the growth bound). 

**(0a) Preimage count.** Fix $n\in\mathbb N_0$ and suppose $T(m)=n$.
- If $m$ is even, $m/2=n$, i.e. $m=2n$. Conversely $T(2n)=n$ always ($2n$ is even). So $2n\in T^{-1}(n)$ for **every** $n\ge 0$, including $n=0$ (where $T(0)=0$).
- If $m$ is odd, $(3m+1)/2=n$, i.e. $m=(2n-1)/3$. This is a nonnegative integer iff $3\mid 2n-1$ iff $2n\equiv 1\pmod 3$ iff $n\equiv 2\pmod 3$ (since $2$ is invertible mod $3$ with inverse $2$). When $n=3k+2$ we get $m=(6k+3)/3=2k+1$, which is indeed odd and $\ge 1\ge 0$, and $T(2k+1)=(6k+4)/2=3k+2=n$, confirming it is a genuine preimage. When $n\equiv 2\pmod 3$, the two preimages are distinct: $2n$ is even, $(2n-1)/3$ is odd.
- $n=0$: $n\equiv 0\pmod 3$, so the only preimage is $2\cdot 0=0$: $T^{-1}(0)=\{0\}$, count $1$. (The candidate odd preimage would be $-1/3\notin\mathbb N_0$.)

Hence $c_n:=\#T^{-1}(n)=2$ if $n\equiv2\pmod3$ and $c_n=1$ otherwise; always $1\le c_n\le 2$, and the fibers $\{T^{-1}(n)\}_{n\ge0}$ **partition** $\mathbb N_0$ because $T$ is a totally defined function ($m$ lies in exactly the fiber over $n=T(m)$). Also $T$ is **surjective** ($T(2n)=n$).

**(0b) Growth bound: $T(m)\le 2m$ for all $m\ge 0$.** If $m$ is even, $T(m)=m/2\le 2m$ (as $m\ge0$). If $m$ is odd (so $m\ge1$), $T(m)=(3m+1)/2\le 2m \iff 3m+1\le 4m \iff m\ge 1$, true. The edge case $m=0$: $T(0)=0=2\cdot0$, so the inequality holds there too, with equality; equality also holds at $m=1$ ($T(1)=2$) and at no even $m\ge 2$ ($m/2<2m$) and no odd $m\ge3$ ($m>1$ strict). So $T(m)\le 2m$ holds for **all** $m\ge0$. $\square$

## Part 1 (F preserves holomorphy on the unit disk).

**Claim.** If $\limsup_{n\to\infty}|a_n|^{1/n}\le 1$ then $\limsup_{m\to\infty}|(Fa)_m|^{1/m}\le 1$.

**Proof.** Write $b_m=(Fa)_m=a_{T(m)}$. Let $\varepsilon>0$. Since $\limsup|a_n|^{1/n}\le1$, there is $N_\varepsilon$ with $|a_n|\le(1+\varepsilon)^n$ for all $n\ge N_\varepsilon$; setting $C:=\max\big(1,\max_{0\le n<N_\varepsilon}|a_n|\big)<\infty$ (a max over a finite, possibly empty, set — take $C=1$ if $N_\varepsilon=0$) gives
$$|a_n|\le C(1+\varepsilon)^n\quad\text{for all }n\ge0.$$
By Part 0b, $0\le T(m)\le 2m$, and $(1+\varepsilon)^x$ is increasing in $x\ge 0$, so for every $m\ge0$
$$|b_m|=|a_{T(m)}|\le C(1+\varepsilon)^{T(m)}\le C(1+\varepsilon)^{2m}.$$
Hence for $m\ge1$, $|b_m|^{1/m}\le C^{1/m}(1+\varepsilon)^2\to(1+\varepsilon)^2$ as $m\to\infty$, so $\limsup_m|b_m|^{1/m}\le(1+\varepsilon)^2$. Since $\varepsilon>0$ was arbitrary, $\limsup_m|b_m|^{1/m}\le1$. By Cauchy–Hadamard, the radius of convergence of $\sum b_mz^m$ is $\ge1$, i.e. $Ff\in H(\mathbb D)$. (The $m=0$ term never affects the $\limsup$.) $\square$

## Part 2 ($\ell^\infty$: F is an isometry; operator norm exactly 1).

Let $a\in\ell^\infty$. For every $m$, $|(Fa)_m|=|a_{T(m)}|\le\sup_n|a_n|=\|a\|_\infty$, so $\|Fa\|_\infty\le\|a\|_\infty$ and $\|F\|_{\ell^\infty\to\ell^\infty}\le1$.

Conversely, $T$ is surjective (Part 0a: $T(2n)=n$), so $\{T(m):m\ge0\}=\mathbb N_0$ and
$$\|Fa\|_\infty=\sup_m|a_{T(m)}|=\sup_{n\in T(\mathbb N_0)}|a_n|=\sup_n|a_n|=\|a\|_\infty.$$
Thus $F$ is a linear isometry of $\ell^\infty$ into itself; in particular $\|F\|_{\ell^\infty\to\ell^\infty}=1$ exactly (attained e.g. at the constant sequence $a\equiv1$, for which $Fa=a$). $\square$

---

## Part 3 ($\ell^2$: exact norm $\sqrt2$).

Let $a\in\ell^2(\mathbb N_0)$. All terms below are nonnegative, so all rearrangements of these sums are legitimate (Tonelli for counting measure on a countable set). Grouping the index $m$ by the value $n=T(m)$ — the fibers $T^{-1}(n)$ partition $\mathbb N_0$ (Part 0a) —
$$\|Fa\|_2^2=\sum_{m\ge0}|a_{T(m)}|^2=\sum_{n\ge0}\ \sum_{m\in T^{-1}(n)}|a_n|^2=\sum_{n\ge0}c_n|a_n|^2,\qquad c_n=\#T^{-1}(n)\in\{1,2\}.$$
**Upper bound.** $c_n\le2$ gives $\|Fa\|_2^2\le2\|a\|_2^2$, so $Fa\in\ell^2$ and $\|F\|_{\ell^2\to\ell^2}\le\sqrt2$.

**Basis vectors and exact attainment.** For the standard basis vector $e_n$, $(Fe_n)_m=(e_n)_{T(m)}=1$ iff $T(m)=n$, so $Fe_n=\sum_{m\in T^{-1}(n)}e_m$ and
$$\|Fe_n\|_2^2=c_n=\begin{cases}2,& n\equiv2\pmod3,\\ 1,&\text{otherwise.}\end{cases}$$
Concretely $Fe_2=e_1+e_4$ (since $T^{-1}(2)=\{1,4\}$: $T(1)=2$, $T(4)=2$), so $\|Fe_2\|_2=\sqrt2=\sqrt2\,\|e_2\|_2$. Hence the norm is **exactly attained** at $e_2$ (indeed at every $e_n$ with $n\equiv2\pmod 3$), not merely in a limit, and
$$\|F\|_{\ell^2\to\ell^2}=\sqrt2.\qquad\square$$

## Part 4 (adjoint = transfer/pushforward operator).

Define $S:\ell^2\to\ell^2$ by $(Sb)_n=\sum_{m\in T^{-1}(n)}b_m$ (a sum of $c_n\le2$ terms, so pointwise well defined).

**$S$ maps $\ell^2$ to $\ell^2$.** By Cauchy–Schwarz on each fiber, $|(Sb)_n|^2\le c_n\sum_{m\in T^{-1}(n)}|b_m|^2\le 2\sum_{m\in T^{-1}(n)}|b_m|^2$; summing over $n$ and using that the fibers partition $\mathbb N_0$: $\|Sb\|_2^2\le2\|b\|_2^2<\infty$.

**$S=F^*$.** Fix $a,b\in\ell^2$. By Part 3, $Fa\in\ell^2$, so by Cauchy–Schwarz the double-indexed family $\big(a_{T(m)}\overline{b_m}\big)_{m\ge0}$ is absolutely summable: $\sum_m|a_{T(m)}||b_m|\le\|Fa\|_2\|b\|_2<\infty$. Absolute summability over a countable index set permits grouping the sum by fibers (Fubini for counting measure / rearrangement of absolutely convergent series):
$$\langle Fa,b\rangle=\sum_{m\ge0}a_{T(m)}\overline{b_m}=\sum_{n\ge0}\sum_{m\in T^{-1}(n)}a_n\overline{b_m}=\sum_{n\ge0}a_n\overline{\sum_{m\in T^{-1}(n)}b_m}=\sum_{n\ge0}a_n\overline{(Sb)_n}=\langle a,Sb\rangle,$$
where the inner sums are finite (at most 2 terms) and the outer regrouped series is again absolutely convergent (it is a grouping of an absolutely convergent series). Since $F$ is bounded (Part 3) and $\langle Fa,b\rangle=\langle a,Sb\rangle$ holds for all $a,b\in\ell^2$, uniqueness of the Hilbert-space adjoint (if $\langle a,Sb\rangle=\langle a,S'b\rangle$ for all $a$, take $a=Sb-S'b$) gives $F^*=S$. This is precisely the pushforward/transfer operator of $T$ on coefficients. (Consistency check: $\|F^*\|=\|F\|=\sqrt2$, matching $\|Sb\|_2^2\le2\|b\|_2^2$ and $\|Se_1\|$... e.g. $S(e_1+e_4)=2e_2$, $\|2e_2\|/\|e_1+e_4\|=2/\sqrt2=\sqrt2$.) $\square$

## Part 5 (continuity on $H(\mathbb D)$ with the compact-open topology).

$H(\mathbb D)$ carries the compact-open topology, generated by the seminorms $p_r(f)=\sup_{|z|\le r}|f(z)|$, $0<r<1$ (every compact $K\subset\mathbb D$ is contained in some closed disk $\{|z|\le r\}$, $r<1$, so these seminorms suffice; $H(\mathbb D)$ is a Fréchet space). By Part 1, $F:H(\mathbb D)\to H(\mathbb D)$ is well defined. Since $F$ is linear, continuity follows if for every $r\in(0,1)$ there exist $s\in(0,1)$ and $C<\infty$ with $p_r(Ff)\le C\,p_s(f)$ for all $f$.

Fix $0<r<1$ and choose any $s$ with $\sqrt r<s<1$ (possible since $\sqrt r<1$). Let $f(z)=\sum a_nz^n\in H(\mathbb D)$. The **Cauchy coefficient estimates** on the circle $|z|=s$ (contained in $\mathbb D$) give
$$|a_n|\le \frac{p_s(f)}{s^n}\quad\text{for all }n\ge0.$$
Since $0<s<1$, the map $x\mapsto s^{-x}$ is increasing in $x\ge0$; with $0\le T(m)\le2m$ (Part 0b, valid for all $m\ge0$ including $m=0$),
$$|a_{T(m)}|\le p_s(f)\,s^{-T(m)}\le p_s(f)\,s^{-2m}.$$
Therefore, for $|z|\le r$,
$$|(Ff)(z)|\le\sum_{m\ge0}|a_{T(m)}|\,r^m\le p_s(f)\sum_{m\ge0}\Big(\frac{r}{s^2}\Big)^m=\frac{p_s(f)}{1-r/s^2},$$
the geometric series converging because $r/s^2<1$ by the choice of $s$. Hence
$$p_r(Ff)\le\Big(1-\frac r{s^2}\Big)^{-1}p_s(f),$$
a seminorm bound with constant $C(r,s)=(1-r/s^2)^{-1}<\infty$. Thus $F$ is continuous $H(\mathbb D)\to H(\mathbb D)$. (Sequential form: if $f_k\to f$ uniformly on compacts, then $p_s(f_k-f)\to0$ for each $s<1$, hence $p_r(F f_k - Ff)=p_r(F(f_k-f))\to0$ for each $r<1$ by linearity, i.e. $Ff_k\to Ff$ uniformly on compacts.) $\square$

## Edge cases handled
- $m=0$ / $n=0$: $T(0)=0$; $T^{-1}(0)=\{0\}$ (count 1, consistent with $0\not\equiv2\bmod3$); $T(m)\le 2m$ holds at $m=0$ with equality.
- The $\{1,2\}$ cycle: $T^{-1}(2)=\{1,4\}$ is the smallest two-element fiber and provides exact attainment of $\sqrt2$ in Part 3; $Fe_2=e_1+e_4$, $F^*(e_1+e_4)=2e_2$.
- Empty sums: in Part 1, the finite max defining $C$ may be over an empty set ($N_\varepsilon=0$); handled by $C\ge1$.
- No statement anywhere depends on the Collatz conjecture, on the number of components, or on the distinction between components and forward orbits; only the totally-defined-function property, surjectivity, the fiber counts, and $T(m)\le2m$ are used.

## Gap audit (author)

Three points most likely to harbor an error, honestly assessed: (1) Part 4's rearrangement step: I regroup sum_m a_{T(m)} conj(b_m) by fibers, justified by absolute summability (Cauchy-Schwarz with ||Fa||_2 < infinity from Part 3). If Part 3's norm identity were wrong the absolute-summability premise would fail; but Part 3 itself uses only Tonelli for nonnegative terms, which needs no integrability hypothesis, so the chain is sound. Residual risk: conflating 'grouping an absolutely convergent series' (always valid) with a general rearrangement — grouping by a partition of the index set is exactly the valid case. (2) Part 0a completeness: I claim the two preimages 2n and (2n-1)/3 exhaust T^{-1}(n). The case split even/odd on the preimage m is exhaustive, and distinctness is by parity; the residue computation 2n ≡ 1 (mod 3) iff n ≡ 2 (mod 3) is elementary but is the single arithmetic fact everything with the constant sqrt(2) rests on — it is machine-checked in the snippet for n < 60 on both T and the 3n-1 control U (where the residue class correctly shifts to n ≡ 1 mod 3). (3) Part 5's seminorm sufficiency: continuity of a linear map between the metrizable spaces requires the bound p_r(Ff) <= C p_s(f) for each r with SOME s; I use s in (sqrt(r),1), which exists for every r in (0,1). One could worry that the compact-open topology needs general compacta, not just closed disks, but every compact subset of D lies in a closed disk of radius r < 1, so the disk seminorms generate the topology. Minor caveat, not a gap: Part 1 shows F preserves 'radius >= 1'; it does NOT claim F preserves the exact radius of convergence for functions holomorphic on larger disks (composition with T(m) <= 2m can shrink a radius R > 1 toward R^{1/2}-type behavior); the statement is scoped to the unit disk only.

## Caveats

Part (2) sharpens to: F is an isometry on l^infinity (via surjectivity of T), which implies norm exactly 1. Part (1) is scoped to the unit disk: F maps H(D) to H(D); it does not preserve larger radii of convergence.
