## Boundary-handling decisions (all of them, explicitly)

1. **Truncation.** `G_N(f)` has vertex set `[lo, N]` (`lo=1` for U since U acts on positive integers; `lo=0` for T) and directed edge `m -> f(m)` present **iff `f(m) <= N`**. No edge is ever imposed with an endpoint outside the window.
2. **Truncated pushforward.** `(P_f x)_n = sum_{m<=N, f(m)=n} x_m` for `n <= N`. This makes `P_f` **column-substochastic**: the column of any *sink* (a vertex `v <= N` with `f(v) > N`) is identically zero, so its mass leaks out of the system. No renormalization is applied. Consequence used below: leakage can only shrink the fixed space, never enlarge it.
3. **Sink / interior / escaping.** `v` is a *sink* iff `f(v) > N`. `v` is *interior* iff its **truncated** forward orbit `v, f(v), f^2(v), ...` reaches a cycle lying fully inside the truncation before ever exceeding `N` (computed as `reach[v] != -1`); otherwise `v` is *escaping*. This is the honest definition of interior support: "interior-supported" solution = solution vanishing off the interior set... and we in fact prove the stronger statement that the relevant solution spaces vanish on entire components.
4. **Eigen-equations.** The Koopman-direction equation `a_{f(m)} = lambda * a_m` is imposed **only on edges that exist in the truncation** (both endpoints `<= N`). A sink contributes no outgoing equation. This is the only honest choice; it is also the source of the boundary artifacts quantified below.
5. **Artifact components.** A truncated weak component containing no directed cycle is an *artifact* of truncation. We verify for each one: it is cycle-free, every vertex is escaping, and it has **exactly one** sink (a truncated functional-graph component has exactly one cycle or one sink). We then verify by **untruncated** iteration (cap 10^6 steps, never reached) that its vertices' true orbits reach a known cycle, i.e. each artifact merges into a cycle component in the full graph.
6. **Empirical boundary census (a finding, not an assumption).** At `N = 50000`, both U and T have exactly **8333 sinks** — precisely the odd `v >= 33335` (for U: odd `v > (2N+1)/3`; for T: odd `v > (2N-1)/3`; even vertices are never sinks since `v/2 <= N`). All 8333 lie in artifact components; the three U-cycle components and T's comp(1) contain **zero sinks**, i.e. they are orbit-closed in the truncation. In particular "interior" is the *whole* `{5,7,10}` component at this `N`, which makes the part-(3) negative result stronger than requested.

## The two small mathematical lemmas the code leans on (stated, since they justify reading the outputs as exact dimensions)

**Lemma A (truncated fixed space).** In `G_N(f)`, any directed cycle of the preimage relation is a directed cycle of `f`; the enumerated cycles are the only ones (machine-checked). A cycle vertex `c` is a preimage only of its cycle successor `f(c)` (machine-checked), so preimages of non-cycle vertices are non-cycle; the preimage relation on non-cycle vertices is therefore a finite DAG. For `x = P_f x`, each source of that DAG satisfies `x_v = (empty sum) = 0`, and by topological induction every non-cycle coordinate is forced to 0 (implemented as exact Kahn propagation; the code asserts *all* non-cycle coordinates get forced). On each cycle the equation then reads `x_{f(c)} = x_c`, i.e. `x` is constant per cycle. Hence `dim ker(P_f - I) =` (number of in-truncation cycles), with basis the cycle indicators. Since these have pairwise disjoint supports, every nonnegative fixed vector is a nonnegative combination, and the extremal nonneg l1-normalized fixed vectors are exactly the uniform cycle measures. (Cross-checked independently by dense exact Gaussian elimination over Q at `N0 = 200`.)

**Lemma B (edge systems).** For `lambda` invertible, each edge relation `a_{f(m)} = lambda a_m` is a bijection between the two endpoint values, so on a connected edge-set the solution space has dimension 0 or 1: fix a BFS spanning tree from a root `r` and every solution satisfies `a_v = lambda^{k(v)} a_r` with `k` the tree-assigned exponent; each non-tree edge is either consistent with `k` (no constraint) or forces `(lambda^p - lambda^q) a_r = 0` with `lambda^p != lambda^q`, which in the integral domains Z[omega], Z[i] forces `a_r = 0`, hence `a ≡ 0` on the component. Consistency of `k` on **every** edge (machine-checked edge-by-edge) conversely exhibits an everywhere-nonzero exact eigenvector. (Cross-checked independently by dense exact elimination over Q(omega) and Q(i) at `N = 500`.)

class DSU:
    __slots__ = ("p",)

    def find(self, x):
        p = self.p
        while p[x] != x:
            p[x] = p[p[x]]
            x = p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)

    """Truncated functional graph on [lo, n_max], edges m -> f(m) present iff f(m) <= n_max.
