## Statement

Let T: N₀ → N₀ be the shortcut Collatz map (T(n)=n/2 for n even, T(n)=(3n+1)/2 for n odd), G the functional graph with edge m → T(m) for every m ∈ N₀, and let 𝒦 denote the set of weak components of G (connected components of the undirected version). Let 𝕂 ∈ {ℝ, ℂ}, let ℓ∞ = ℓ∞(N₀; 𝕂), and let F: ℓ∞ → ℓ∞ be (Fa)ₘ = a_{T(m)}. Then:

(1) For every a ∈ 𝕂^{N₀} (in particular every a ∈ ℓ∞): Fa = a ⇔ a is constant on every weak component of G.

(2) Fix(F|ℓ∞) := {a ∈ ℓ∞ : Fa = a} is a closed subspace of ℓ∞, and the map Φ: ℓ∞(𝒦) → Fix(F|ℓ∞), (Φb)ₙ = b(C(n)) (C(n) = the component containing n), is a linear isometric isomorphism. Consequently: if 𝒦 is finite then dim Fix(F|ℓ∞) = |𝒦| (Hamel dimension); if 𝒦 is infinite then dim Fix(F|ℓ∞) is infinite. In particular, for every integer d ≥ 0: dim Fix(F|ℓ∞) = d ⇔ |𝒦| = d.

(3) {0} ∈ 𝒦 (indeed T⁻¹(0) = {0}), the 2-cycle {1,2} lies in a single component C1 ≠ {0}, and the following are equivalent: (i) the Collatz conjecture (𝒦 = {{0}, C1}, i.e. G has exactly two weak components); (ii) dim Fix(F|ℓ∞) = 2; (iii) Fix(F|ℓ∞) = span{1_{{0}}, 1_{C1}}.

(4) Let X ⊆ 𝕂^{N₀} be any linear subspace of sequences and define Fix(F|X) := {a ∈ X : a∘T = a} (pointwise; F need not map X into X) and 𝒦_X := {C ∈ 𝒦 : 1_C ∈ X}. Then: (4a) [Sufficiency of faithfulness] If X satisfies condition (a): 1_C ∈ X for every C ∈ 𝒦 ("X is faithful"), then (i), (ii'), (iii') are equivalent, where (ii') dim Fix(F|X) = 2 and (iii') Fix(F|X) = span{1_{{0}}, 1_{C1}}. (4b) [What Fix counts without faithfulness] If X satisfies condition (b): a ∈ X, C ∈ 𝒦 ⇒ 1_C · a ∈ X (closure under multiplication by component indicators), then every a ∈ Fix(F|X) vanishes identically on every component not in 𝒦_X; if 𝒦_X is finite then Fix(F|X) = span{1_C : C ∈ 𝒦_X} and dim Fix(F|X) = |𝒦_X| (including the empty case 𝒦_X = ∅, Fix(F|X) = {0}); if 𝒦_X is infinite then dim Fix(F|X) is infinite. Hence under (b): dim Fix(F|X) = 2 ⇔ |𝒦_X| = 2, so the operator count sees |𝒦| (and the equivalence with the conjecture holds) exactly when 𝒦_X = 𝒦, i.e. exactly under the faithfulness condition (a). (4c) [ℓ² instance] X = ℓ² satisfies (b) but not (a): every component other than {0} is infinite, 1_{C1} ∉ ℓ², 𝒦_{ℓ²} = {{0}}, and unconditionally dim Fix(F|ℓ²) = 1, Fix(F|ℓ²) = span{1_{{0}}}. Thus the component-counting identity dim Fix(F|X) = |𝒦| fails for X = ℓ² (1 vs ≥ 2), independently of the truth of the conjecture.

## Proof

# T-9701. Fixed-point/component theorem for the pullback operator F on ℓ∞

Throughout, N₀ = {0,1,2,…}, 𝕂 ∈ {ℝ, ℂ} (every argument works verbatim for either scalar field), T is the shortcut Collatz map T(n) = n/2 (n even), (3n+1)/2 (n odd), and G is the functional graph on N₀ with the directed edge m → T(m) for every m. All sums written as Σ_C over components are pointwise-finite (at each n ∈ N₀ exactly one summand is nonzero), so no convergence issues arise; the empty sum is 0.

**Definition (grand-orbit relation).** For m, n ∈ N₀ write m ~ n iff there exist j, k ≥ 0 with T^j(m) = T^k(n).

## Lemma 0 (weak components = grand orbits)

*The relation ~ is an equivalence relation on N₀, and its classes are exactly the weak components of G (the connected components of the undirected version of G). In particular the components partition N₀ and each is nonempty.*

**Proof.** *Equivalence:* Reflexive (j = k = 0). Symmetric (swap j, k). Transitive: if T^j(m) = T^k(n) and T^p(n) = T^q(r), apply T^p to the first identity and T^k to the second: T^{j+p}(m) = T^{k+p}(n) = T^k(T^p(n)) = T^k(T^q(r)) = T^{k+q}(r), so m ~ r. (Here we use that T is a globally defined function, so T^i is defined for all i ≥ 0 — this is where out-degree exactly 1 enters.)

*Classes = weak components:* Let ≈ be undirected connectivity: m ≈ n iff there is a finite sequence m = v₀, v₁, …, v_r = n with, for each i, either v_{i+1} = T(v_i) or v_i = T(v_{i+1}). By definition ≈ is the smallest equivalence relation containing every edge pair (m, T(m)).

(⊆): ~ contains every edge pair: m ~ T(m) via T¹(m) = T⁰(T(m)). Since ~ is an equivalence relation containing all edge pairs and ≈ is the smallest such, ≈ ⊆ ~.

(⊇): If T^j(m) = T^k(n), then m ≈ T(m) ≈ … ≈ T^j(m) = T^k(n) ≈ … ≈ n (each step is an edge). So ~ ⊆ ≈.

Hence ~ = ≈ and the weak components are the ~-classes; equivalence classes are nonempty and partition N₀. ∎

Write 𝒦 for the set of components, C(n) for the component of n, and 1_C ∈ 𝕂^{N₀} for the indicator of C.

## Lemma 1 (bookkeeping: the {0} component, the {1,2} cycle, infinitude)

*(i) T⁻¹(0) = {0}; hence C(0) = {0}, i.e. {0} ∈ 𝒦.
(ii) 1 ~ 2, so 1 and 2 lie in one component C1 := C(1) = C(2), and C1 ≠ {0}; thus |𝒦| ≥ 2 always.
(iii) Every component other than {0} is infinite.*

**Proof.** (i) T(0) = 0/2 = 0. If T(m) = 0 with m even, then m/2 = 0, so m = 0. If m is odd, T(m) = 0 would force (3m+1)/2 = 0, i.e. m = −1/3 ∉ N₀ (the putative odd preimage (2·0−1)/3 = −1/3 of 0 is not a nonnegative integer). So T⁻¹(0) = {0}.

Now let n ~ 0, say T^j(n) = T^k(0) = 0 (since T(0) = 0, T^k(0) = 0 for all k). If j = 0 then n = 0. If j ≥ 1, then T(T^{j−1}(n)) = 0, so T^{j−1}(n) ∈ T⁻¹(0) = {0}; descending induction on j gives T^0(n) = n = 0. Hence C(0) = {0}.

(ii) T(1) = (3·1+1)/2 = 2 and T(2) = 1, so 1 ~ 2 (edge pairs), and C(1) = C(2) =: C1. Since C(0) = {0} and 1 ≠ 0, we get 1 ∉ C(0), so C1 ≠ {0}. The components {0} and C1 are distinct, whence |𝒦| ≥ 2 unconditionally.

(iii) Let C ∈ 𝒦, C ≠ {0}, and pick n ∈ C; by (i), n ≥ 1. For every k ≥ 1, T(2^k n) = 2^{k−1} n (2^k n is even and positive), so by induction T^k(2^k n) = n, giving 2^k n ~ n, i.e. 2^k n ∈ C. Since n ≥ 1, the numbers n, 2n, 4n, … are pairwise distinct, so C is infinite. ∎

## Part (1): Fix(F) = component-constant sequences (pointwise; no norm needed)

**Proposition 1.** *For a ∈ 𝕂^{N₀}: a∘T = a (i.e. a_{T(m)} = a_m for all m ∈ N₀) ⇔ a is constant on every component of G.*

**Proof.** (⇐) Suppose a is constant on every component. For any m, the pair (m, T(m)) lies in one component (Lemma 0, edge pair), so a_{T(m)} = a_m. Hence Fa = a.

(⇒) Suppose a_{T(m)} = a_m for all m. By induction on j, a_{T^j(m)} = a_m for all m and all j ≥ 0 (constancy along forward orbits). Now let m, n be in the same component. By Lemma 0 this means precisely m ~ n: there are j, k ≥ 0 with T^j(m) = T^k(n). Then

  a_m = a_{T^j(m)} = a_{T^k(n)} = a_n.

This is the forward-orbit → grand-orbit propagation: forward-orbit constancy alone only relates a point to its images, but any two points of a weak component have a *common* forward image (Lemma 0), and equality at that common point transfers between the two orbits. So a is constant on each component. ∎

Applied inside ℓ∞ (note (Fa)ₘ = a_{T(m)} takes values among the values of a, so ‖Fa‖∞ ≤ ‖a‖∞; F is linear and bounded with ‖F‖ = 1 since F𝟙 = 𝟙), Proposition 1 gives: Fix(F|ℓ∞) = {a ∈ ℓ∞ : a constant on every component}. Being the kernel of the bounded operator F − I, it is a closed subspace.

## Part (2): Fix(F|ℓ∞) ≅ ℓ∞(𝒦) isometrically

**Theorem 2.** *Define Φ: ℓ∞(𝒦) → 𝕂^{N₀} by (Φb)ₙ = b(C(n)); equivalently Φb = Σ_{C∈𝒦} b(C)·1_C (pointwise-finite sum: components partition N₀, so at each n exactly one term survives). Then Φ is a linear isometric isomorphism from ℓ∞(𝒦) onto Fix(F|ℓ∞). Consequently:*
- *if 𝒦 is finite, dim Fix(F|ℓ∞) = |𝒦| (Hamel dimension);*
- *if 𝒦 is infinite, dim Fix(F|ℓ∞) is infinite;*
- *for every integer d ≥ 0: dim Fix(F|ℓ∞) = d ⇔ |𝒦| = d.*

**Proof.** *Well-defined into Fix:* Φb is constant on each component by construction (value b(C) on C), so Φb ∈ Fix by Proposition 1 (⇐), and ‖Φb‖∞ = sup_{n∈N₀} |b(C(n))| < ∞, so Φb ∈ ℓ∞. *Linear:* immediate pointwise.

*Isometric:* The map n ↦ C(n) is surjective onto 𝒦 (every component is nonempty), so sup_{n} |b(C(n))| = sup_{C∈𝒦} |b(C)|, i.e. ‖Φb‖∞ = ‖b‖∞. In particular Φ is injective.

*Surjective onto Fix(F|ℓ∞):* Let a ∈ Fix(F|ℓ∞). By Proposition 1 (⇒), a is constant on each component; define b(C) to be the common value of a on C (well-defined: C nonempty; unambiguous: a constant on C). Then |b(C)| ≤ ‖a‖∞ for all C, so b ∈ ℓ∞(𝒦), and (Φb)ₙ = b(C(n)) = aₙ, i.e. Φb = a.

So Φ is a linear isometric bijection ℓ∞(𝒦) → Fix(F|ℓ∞); in particular a vector-space isomorphism, so the Hamel dimensions coincide: dim Fix(F|ℓ∞) = dim ℓ∞(𝒦).

*Dimension:* If |𝒦| = d < ∞, then ℓ∞(𝒦) = 𝕂^𝒦 has dimension d. If 𝒦 is infinite, then for every finite subset {C₁,…,C_r} ⊆ 𝒦 the indicators δ_{C₁},…,δ_{C_r} ∈ ℓ∞(𝒦) are linearly independent (evaluate a vanishing combination at each Cᵢ), so dim ℓ∞(𝒦) ≥ r for all r, hence infinite. The biconditional "dim = d ⇔ |𝒦| = d" for finite d follows: if |𝒦| = d then dim = d; conversely if dim = d < ∞ then 𝒦 cannot be infinite (else dim infinite) and |𝒦| = dim = d.

**Cardinality caveat (stated for honesty):** for *infinite* 𝒦 we claim only "dim is infinite", not the cardinal equality dim = |𝒦|; indeed the Hamel dimension of ℓ∞ over a countably infinite index set is 2^{ℵ₀} ≠ ℵ₀. Nothing in Parts (3)–(4) uses more than the finite-d biconditional. ∎

## Part (3): equivalence with the Collatz conjecture

Per the frozen definition, the **Collatz conjecture** is the statement: G has exactly two weak components, namely {0} and C1; equivalently (Lemma 1 guarantees {0}, C1 ∈ 𝒦 are distinct) 𝒦 = {{0}, C1}.

**Theorem 3.** *The following are equivalent:*
1. *(i) The Collatz conjecture: 𝒦 = {{0}, C1}.*
2. *(ii) dim Fix(F|ℓ∞) = 2.*
3. *(iii) Fix(F|ℓ∞) = span{1_{{0}}, 1_{C1}}.*

*Moreover, unconditionally, dim Fix(F|ℓ∞) ≥ 2 and span{1_{{0}}, 1_{C1}} ⊆ Fix(F|ℓ∞).*

**Proof.** First the unconditional facts. By Lemma 1, {0} and C1 are distinct components; 1_{{0}} and 1_{C1} are bounded (values in {0,1}) and constant on every component (value 1 on their own component, 0 on every other — Lemma 0 partition), hence lie in Fix(F|ℓ∞) by Proposition 1. They are linearly independent: if α·1_{{0}} + β·1_{C1} = 0, evaluating at n = 0 gives α = 0 (1_{C1}(0) = 0 since 0 ∉ C1) and at n = 1 gives β = 0. So dim Fix ≥ 2.

(i) ⇒ (iii): Assume 𝒦 = {{0}, C1}. Let a ∈ Fix(F|ℓ∞). By Proposition 1, a is constant on each component, say value α on {0} and β on C1. Since {0} ∪ C1 = N₀ (the two components partition N₀ under (i)), the pointwise identity a = α·1_{{0}} + β·1_{C1} holds. So Fix ⊆ span{1_{{0}}, 1_{C1}}; the reverse inclusion is the unconditional fact above.

(iii) ⇒ (ii): span{1_{{0}}, 1_{C1}} has dimension exactly 2 by the independence shown above.

(ii) ⇒ (i): Suppose the conjecture fails. Since |𝒦| ≥ 2 always (Lemma 1), failure means |𝒦| ≥ 3: there is a component C ∈ 𝒦 with C ∉ {{0}, C1}. Then 1_C ∈ ℓ∞ is fixed (Proposition 1, as above), and 1_{{0}}, 1_{C1}, 1_C are linearly independent: they have pairwise disjoint nonempty supports (distinct components are disjoint, all nonempty), so evaluating a vanishing linear combination at a point of each support kills each coefficient in turn. Hence dim Fix(F|ℓ∞) ≥ 3 ≠ 2. Contrapositive gives (ii) ⇒ (i). ∎

(Equivalently via Theorem 2: dim Fix = 2 ⇔ |𝒦| = 2 ⇔ 𝒦 = {{0}, C1}, the last step because {0}, C1 are always two distinct members of 𝒦.)

## Part (4): general sequence spaces X and the faithfulness condition

Let X ⊆ 𝕂^{N₀} be any linear subspace. Define Fix(F|X) := {a ∈ X : a∘T = a}. This is well-defined even if F does not map X into X: the condition a∘T = a is pointwise, and when it holds, Fa = a ∈ X anyway. Set

  𝒦_X := {C ∈ 𝒦 : 1_C ∈ X}.

By Proposition 1 (which was proved for arbitrary a ∈ 𝕂^{N₀}, with no norm):

  Fix(F|X) = {a ∈ X : a is constant on every component}.  (★)

**Theorem 4a (sufficiency of faithfulness).** *Assume condition (a): 𝒦_X = 𝒦, i.e. 1_C ∈ X for every component C. Then the following are equivalent: (i) the Collatz conjecture; (ii') dim Fix(F|X) = 2; (iii') Fix(F|X) = span{1_{{0}}, 1_{C1}}. (Condition (b) is NOT needed here.)*

**Proof.** By (a), 1_{{0}}, 1_{C1} ∈ X, and by (★) they lie in Fix(F|X); they are independent (as in Theorem 3), so dim Fix(F|X) ≥ 2 and span{1_{{0}},1_{C1}} ⊆ Fix(F|X), both unconditionally under (a).

(i) ⇒ (iii'): if 𝒦 = {{0}, C1}, any a ∈ Fix(F|X) is constant on both components by (★), and since they partition N₀, a = α·1_{{0}} + β·1_{C1} as a pointwise identity in 𝕂^{N₀} (whether the two indicators individually lie in X is irrelevant for this identity, though under (a) they do). So Fix(F|X) ⊆ span, and equality follows.

(iii') ⇒ (ii'): the span has dimension 2 (independence as before).

(ii') ⇒ (i): if the conjecture fails there is a third component C; by (a), 1_C ∈ X, it is fixed by (★), and 1_{{0}}, 1_{C1}, 1_C are independent (disjoint nonempty supports), so dim Fix(F|X) ≥ 3. ∎

**Theorem 4b (what dim Fix counts when faithfulness may fail).** *Assume condition (b): a ∈ X and C ∈ 𝒦 imply 1_C·a ∈ X (pointwise product). Then:*
1. *If a ∈ Fix(F|X) and a does not vanish identically on some component C, then 1_C ∈ X (so C ∈ 𝒦_X). Consequently every a ∈ Fix(F|X) vanishes identically on every component outside 𝒦_X.*
2. *If 𝒦_X is finite, then Fix(F|X) = span{1_C : C ∈ 𝒦_X} and dim Fix(F|X) = |𝒦_X|. (Empty case: 𝒦_X = ∅ gives Fix(F|X) = {0}, the empty span, dimension 0.)*
3. *If 𝒦_X is infinite, dim Fix(F|X) is infinite.*
4. *Hence, under (b): dim Fix(F|X) = 2 ⇔ |𝒦_X| = 2. The operator-theoretic count equals the true component count |𝒦| for every possible value — and the equivalence with the conjecture in the form of Theorem 4a holds — precisely when 𝒦_X = 𝒦, i.e. precisely under the faithfulness condition (a). We record (a) as the **faithfulness condition** for the solution-cone program.*

**Proof.** 1. Let a ∈ Fix(F|X) and let λ ≠ 0 be the constant value of a on C ((★) gives constancy). Then 1_C·a = λ·1_C pointwise, and 1_C·a ∈ X by (b), so 1_C = λ⁻¹·(1_C·a) ∈ X since X is a linear subspace. Contrapositive: C ∉ 𝒦_X forces a|_C ≡ 0.

2. (⊇) For C ∈ 𝒦_X, 1_C ∈ X and 1_C ∈ Fix(F|X) by (★); take spans (Fix(F|X) is a subspace: intersection of X with the pointwise-linear condition set). (⊆) Let a ∈ Fix(F|X) with 𝒦_X = {C₁,…,C_r} finite (possibly r = 0). By part 1, a vanishes off C₁ ∪ … ∪ C_r; by (★), a ≡ λᵢ on Cᵢ; since components are pairwise disjoint, a = Σᵢ λᵢ·1_{Cᵢ} pointwise (for r = 0: a = 0, the empty sum). Dimension: the 1_{Cᵢ} are independent (disjoint nonempty supports), so dim = r = |𝒦_X|.

3. If 𝒦_X is infinite, for every r choose r distinct members; their indicators lie in Fix(F|X) and are independent, so dim ≥ r for all r.

4. By 2–3, dim Fix(F|X) = 2 ⇔ |𝒦_X| = 2 (if 𝒦_X infinite, dim is infinite ≠ 2; if finite, dim = |𝒦_X|). Since |𝒦| ≥ 2 always with {0}, C1 ∈ 𝒦 (Lemma 1), the count |𝒦_X| agrees with |𝒦| in all cases iff 𝒦_X = 𝒦: indeed 𝒦_X ⊆ 𝒦 always, and if some C ∈ 𝒦 \ 𝒦_X then the count under (b) provably ignores C (parts 1–2), so a strict inclusion makes dim Fix(F|X) = |𝒦_X| < |𝒦| whenever 𝒦 is finite, and more generally makes the fixed space blind to C. ∎

**Scope remark (honest formalization of "the equivalence needs (a)").** The literal universal statement "for every X violating (a), the biconditional 'Collatz ⇔ dim Fix(F|X) = 2' is false" is not provable without settling the conjecture (e.g. for X = span{1_{C1}} the biconditional becomes 'Collatz ⇔ False', whose truth value is the negation of the open conjecture). What is proved, and what the program needs, is Theorem 4b: under (b), dim Fix(F|X) computes |𝒦_X|, not |𝒦|; it computes |𝒦| for all configurations of components iff (a) holds. That is the precise sense in which every component indicator must lie in X — the faithfulness condition.

**Theorem 4c (ℓ² instance).** *X = ℓ² = ℓ²(N₀; 𝕂) satisfies (b) but not (a); 𝒦_{ℓ²} = {{0}}; and unconditionally Fix(F|ℓ²) = span{1_{{0}}} = {a : aₙ = 0 for n ≥ 1}, so dim Fix(F|ℓ²) = 1. In particular the identity dim Fix(F|X) = |𝒦| fails for X = ℓ² (1 < 2 ≤ |𝒦|), regardless of the truth of the conjecture.*

**Proof.** (b) holds: |1_C(n)·aₙ| ≤ |aₙ|, so 1_C·a ∈ ℓ². Faithfulness fails: by Lemma 1(iii), C1 is infinite (it contains 1, 2, 4, 8, …), so Σ_{n∈C1} 1² = ∞ and 1_{C1} ∉ ℓ²; likewise every component other than {0} is infinite, so 𝒦_{ℓ²} = {{0}} (and 1_{{0}} ∈ ℓ², so it is nonempty — this is the sense in which ℓ² satisfies the letter of "contains component indicators" only for the trivial component). Now let a ∈ Fix(F|ℓ²). By (★), a is constant, say value λ_C, on each component C. If C ≠ {0}, C is infinite and Σ_{n∈C} |λ_C|² ≤ ‖a‖₂² < ∞ forces λ_C = 0. So a vanishes on N₀ \ {0}, i.e. a = a₀·1_{{0}}. Conversely 1_{{0}} ∈ ℓ² is fixed by (★). Hence Fix(F|ℓ²) = span{1_{{0}}}, dimension 1, unconditionally. Since |𝒦| ≥ 2 always (Lemma 1), dim Fix(F|ℓ²) ≠ |𝒦| always. (This is Theorem 4b in action: dim = |𝒦_{ℓ²}| = 1.) ∎
