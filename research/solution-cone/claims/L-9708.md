## Statement

Let T: N_0 → N_0 be the shortcut Collatz map T(n) = n/2 (n even), (3n+1)/2 (n odd); let G be its functional graph on N_0 and let "component" mean weak (undirected) component of G. Let F be the coefficient pullback operator on complex sequences, (Fa)_m = a_{T(m)} for all m ∈ N_0. A weight is any function w: N_0 → (0,∞); l2(w) := { a ∈ C^{N_0} : ||a||_w^2 := Σ_{n≥0} w_n |a_n|^2 < ∞ }, and Fix(F | l2(w)) := { a ∈ l2(w) : (Fa)_m = a_m for all m } (a pointwise equation; no boundedness of F is assumed or needed). For a component C write W(C) := Σ_{n∈C} w_n ∈ (0,∞] and 1_C for its indicator sequence. Then, unconditionally (no case assumes the Collatz conjecture, the finiteness of the set of cycles, or the absence of divergent orbits):

(1) [Component sizes] {0} is a component of G and |{0}| = 1; every component other than {0} is infinite (for n ≥ 1 the chain n, 2n, 4n, 8n, … is injective and lies in the component of n). Moreover T(N) ⊆ N for N = {1,2,3,…}, and the components of the restricted graph G|_N are exactly the components of G other than {0}.

(2)+(4) [Space-selection theorem — exact faithfulness criterion] For every weight w: the family { 1_C : C a component with W(C) < ∞ } is a pairwise-orthogonal family of nonzero vectors in l2(w) with ||1_C||_w^2 = W(C), and
   Fix(F | l2(w)) = closed linear span of { 1_C : W(C) < ∞ }
                  = { Σ_C c_C 1_C (pointwise) : c_C ∈ C, c_C = 0 whenever W(C) = ∞, Σ_C |c_C|^2 W(C) < ∞ }.
In particular, for each individual component C: 1_C ∈ l2(w) iff W(C) < ∞, and then 1_C ∈ Fix(F | l2(w)); and dim Fix(F | l2(w)) = #{ C : W(C) < ∞ } (Hilbert dimension; both sides at most countable).

(3)+(5a) [Unweighted no-go, CORRECTED on N_0] For w ≡ 1: W(C) = |C|, so by (1), Fix(F) ∩ l2(N_0) = C·e_0 (e_0 = 1_{{0}}, the constant power series 1 in the H2 picture) and dim ker(F − I)|_{l2(N_0)} = 1 — NOT 0: the target's literal statement "Fix(F) ∩ l2 = {0}" fails on N_0 by exactly this one-dimensional trivial summand. On l2(N) (positive integers) the literal statement holds: Fix(F | l2(N)) = {0}, dim = 0. In both formulations the dimension is the same whether or not the Collatz conjecture holds, whether or not divergent orbits exist, and for any number of infinite components: unweighted l2/H2 is blind to every infinite component (in particular to C1 and to any hypothetical extra cyclic or acyclic component). Hence no argument whose conclusion factors through dim ker(F − I) on unweighted l2/H2 can detect the component structure.

(4') [Sharp blindness condition] If W(C) = ∞ for every infinite component C — in particular if for each infinite component C there exist δ_C > 0 and an infinite S_C ⊆ C with w_n ≥ δ_C on S_C — then Fix(F | l2(w)) = C·e_0 on N_0 (minimal possible: e_0 ∈ Fix(F | l2(w)) for EVERY weight, since W({0}) = w_0 < ∞ always; consequently the target's condition "W(C) = ∞ for every component" is unsatisfiable on N_0 and the implication "⇒ Fix = 0" is vacuously true there). On N the condition is substantive: if W(C) = ∞ for every component of G|_N then Fix(F | l2_N(w)) = {0}.

(5b) [Faithful spaces] If Σ_{n∈N_0} w_n < ∞ (e.g. w_n = (n+1)^{−s} with s > 1, where Σ_{n≥0}(n+1)^{−s} = ζ(s) < ∞; convergence over each component follows since every component is a subset of N_0 and the terms are positive), then W(C) < ∞ for every component, every indicator 1_C lies in Fix(F | l2(w)), and dim Fix(F | l2(w)) = #components of G. Unconditionally dim ≥ 2 (the components {0} and C1 are distinct), and: Collatz conjecture ⇔ dim Fix(F | l2(w)) = 2. Additionally (Remark) F is a bounded operator on l2(w) for w_n = (n+1)^{−s} with ||F||^2 ≤ 1 + 3^s, and on unweighted l2 with ||F||^2 ≤ 2.

The corrected statements (proved below) are: every component **other than {0}** is infinite; Fix(F) ∩ l2(N_0) = C·e_0 (dimension 1); and on l2(N) (positive integers, which T preserves) the target's literal statements do hold verbatim. ## 0. Conventions

- N_0 = {0,1,2,…}, N = {1,2,3,…}. T(n) = n/2 (n even), (3n+1)/2 (n odd). G is the functional graph on N_0 with one directed edge m → T(m) per vertex m; a **component** is a connected component of the undirected version of G. Components partition N_0 and every component is nonempty.
- F acts on all of C^{N_0} by (Fa)_m := a_{T(m)}; it is linear. A **weight** is any w: N_0 → (0,∞) (strict positivity is required throughout and is used in Lemma 3 and in step (e) of Theorem 4). l2(w) := { a : ||a||_w^2 := Σ_n w_n|a_n|^2 < ∞ } with inner product ⟨a,b⟩_w = Σ_n w_n a_n \overline{b_n}; for w ≡ 1 this is unweighted l2, identified with the Hardy space H2 via a ↔ Σ a_n z^n. For a component C, W(C) := Σ_{n∈C} w_n ∈ (0,∞] (a sum of positive terms over a nonempty countable set; W(C) > 0 always, so 1_C ≠ 0 in l2(w) whenever it lies there).
- **Fix(F | l2(w)) := { a ∈ l2(w) : (Fa)_m = a_m for every m ∈ N_0 }.** This is a pointwise equation between sequences; it is well defined whether or not F maps l2(w) into itself, so no boundedness hypothesis is ever needed for the fixed-point statements. (Boundedness is addressed separately in Remark 8.)

## Lemma 0 (Grand orbits = components)

Define m ~ n iff T^j(m) = T^k(n) for some j, k ≥ 0. Then ~ is an equivalence relation on N_0 and its classes are exactly the components of G.

*Proof.* Reflexive and symmetric are immediate. Transitive: if T^j(m) = T^k(n) and T^p(n) = T^q(r), apply T^p to the first equation and T^k to the second: T^{j+p}(m) = T^{k+p}(n) = T^{k+q}(r). So ~ is an equivalence.

Each edge {m, T(m)} joins ~-related vertices (j = 1, k = 0), so any undirected path stays inside one ~-class; by induction on path length, every component is contained in a ~-class. Conversely, if T^j(m) = T^k(n), then the directed paths m → T(m) → … → T^j(m) and n → T(n) → … → T^k(n) concatenate (reversing the second) into an undirected path from m to n, so each ~-class is contained in a component. Hence classes = components. ∎

## Lemma 1 (Component sizes — part (1))

(a) T^j(m) = 0 for some j ≥ 0 implies m = 0; consequently the component of 0 is exactly {0}.
(b) For every n ≥ 1, the numbers n, 2n, 4n, 8n, … are pairwise distinct and all lie in the component of n; hence every component other than {0} is infinite.
(c) T(N) ⊆ N, and the components of the restricted functional graph G|_N (vertex set N, edges n → T(n)) are exactly the components of G other than {0}.

*Proof.* (a) First, T(m) = 0 forces m = 0: if m is even, m/2 = 0 gives m = 0; if m is odd, (3m+1)/2 = 0 would give 3m + 1 = 0, impossible for m ∈ N_0 since 3m + 1 ≥ 1. By induction on j, T^j(m) = 0 forces T^{j−1}(m) = 0 (apply the j = 1 case to T^{j−1}(m))… down to m = 0; the base case j = 0 is trivial. Now by Lemma 0, m is in the component of 0 iff T^j(m) = T^k(0) = 0 for some j, k, iff m = 0. So the component of 0 is {0}, of size 1.

(b) Fix n ≥ 1. For every k ≥ 0, 2^{k+1}n is even (it is ≥ 2 and divisible by 2), so T(2^{k+1}n) = 2^k n; iterating, T^k(2^k n) = n, so 2^k n ~ n (Lemma 0) and 2^k n lies in the component of n. Distinctness: 2^j n = 2^k n with n ≥ 1 implies 2^j = 2^k, so j = k. Hence the component of n is infinite. Any component C ≠ {0}: since components partition N_0 and {0} is a full component by (a), C ⊆ N; C is nonempty, so pick n ∈ C, n ≥ 1; C = (component of n) is infinite.

(c) For n ≥ 1: if n is even then T(n) = n/2 ≥ 1; if n is odd then T(n) = (3n+1)/2 ≥ 2. So T(N) ⊆ N and G|_N is a well-defined functional graph. G|_N is obtained from G by deleting the vertex 0 and the loop edge 0 → 0. By (a), no edge of G joins 0 to any vertex of N (the only edge out of 0 is the loop, and no n ≥ 1 has T(n) = 0), so deleting 0 leaves every other component untouched: undirected paths between vertices of N in G never pass through 0. Hence components of G|_N = components of G minus the component {0}, all infinite by (b). Lemma 0 holds verbatim for G|_N with the same proof. ∎

**Edge case check.** The 2-cycle {1,2}: T(1) = 2, T(2) = 1; the component C1 of 1 contains 1, 2, 4, 8, … and is infinite by (b) — nothing special is needed. Nothing in (a)–(c) restricts the number of components, the number of cycles, or whether acyclic (divergent-orbit) components exist.

## Lemma 2 (Fixed sequences are exactly the component-constant sequences — restatement of T-9701 part (1), proved here so L-9708 is self-contained)

*Statement (as used from T-9701(1)):* For a ∈ C^{N_0}: Fa = a (pointwise) **iff** a is constant on every component of G, i.e. a_m = a_n whenever m, n lie in the same component.

*Proof.* (⇐) If a is component-constant: for every m, the vertices m and T(m) are adjacent, hence in the same component, so (Fa)_m = a_{T(m)} = a_m.

(⇒) Suppose a_{T(m)} = a_m for all m. Iterating, a_{T^j(m)} = a_m for all j ≥ 0 (induction on j: a_{T^j(m)} = a_{T(T^{j−1}(m))} = a_{T^{j−1}(m)} = a_m). Now let m, n be in the same component; by Lemma 0 there are j, k with T^j(m) = T^k(n). Then a_m = a_{T^j(m)} = a_{T^k(n)} = a_n. ∎

**Component vs. forward orbit.** The one-step identity gives constancy on forward orbits for free; the content of (⇒) is constancy on the whole *grand orbit* (weak component), and that is exactly what Lemma 0 supplies: two elements of a component need not be on each other's forward orbits, but their forward orbits merge.

## Lemma 3 (l2(w) kills constants on heavy sets)

Let S ⊆ N_0 with Σ_{n∈S} w_n = ∞, and let a ∈ l2(w) with a_n = c for all n ∈ S. Then c = 0.

*Proof.* |c|^2 Σ_{n∈S} w_n = Σ_{n∈S} w_n |a_n|^2 ≤ ||a||_w^2 < ∞. If c ≠ 0 the left side is ∞, a contradiction. (If S is infinite this uses w_n > 0 only through the hypothesis; empty or finite S never satisfies the hypothesis since w is finite-valued, so no vacuity issue arises where the lemma is applied.) ∎

## Theorem 4 (Space-selection theorem — parts (2) and (4), the exact faithfulness criterion)

Let w be any weight. Write 𝒞 for the (at most countable) set of components of G and 𝒞_fin := { C ∈ 𝒞 : W(C) < ∞ }. Then:

(a) { 1_C : C ∈ 𝒞_fin } is a pairwise-orthogonal family of nonzero vectors in l2(w), with ||1_C||_w^2 = W(C); moreover for any component C, 1_C ∈ l2(w) iff W(C) < ∞.
(b) Fix(F | l2(w)) = { a : a_n = c_{C(n)} for a family (c_C)_{C∈𝒞} with c_C = 0 whenever W(C) = ∞ and Σ_{C∈𝒞} |c_C|^2 W(C) < ∞ }, where C(n) denotes the component containing n.
(c) Fix(F | l2(w)) equals the closed linear span of { 1_C : C ∈ 𝒞_fin } in l2(w).
(d) dim Fix(F | l2(w)) = #𝒞_fin (Hilbert dimension = cardinality of the orthonormal basis { W(C)^{−1/2} 1_C : C ∈ 𝒞_fin }; both are at most countably infinite).

*Proof.*

(a) Distinct components are disjoint, so for C ≠ C′ the products 1_C(n)1_{C′}(n) vanish identically and ⟨1_C, 1_{C′}⟩_w = 0. Also ||1_C||_w^2 = Σ_{n∈C} w_n = W(C), which is finite iff W(C) < ∞ and is > 0 since C ≠ ∅ and w > 0. So 1_C ∈ l2(w) iff W(C) < ∞, and then it is a nonzero vector.

(b) (⊆) Let a ∈ Fix(F | l2(w)). By Lemma 2, a is component-constant; let c_C be its constant value on C, so a_n = c_{C(n)} for all n. Since 𝒞 partitions N_0 and all terms below are nonnegative, regrouping the sum over the partition is legitimate (Tonelli for counting measure / the standard theory of unordered sums of nonnegative terms):
  ||a||_w^2 = Σ_{n∈N_0} w_n |a_n|^2 = Σ_{C∈𝒞} Σ_{n∈C} w_n |c_C|^2 = Σ_{C∈𝒞} |c_C|^2 W(C) < ∞,
with the convention that for W(C) = ∞ the inner sum Σ_{n∈C} w_n|c_C|^2 equals |c_C|^2·∞ if c_C ≠ 0 and equals Σ_{n∈C} 0 = 0 if c_C = 0 — no 0·∞ ambiguity, because the inner sum is computed termwise. Finiteness forces, for each C with W(C) = ∞, that c_C = 0 (this is Lemma 3 with S = C). So a has the stated form.

(⊇) Conversely, given (c_C) with c_C = 0 whenever W(C) = ∞ and M := Σ_C |c_C|^2 W(C) < ∞, define a_n := c_{C(n)}. The same regrouping (nonnegative terms, termwise inner sums, so components with c_C = 0 contribute exactly 0 even when W(C) = ∞) gives ||a||_w^2 = M < ∞, so a ∈ l2(w); a is component-constant by construction, hence Fa = a by Lemma 2. So a ∈ Fix(F | l2(w)).

(c) Recall the standard Hilbert-space fact: if { v_i }_{i∈I} is an orthogonal family of nonzero vectors in a Hilbert space H, then the closed span of { v_i } equals { Σ_i c_i v_i : Σ_i |c_i|^2 ||v_i||^2 < ∞ }, the (unconditionally convergent) sums. Apply this in H = l2(w) with the family { 1_C : C ∈ 𝒞_fin } from (a): the closed span is 𝒮 := { Σ_{C∈𝒞_fin} c_C 1_C (norm-convergent sum) : Σ_{C∈𝒞_fin} |c_C|^2 W(C) < ∞ }.

It remains to identify 𝒮 with the set in (b), i.e. to check the norm-convergent sum agrees with the pointwise formula. Let b = Σ_{C∈𝒞_fin} c_C 1_C in the norm sense and let a be the pointwise sequence a_n = c_{C(n)} (with c_C := 0 for C ∉ 𝒞_fin), which lies in l2(w) by (b). The partial sums b_K := Σ_{C∈K} c_C 1_C over finite K ⊆ 𝒞_fin converge to b in ||·||_w. Norm convergence in l2(w) implies pointwise convergence, because w_n > 0 gives |x_n − y_n|^2 ≤ ||x − y||_w^2 / w_n for every n. For each fixed n, (b_K)_n is eventually c_{C(n)} if C(n) ∈ 𝒞_fin (once K ∋ C(n)) and is 0 = c_{C(n)} for all K if C(n) ∉ 𝒞_fin. Hence b = a pointwise. So 𝒮 equals the set in (b), which is Fix(F | l2(w)) by (b).

(d) By (c), { W(C)^{−1/2} 1_C : C ∈ 𝒞_fin } is an orthonormal basis of the Hilbert space Fix(F | l2(w)) (a closed subspace of l2(w)), so its Hilbert dimension is #𝒞_fin. Since 𝒞 partitions the countable set N_0 into nonempty pieces, #𝒞 ≤ ℵ_0, so both cardinals are at most countable. ∎

**Faithfulness criterion (exact form of part (4)).** For each component C: 1_C ∈ Fix(F | l2(w)) iff W(C) < ∞; and Fix(F | l2(w)) is spanned (in the closed sense) by exactly those indicators. The space l2(w) "sees" precisely the components of finite w-mass.

## Corollary 5 (Unweighted blindness — parts (2), (3), (5), corrected)

(a) On N_0 with w ≡ 1: W(C) = |C|, and by Lemma 1 the unique finite component is {0}. Hence
  **Fix(F) ∩ l2(N_0) = C·1_{{0}} = C·e_0, and dim ker(F − I)|_{l2(N_0)} = 1.**
In the H2 picture, the only F-fixed H2 functions are the constant functions c·1 (the series of 1_{{0}} is z^0 = 1). In particular the target's literal "Fix(F) ∩ l2 = {0}" is false on N_0; the correct kernel is this trivial line.

(b) On N with w ≡ 1: by Lemma 1(c) every component of G|_N is infinite, and Lemmas 0–3 and Theorem 4 hold verbatim for G|_N (same proofs; T maps N to N). So 𝒞_fin = ∅ and
  **Fix(F | l2(N)) = {0}, dim = 0** — the target's literal statement, valid on the positive integers.

(c) **Blindness.** In both (a) and (b) the dimension was computed using only Lemma 1, which is unconditional. Therefore dim ker(F − I) on unweighted l2 equals 1 (on N_0), resp. 0 (on N), **regardless of** whether the Collatz conjecture holds, how many components G has, whether extra cycles exist, or whether divergent (acyclic tree) components exist: every infinite component contributes 0 to the kernel no matter what. Since (conjecture) ⇔ (𝒞 = { {0}, C1 }) ⇔ (exactly one infinite component), and the kernel dimension is constant across all these scenarios, no quantity that factors through dim ker(F − I) on unweighted l2/H2 can distinguish them. This is the precise scope of the no-go: it concerns ker(F − I) (and hence any Fredholm-index or dimension-count argument whose input is that kernel); it does not by itself assert that all spectral data of F on l2 is component-blind. Any attack needing the indicators 1_C inside the space must move to a faithful weighted l2(w) (forward reference: L-9705) or to a non-Hilbert sequence space that contains bounded sequences.

## Corollary 6 (Sharp blindness condition — part (4), first half)

(a) If W(C) = ∞ for **every infinite** component C of G, then Fix(F | l2(w)) = C·e_0 on N_0. This is the minimum possible for any weight, because W({0}) = w_0 < ∞ **always** (w_0 is a positive real), so e_0 ∈ Fix(F | l2(w)) for every weight w. Consequently: the target's hypothesis "W(C) = ∞ for every component" is **unsatisfiable on N_0**, and the target's implication "⇒ Fix = 0" is vacuously true there; the substantive statement is the one just given.
(b) On N: if W(C) = ∞ for every component of G|_N, then Fix(F | l2_N(w)) = {0}.
(c) A sufficient condition for (a)/(b): for each infinite component C there exist δ_C > 0 and an infinite subset S_C ⊆ C with w_n ≥ δ_C for all n ∈ S_C; then W(C) ≥ Σ_{n∈S_C} δ_C = ∞. (In particular any w bounded below by a global constant δ > 0, e.g. w ≡ 1, qualifies.)

*Proof.* (a), (b): immediate from Theorem 4(c)/(d): 𝒞_fin = {{0}} in case (a) (by Lemma 1, {0} is the only finite component and W({0}) = w_0 < ∞), and 𝒞_fin = ∅ in case (b). (c): a sum of infinitely many terms each ≥ δ_C > 0 diverges. ∎

## Corollary 7 (Faithful spaces and dimension = number of components — parts (4) second half, (5))

Suppose Σ_{n∈N_0} w_n < ∞ (globally summable weight). Then:
(a) For every component C, W(C) ≤ Σ_{n∈N_0} w_n < ∞, since C ⊆ N_0 and the terms are positive — note carefully (as the target flags): the needed convergence is over each component, but summability over the **whole** of N_0 suffices because components are subsets of N_0. Example: w_n = (n+1)^{−s}, s > 1, with Σ_{n≥0} (n+1)^{−s} = ζ(s) < ∞.
(b) Hence 𝒞_fin = 𝒞: every indicator 1_C lies in Fix(F | l2(w)), and by Theorem 4(d), **dim Fix(F | l2(w)) = #components of G** (as at-most-countable cardinals; if the conjecture fails badly enough to produce infinitely many components, both sides are ℵ_0).
(c) Unconditionally #𝒞 ≥ 2: {0} and C1 are components, and they are distinct because the component of 0 is exactly {0} (Lemma 1(a)) and 1 ≠ 0. Therefore dim Fix(F | l2(w)) ≥ 2 for every summable weight, and
  **Collatz conjecture ⇔ 𝒞 = { {0}, C1 } ⇔ dim Fix(F | l2(w)) = 2.**
The space l2(w) is fully faithful to the component structure: the fixed subspace has orthogonal basis { 1_C : C ∈ 𝒞 }, one basis vector per component. ∎

## Remark 8 (Boundedness of F — relevant for the forward-referenced Fredholm program; proved, but logically optional for L-9708)

For any weight, if a ∈ l2(w) then ||Fa||_w^2 = Σ_m w_m |a_{T(m)}|^2 = Σ_n ( Σ_{m: T(m)=n} w_m ) |a_n|^2, so F is a bounded operator l2(w) → l2(w) iff s(w) := sup_n W_pre(n)/w_n < ∞ where W_pre(n) := Σ_{T(m)=n} w_m, and then ||F||^2 = s(w). The preimage structure is: T^{-1}(0) = {0}; for n ≥ 1, T^{-1}(n) = {2n} if n ≢ 2 (mod 3), and {2n, (2n−1)/3} if n ≡ 2 (mod 3) — indeed (3m+1)/2 = n with m odd solves to m = (2n−1)/3, which is an integer iff 2n ≡ 1 (mod 3) iff n ≡ 2 (mod 3), and then n = 3t+2 gives m = 2t+1, odd and in N_0. (Checked exactly for n ≤ 2000 in the verification snippet.) Consequences: (i) w ≡ 1: every n has at most 2 preimages, so ||F||^2 ≤ 2 — F is bounded on unweighted l2; the no-go of Corollary 5 is not caused by unboundedness. (ii) w_n = (n+1)^{−s}: w_{2n} = (2n+1)^{−s} ≤ (n+1)^{−s} and, when present, w_{(2n−1)/3} = ((2n+2)/3)^{−s} = 3^s (2n+2)^{−s} ≤ 3^s (n+1)^{−s} (as 2n+2 ≥ n+1); hence s(w) ≤ 1 + 3^s and F is bounded on the faithful space l2((n+1)^{−s}). So the faithful spaces of Corollary 7 support bounded-operator methods.

## Remark 9 (3n−1 control)

Nothing above used any property of T beyond: T is a self-map of the index set, 0 is an isolated fixed point with no other preimage, and every n ≥ 1 has the doubling preimage chain. The 3n−1 shortcut map U(n) = n/2 (even), (3n−1)/2 (odd) on N satisfies U(N) ⊆ N and U(2^{k+1}n) = 2^k n, so Lemmas 0–3 and Theorem 4 hold verbatim for U on N: every component of U is infinite, Fix(F_U | l2(N)) = {0} unweighted (blindness again — even though U provably has ≥ 3 components, containing the cycles {1}, {5,7,10}, {17,…,34}), and for summable w, dim Fix(F_U | l2(w)) = #components of U ≥ 3. This is the sanity check that the unweighted kernel dimension carries no component information: it is 0 for both T|_N and U, whose component counts (conjecturally 1 vs. provably ≥ 3) differ.
