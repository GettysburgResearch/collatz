## Statement

Let T: N_0 -> N_0 be the shortcut Collatz map (T(n) = n/2 for n even, (3n+1)/2 for n odd). Let l1 = l1(N_0; C), linf = linf(N_0; C), with pairing <a,b> = sum_{n>=0} a_n b_n for a in linf, b in l1. Let F: linf -> linf, (Fa)_m = a_{T(m)}, and P defined coordinatewise by (Pb)_n = sum_{m in T^{-1}(n)} b_m. Call x in N_0 periodic if T^p(x) = x for some p >= 1; a cycle Z is the forward orbit of a periodic point; Cyc = set of cycles of T; mu_Z = sum_{x in Z} delta_x; Comp = set of weak components (= grand orbits) of the functional graph of T; an orbit is divergent if it never meets any cycle. Then: (1) P is a well-defined linear operator l1 -> l1 with operator norm exactly ||P||_{l1->l1} = 1, and P preserves the sum sum_n b_n of every b in l1. (2) The set of nonnegative fixed points of P in l1 is exactly { sum_{Z in Cyc} c_Z mu_Z : c_Z >= 0, sum_{Z in Cyc} c_Z |Z| < infinity } (the sum converging unconditionally in l1). (3) Fix(P|l1) := {b in l1 : Pb = b} = { sum_{Z in Cyc} c_Z mu_Z : c_Z in C, sum_Z |c_Z||Z| < infinity }, the closed linear span of {mu_Z : Z in Cyc}; the mu_Z have pairwise disjoint supports and are linearly independent, so with dim in N ∪ {infinity} (Hamel dimension collapsed to infinity when infinite), dim Fix(P|l1) = #Cyc when #Cyc < infinity, and Fix(P|l1) is infinite-dimensional otherwise; it equals the algebraic span of {mu_Z} iff #Cyc < infinity. (4) For all a in linf, b in l1, both sums in <Fa,b> = <a,Pb> converge absolutely and the identity holds; consequently F = P* under the canonical identification (l1)* = linf, and equivalently l1 (embedded in (linf)*) is invariant under F* with F*|_{l1} = P. (5) Fix(F|linf) := {a in linf : Fa = a} = {a in linf : a is constant on every component}, and a -> (its component values) is a linear isometric bijection Fix(F|linf) -> linf(Comp); hence dim Fix(F|linf) = #Comp when #Comp < infinity, and is infinite otherwise. The map iota: Cyc -> Comp, Z -> the component containing Z, is injective, and iota is surjective iff every component contains a cycle iff T has no divergent orbit; in particular #Cyc <= #Comp, and when #Comp < infinity, #Cyc = #Comp iff no divergent orbit exists. Unconditionally {0} and {1,2} are cycles lying in distinct components, so #Comp >= #Cyc >= 2 and both fixed spaces have dimension >= 2. Finally: the Collatz conjecture (G has exactly the two components {0} and the component of 1) holds iff dim Fix(F|linf) = 2, iff dim Fix(F|linf) = dim Fix(P|l1) = 2; whereas dim Fix(P|l1) = 2 alone is exactly the statement "T has no cycles besides {0} and {1,2}" and does not by itself exclude divergent orbits.

# T-9704 — Pushforward $\ell^1$ duality: cycles vs components (shortcut Collatz map)

## 0. Setting, notation, conventions

$\mathbb{N}_0=\{0,1,2,\dots\}$. The **shortcut Collatz map** is
$$T(n)=\begin{cases} n/2, & n \text{ even},\\ (3n+1)/2, & n \text{ odd}.\end{cases}$$
All sequence spaces are over $\mathbb{C}$ unless stated otherwise: $\ell^1=\ell^1(\mathbb{N}_0)$ with $\|b\|_1=\sum_n|b_n|$, $\ell^\infty=\ell^\infty(\mathbb{N}_0)$ with $\|a\|_\infty=\sup_n|a_n|$, pairing $\langle a,b\rangle=\sum_{n\ge0}a_nb_n$ ($a\in\ell^\infty$, $b\in\ell^1$; absolutely convergent since $|a_nb_n|\le\|a\|_\infty|b_n|$). $\delta_m$ is the point mass at $m$.

* **Periodic point:** $x$ with $T^p(x)=x$ for some $p\ge1$. $\mathrm{Per}$ = set of periodic points.
* **Cycle:** the forward orbit $Z=\{x,T(x),\dots,T^{p-1}(x)\}$ of a periodic point $x$ of minimal period $p$; then $T|_Z$ is a cyclic permutation of $Z$ ($T$ maps $Z$ into $Z$, is surjective $Z\to Z$ since $T(T^{p-1}x)=x$ etc., hence bijective on the finite set $Z$; injectivity + transitivity of the orbit make it a $p$-cycle). $\mathrm{Cyc}$ = set of cycles of $T$; $\mathrm{Per}=\bigcup_{Z\in\mathrm{Cyc}}Z$. For $Z\in\mathrm{Cyc}$ put $\mu_Z=\sum_{x\in Z}\delta_x\in\ell^1$ ($\|\mu_Z\|_1=|Z|$).
* **Component:** a weak (undirected) component of the functional graph $G$ (vertices $\mathbb{N}_0$, edges $m\to T(m)$). $\mathrm{Comp}$ = set of components. As given in the frozen definitions — and reproved in Lemma 2 below for self-containedness — components are exactly the classes of the **grand-orbit relation** $m\approx n \iff \exists\, j,k\ge0:\ T^j(m)=T^k(n)$.
* **Divergent orbit:** the orbit $(T^k(m))_{k\ge0}$ of some $m$ that never meets any cycle.
* **Operators:** $F:\ell^\infty\to\ell^\infty$, $(Fa)_m=a_{T(m)}$ (clearly linear, $\|Fa\|_\infty\le\|a\|_\infty$, $F\mathbf{1}=\mathbf{1}$, so $\|F\|=1$). $P$ is defined coordinatewise by $(Pb)_n=\sum_{m\in T^{-1}(n)}b_m$; Part (1) shows it maps $\ell^1$ to $\ell^1$.
* **Dimension convention:** $\dim V\in\mathbb{N}\cup\{\infty\}$ (Hamel dimension, collapsed to the single symbol $\infty$ when infinite); likewise $\#\mathrm{Cyc},\#\mathrm{Comp}\in\mathbb{N}\cup\{\infty\}$ (all sets here are countable).

**Known cycles (verified now, once):** $T(0)=0$, so $\{0\}$ is a cycle of length 1. $T(1)=2$, $T(2)=1$, so $\{1,2\}$ is a cycle of length 2. We do **not** assume these are the only cycles anywhere below.

## Lemma 1 (preimage structure)

For every $n\in\mathbb{N}_0$:
$$T^{-1}(n)=\begin{cases}\{2n\}, & n\not\equiv2\pmod 3,\\ \{2n,\ (2n-1)/3\}, & n\equiv2\pmod 3,\end{cases}$$
the two listed elements being distinct in the second case. Consequently $1\le|T^{-1}(n)|\le2$, and the family $\{T^{-1}(n)\}_{n\in\mathbb{N}_0}$ is a **partition** of $\mathbb{N}_0$ (each $m$ lies in $T^{-1}(n)$ for exactly one $n$, namely $n=T(m)$).

*Proof.* Solve $T(m)=n$ by parity of $m$. If $m$ is even: $m/2=n\iff m=2n$, and $2n$ is even, so $2n\in T^{-1}(n)$ always (including $n=0$: $T(0)=0$). If $m$ is odd: $(3m+1)/2=n\iff m=(2n-1)/3$, which is a nonnegative integer iff $3\mid 2n-1$ iff $2n\equiv1\pmod3$ iff $n\equiv2\pmod3$; in that case $3m=2n-1$ is odd, forcing $m$ odd (consistent), and $n\equiv2\pmod 3$ with $n\ge 0$ forces $n\ge2$, hence $m=(2n-1)/3\ge1\ge 0$. Distinctness: $2n=(2n-1)/3\Rightarrow 6n=2n-1\Rightarrow 4n=-1$, impossible. The partition statement is just the fact that $T$ is a (total, single-valued) function on $\mathbb{N}_0$. $\square$

**Edge case $n=0$:** $0\not\equiv2\pmod3$, so $T^{-1}(0)=\{0\}$: the only $T$-predecessor of $0$ is $0$ itself.

## Lemma 2 (components = grand orbits; basic component facts)

(i) $\approx$ (defined above) is an equivalence relation and its classes are exactly the weak components of $G$.
(ii) Two cycles are equal or disjoint; distinct cycles lie in distinct components; a component contains **at most one** cycle.
(iii) If a component $C$ contains a cycle $Z$, then the orbit of **every** $m\in C$ enters $Z$ (hence is eventually periodic). If $C$ contains no cycle, then the orbit of every $m\in C$ is divergent. Thus: some component lacks a cycle $\iff$ some orbit is divergent.
(iv) $\mathrm{comp}(0)=\{0\}$; every other component is infinite; $\mathrm{comp}(0)\neq\mathrm{comp}(1)$, so $\#\mathrm{Comp}\ge2$.

*Proof.* (i) Reflexivity ($j=k=0$) and symmetry are clear. Transitivity: if $T^j m=T^k n$ and $T^{j'}n=T^{k'}p$, apply $T^{j'}$ to the first and $T^{k}$ to the second: $T^{j'+j}m=T^{j'+k}n=T^{k+j'}n$ and $T^{k+j'}n=T^{k+k'}p$, so $T^{j+j'}m=T^{k+k'}p$. Each class is connected in the undirected graph (from $m$, walk forward along directed edges to $T^j(m)$, then backwards from $T^k(n)$ to $n$), and each undirected edge $\{m,T(m)\}$ has $m\approx T(m)$, so classes are unions of components and components are unions of classes; hence they coincide.

(ii) A cycle is the full forward orbit of each of its points: if $x\in Z\cap Z'$, then $Z=\{T^i(x):i\ge0\}=Z'$. If cycles $Z\ne Z'$ lay in one component, pick $z\in Z$, $z'\in Z'$ with $T^j(z)=T^k(z')$; but $T^j(z)\in Z$ and $T^k(z')\in Z'$, so $Z\cap Z'\ne\emptyset$, contradiction. \"At most one cycle per component\" is the same statement.

(iii) Let $Z\subseteq C$ and $m\in C$: pick $z\in Z$ with $T^j(m)=T^k(z)\in Z$; since $T(Z)=Z$, the orbit of $m$ enters $Z$ (at time $j$) and stays in $Z$, so it meets a cycle. Conversely if $C$ contains no cycle and $m\in C$, the orbit of $m$ meets no cycle: if it met a cycle $Z$, then $Z\subseteq\mathrm{comp}(m)=C$ (every point of $Z$ is $\approx m$), contradiction. The final equivalence follows immediately.

(iv) By Lemma 1, $T^{-1}(0)=\{0\}$, so by induction $T^{-k}(\{0\})=\{0\}$ for all $k\ge 0$; if $m\approx 0$ then $T^j(m)=T^k(0)=0$, so $m\in T^{-j}(\{0\})=\{0\}$. Hence $\mathrm{comp}(0)=\{0\}$. Any other component contains some $n\ge1$ and then contains the pairwise-distinct chain $n,2n,4n,\dots$ (each $2^{k}n$ satisfies $T(2^{k+1}n)=2^kn$, so all are $\approx n$; distinct since $n\ge 1$), so it is infinite. In particular $1\notin\mathrm{comp}(0)$. (Note: the frozen \"every component is infinite\" fails precisely for $\mathrm{comp}(0)=\{0\}$; we use only the corrected version just proved.) $\square$

## Lemma 3 (periodic preimages of cycle points)

Let $Z\in\mathrm{Cyc}$ and $n\in Z$. Then $T^{-1}(n)\cap\mathrm{Per}=T^{-1}(n)\cap Z=\{\sigma(n)\}$, where $\sigma:Z\to Z$ is the inverse of the cyclic permutation $T|_Z$ (the unique cycle predecessor of $n$). In particular every element of $T^{-1}(n)\setminus Z$ is non-periodic.

*Proof.* $T|_Z$ is a bijection of $Z$ (Section 0), so exactly one $m\in Z$ has $T(m)=n$, namely $\sigma(n)$. If $m\in T^{-1}(n)$ is periodic, $m$ lies on the cycle $Z_m$ = forward orbit of $m$, which contains $T(m)=n$; cycles through $n$ are unique by Lemma 2(ii), so $Z_m=Z$ and $m\in Z$. $\square$

## Part (1): $P$ is well defined on $\ell^1$, linear, and $\|P\|_{\ell^1\to\ell^1}=1$

Let $b\in\ell^1$. Each $(Pb)_n=\sum_{m\in T^{-1}(n)}b_m$ is a finite sum (Lemma 1: at most two terms; never an empty sum, though the definition would handle that too). Using the partition of Lemma 1 and Tonelli's theorem for nonnegative countable sums,
$$\sum_{n\ge0}\big|(Pb)_n\big|\;\le\;\sum_{n\ge0}\sum_{m\in T^{-1}(n)}|b_m|\;=\;\sum_{m\ge0}|b_m|\;=\;\|b\|_1<\infty, \tag{1.1}$$
because each $m\in\mathbb{N}_0$ occurs in exactly one inner sum (for $n=T(m)$), exactly once. So $Pb\in\ell^1$ and $\|Pb\|_1\le\|b\|_1$; linearity is clear coordinatewise (finite sums). Hence $\|P\|\le1$. For the reverse inequality: for any $m$, directly from the definition $P\delta_m=\delta_{T(m)}$ (the point $m$ lies in $T^{-1}(n)$ only for $n=T(m)$), so $\|P\delta_m\|_1=1=\|\delta_m\|_1$; thus $\|P\|\ge 1$ and
$$\boxed{\ \|P\|_{\ell^1\to\ell^1}=1.\ }$$

**Mass conservation (used repeatedly).** For every $b\in\ell^1$ (signed/complex included),
$$\sum_{n\ge0}(Pb)_n=\sum_{n\ge0}\sum_{m\in T^{-1}(n)}b_m=\sum_{m\ge0}b_m, \tag{1.2}$$
the regrouping over the partition $\{T^{-1}(n)\}_n$ being legitimate because the double family is absolutely summable by (1.1), so any regrouping of the unconditionally convergent sum $\sum_m b_m$ is permitted. In particular, if $b\ge0$ then $Pb\ge 0$ and $\|Pb\|_1=\|b\|_1$: **$P$ is a positive, sum-preserving (stochastic) contraction** — the column of $P$ indexed by $m$ is $\delta_{T(m)}$, with column sum $1$.

## Part (4): duality $\langle Fa,b\rangle=\langle a,Pb\rangle$; $F=P^*$

Let $a\in\ell^\infty$, $b\in\ell^1$. Then $\sum_m |a_{T(m)}b_m|\le\|a\|_\infty\|b\|_1<\infty$, so $\langle Fa,b\rangle=\sum_m a_{T(m)}b_m$ converges absolutely; regrouping this absolutely convergent sum over the partition $\{T^{-1}(n)\}_{n}$ of the index set (Lemma 1),
$$\langle Fa,b\rangle=\sum_{m\ge0}a_{T(m)}b_m=\sum_{n\ge0}\;\sum_{m\in T^{-1}(n)}a_n\,b_m=\sum_{n\ge0}a_n\,(Pb)_n=\langle a,Pb\rangle, \tag{4.1}$$
the right side also absolutely convergent since $Pb\in\ell^1$. (Absolute summability of the double family $(a_nb_m)_{n,\,m\in T^{-1}(n)}$ — it is bounded by $\|a\|_\infty\sum_m|b_m|$ — justifies the regrouping.)

Consequences. Under the canonical isometric identification $(\ell^1)^*=\ell^\infty$ (via the pairing $\langle\cdot,\cdot\rangle$), the adjoint $P^*:\ell^\infty\to\ell^\infty$ is characterized by $\langle P^*a,b\rangle=\langle a,Pb\rangle$ for all $b\in\ell^1$; by (4.1), $\langle Fa,b\rangle=\langle a,Pb\rangle$ for all $b$, and since elements of $\ell^\infty$ are separated by the pairing against $\{\delta_m\}\subset\ell^1$, we get $P^*=F$. Equivalently, reading (4.1) the other way: $F^*:(\ell^\infty)^*\to(\ell^\infty)^*$ leaves the canonically embedded copy of $\ell^1$ invariant and $F^*|_{\ell^1}=P$. This is the precise sense of \"$P=F^*$\". $\square$

## Part (2): nonnegative fixed points of $P$ in $\ell^1$

**Claim.** For $b\in\ell^1$ with $b\ge0$ coordinatewise: $Pb=b$ $\iff$ $b=\sum_{Z\in\mathrm{Cyc}}c_Z\,\mu_Z$ with $c_Z\ge0$ and $\sum_Z c_Z|Z|<\infty$.

**($\Leftarrow$).** First, $P\mu_Z=\mu_Z$ for every cycle $Z$: for any $n\in\mathbb{N}_0$, $(P\mu_Z)_n=|T^{-1}(n)\cap Z|$; if $n\in Z$ this is $1$ (Lemma 3), and if $n\notin Z$ it is $0$ (if $m\in Z$ then $T(m)\in Z$, so $m\notin T^{-1}(n)$). Hence $(P\mu_Z)_n=(\mu_Z)_n$ for all $n$. Next, since cycles are pairwise disjoint (Lemma 2(ii)) and $\|c_Z\mu_Z\|_1=c_Z|Z|$ is summable, the series $b=\sum_Z c_Z\mu_Z$ converges unconditionally in $\ell^1$ (its partial sums over finite sets of cycles are Cauchy). $\mathrm{Fix}(P)=\ker(P-I)$ is a norm-closed subspace ($P$ is bounded), contains every finite combination $\sum_{Z\in E}c_Z\mu_Z$ (linearity), hence contains the limit $b$. And $b\ge0$ trivially. *(Empty-sum edge case: $\mathrm{Cyc}$ is nonempty — it contains $\{0\}$ and $\{1,2\}$ — but even the zero combination is covered: $b=0$ is fixed.)*

**($\Rightarrow$).** Let $b\ge0$, $b\in\ell^1$, $Pb=b$. Define $\nu(A)=\sum_{n\in A}b_n\in[0,\|b\|_1]$ for $A\subseteq\mathbb{N}_0$ ($\nu$ is a finite measure on the power set; countable additivity is Tonelli).

*Step A ($T^{-1}$-invariance of $\nu$).* For every $A\subseteq\mathbb{N}_0$:
$$\nu(T^{-1}A)=\sum_{m:\,T(m)\in A}b_m=\sum_{n\in A}\sum_{m\in T^{-1}(n)}b_m=\sum_{n\in A}(Pb)_n=\sum_{n\in A}b_n=\nu(A),$$
the middle regrouping by the partition of $T^{-1}A$ into $\{T^{-1}(n)\}_{n\in A}$ (Tonelli, $b\ge0$). By induction, $\nu(T^{-k}A)=\nu(A)$ for all $k\ge0$.

*Step B (no mass off $\mathrm{Per}$).* Suppose $m_0\notin\mathrm{Per}$ and $b_{m_0}>0$. Put $A_k=T^{-k}(\{m_0\})$, $k\ge0$. By Step A, $\nu(A_k)=\nu(\{m_0\})=b_{m_0}>0$ for every $k$. The $A_k$ are pairwise disjoint: if $x\in A_j\cap A_k$ with $j<k$, then $T^j(x)=m_0$ and $m_0=T^k(x)=T^{k-j}\big(T^j(x)\big)=T^{k-j}(m_0)$, making $m_0$ periodic — contradiction. Hence, by countable additivity,
$$\|b\|_1=\nu(\mathbb{N}_0)\ \ge\ \nu\Big(\bigsqcup_{k\ge0}A_k\Big)=\sum_{k\ge0}\nu(A_k)=\sum_{k\ge0}b_{m_0}=\infty,$$
contradicting $b\in\ell^1$. Therefore $b_m=0$ for every non-periodic $m$: $\operatorname{supp}b\subseteq\mathrm{Per}=\bigsqcup_{Z\in\mathrm{Cyc}}Z$.

*Step C (constant on each cycle).* Fix $Z\in\mathrm{Cyc}$ and $n\in Z$. By Lemma 3, $T^{-1}(n)=\{\sigma(n)\}\sqcup\big(T^{-1}(n)\setminus Z\big)$ with every $m\in T^{-1}(n)\setminus Z$ non-periodic, hence $b_m=0$ by Step B. So
$$b_n=(Pb)_n=b_{\sigma(n)}\qquad\text{for every } n\in Z.$$
Iterating $\sigma$ (which generates the cyclic group on $Z$), $b$ is constant on $Z$; call the value $c_Z\ge0$. *(Edge cases: $Z=\{0\}$: $\sigma(0)=0$ and $T^{-1}(0)\setminus Z=\emptyset$, statement trivially holds. $Z=\{1,2\}$: $\sigma(1)=2,\sigma(2)=1$, giving $b_1=b_2$.)*

Thus $b=\sum_Z c_Z\mu_Z$ pointwise, with $\sum_Z c_Z|Z|=\|b\|_1<\infty$; since the supports are disjoint, this pointwise identity is also an unconditionally convergent $\ell^1$ representation. $\square$

## Part (3): all fixed points of $P$ in $\ell^1$ (signed/complex)

**Claim.** $\mathrm{Fix}(P|\ell^1)=\big\{\sum_{Z\in\mathrm{Cyc}}c_Z\mu_Z:\ c_Z\in\mathbb{C},\ \sum_Z|c_Z||Z|<\infty\big\}$ — the closed linear span of $\{\mu_Z\}_{Z\in\mathrm{Cyc}}$ in $\ell^1$.

*Proof.* ($\supseteq$): identical to ($\Leftarrow$) of Part (2) (closedness of $\ker(P-I)$; positivity was not used there).

($\subseteq$): let $b\in\ell^1$, $Pb=b$. Let $|b|$ denote the coordinatewise absolute value; $|b|\in\ell^1$, $\||b|\|_1=\|b\|_1$. Pointwise, by the triangle inequality,
$$(P|b|)_n=\sum_{m\in T^{-1}(n)}|b_m|\;\ge\;\Big|\sum_{m\in T^{-1}(n)}b_m\Big|=|(Pb)_n|=|b_n|,$$
so $P|b|-|b|\ge0$ coordinatewise. But by mass conservation (1.2) applied to the nonnegative vector $|b|$: $\sum_n(P|b|)_n=\sum_n|b|_n$, so the nonnegative vector $P|b|-|b|$ has total sum $0$, hence is $0$: $P|b|=|b|$. By Part (2), $\operatorname{supp}|b|\subseteq\mathrm{Per}$, i.e. $\operatorname{supp}b\subseteq\mathrm{Per}$. Now repeat Step C verbatim with the (possibly complex) $b$: for $n\in Z\in\mathrm{Cyc}$, all preimages of $n$ outside $Z$ are non-periodic, hence carry $b$-mass $0$, so $b_n=(Pb)_n=b_{\sigma(n)}$, and $b$ is constant $=c_Z$ on each $Z$. Then $b=\sum_Z c_Z\mu_Z$ with $\sum_Z|c_Z||Z|=\|b\|_1<\infty$. $\square$

**Dimension.** The $\mu_Z$ have pairwise disjoint supports (Lemma 2(ii)), hence are linearly independent, and the coefficient map $b\mapsto(c_Z|Z|^{?}\!)$ — precisely, $b\mapsto(c_Z)_{Z}$ — is a linear bijection of $\mathrm{Fix}(P|\ell^1)$ onto the weighted space $\ell^1(\mathrm{Cyc},\,w)$, $w(Z)=|Z|$ (indeed $\|b\|_1=\sum_Z|c_Z||Z|$, so it is an isometry onto). Therefore: if $\#\mathrm{Cyc}=d<\infty$, then $\mathrm{Fix}(P|\ell^1)$ equals the algebraic span of the $\mu_Z$ and $\dim\mathrm{Fix}(P|\ell^1)=d=\#\mathrm{Cyc}$; if $\#\mathrm{Cyc}=\infty$, then $\mathrm{Fix}(P|\ell^1)$ contains the infinite independent family $\{\mu_Z\}$, so $\dim=\infty=\#\mathrm{Cyc}$ under the collapsed convention (and it is the *closed*, not algebraic, span). Unconditionally $\{0\},\{1,2\}\in\mathrm{Cyc}$, so $\dim\mathrm{Fix}(P|\ell^1)\ge2$.

## Part (5): $\mathrm{Fix}(F|\ell^\infty)$, the count dichotomy, and the Collatz equivalence

**(5a) Fixed points of $F$.** $Fa=a$ $\iff$ $a_m=a_{T(m)}$ for all $m$ $\iff$ $a$ is constant on every component. Indeed: if $Fa=a$ then $a_m=a_{T^j(m)}$ for all $j$ (induction), so for $m\approx n$ with $T^j(m)=T^k(n)$: $a_m=a_{T^j(m)}=a_{T^k(n)}=a_n$; conversely if $a$ is constant on components then $a_m=a_{T(m)}$ since $m\approx T(m)$. The map $\Phi:\mathrm{Fix}(F|\ell^\infty)\to\ell^\infty(\mathrm{Comp})$, $\Phi(a)(C)=$ the constant value of $a$ on $C$, is linear, bijective (any bounded assignment of values to components defines a fixed $a\in\ell^\infty$; components are nonempty), and isometric ($\sup_n|a_n|=\sup_C|\Phi(a)(C)|$). Hence: if $\#\mathrm{Comp}=d<\infty$, $\dim\mathrm{Fix}(F|\ell^\infty)=d$ (the indicators $\{\mathbf 1_C\}$ form a basis); if $\#\mathrm{Comp}=\infty$, the infinite independent family $\{\mathbf 1_C\}$ gives $\dim=\infty$. So $\dim\mathrm{Fix}(F|\ell^\infty)=\#\mathrm{Comp}$ under the collapsed convention. By Lemma 2(iv), $\#\mathrm{Comp}\ge2$, so $\dim\mathrm{Fix}(F|\ell^\infty)\ge2$ unconditionally (e.g. $\mathbf 1$, $\mathbf 1_{\{0\}}$ are independent fixed vectors).

**(5b) Counts.** Define $\iota:\mathrm{Cyc}\to\mathrm{Comp}$, $\iota(Z)=$ the component containing $Z$ (well defined: $Z$ is $\approx$-connected). By Lemma 2(ii), $\iota$ is **injective**. By Lemma 2(iii), $\iota$ is **surjective** $\iff$ every component contains a cycle $\iff$ no orbit is divergent. Hence $\#\mathrm{Cyc}\le\#\mathrm{Comp}$ always; and if $\#\mathrm{Comp}<\infty$, then $\#\mathrm{Cyc}=\#\mathrm{Comp}$ $\iff$ $\iota$ is bijective $\iff$ no divergent orbit exists. (Caution, stated honestly: if both counts are infinite, numerical equality \"$\infty=\infty$\" no longer implies surjectivity of $\iota$; the invariant statement is the one about $\iota$.) Combining with Parts (3), (5a):
$$\dim\mathrm{Fix}(F|\ell^\infty)=\#\mathrm{Comp}\ \ge\ \#\mathrm{Cyc}=\dim\mathrm{Fix}(P|\ell^1)\ \ge\ 2,$$
with equality of the middle two (via $\iota$) iff every component contains a cycle iff no divergent orbit.

**(5c) Collatz equivalence.** The Collatz conjecture, in the frozen formulation, is: $G$ has exactly two components, $\{0\}$ and $\mathrm{comp}(1)$.

*Collatz $\iff$ $\#\mathrm{Comp}=2$.* ($\Rightarrow$) immediate. ($\Leftarrow$) $\mathrm{comp}(0)=\{0\}$ and $\mathrm{comp}(1)$ are two distinct components (Lemma 2(iv)); if $\#\mathrm{Comp}=2$ these are all of them.

*Collatz $\Rightarrow$ $\#\mathrm{Cyc}=2$.* Under Collatz, every cycle lies in $\{0\}$-component or in $\mathrm{comp}(1)$; each component contains at most one cycle (Lemma 2(ii)), and these two components do contain the cycles $\{0\}$ and $\{1,2\}$ respectively; so $\mathrm{Cyc}=\{\{0\},\{1,2\}\}$.

*Putting it together.*
$$\text{Collatz}\iff \#\mathrm{Comp}=2\iff \dim\mathrm{Fix}(F|\ell^\infty)=2 \iff \big(\dim\mathrm{Fix}(F|\ell^\infty)=\dim\mathrm{Fix}(P|\ell^1)=2\big).$$
For the second $\iff$: $\dim\mathrm{Fix}(F|\ell^\infty)=\#\mathrm{Comp}$ and both are $\ge2$; a finite dimension pins the count exactly. For the third: ($\Rightarrow$) Collatz gives $\#\mathrm{Cyc}=2$, hence $\dim\mathrm{Fix}(P|\ell^1)=2$ by Part (3); ($\Leftarrow$) trivial (drop the second conjunct).
