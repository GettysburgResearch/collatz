## Statement

Fix a real s > 1. Let w_n = (n+1)^{-s} for n ∈ N_0 = {0,1,2,...}, and let H_s = ℓ²(w) = { a = (a_n)_{n≥0} ∈ C^{N_0} : ‖a‖² := Σ_{n≥0} |a_n|² w_n < ∞ }, a Hilbert space with inner product ⟨a,b⟩ = Σ_n a_n b̄_n w_n. Let T: N_0 → N_0 be the shortcut Collatz map T(n) = n/2 (n even), (3n+1)/2 (n odd), let G be its functional graph on N_0, and let F be the pullback operator (Fa)_m = a_{T(m)}. Then:
(1) [Faithfulness] For EVERY subset S ⊆ N_0 the indicator 1_S lies in H_s with ‖1_S‖² = Σ_{n∈S}(n+1)^{-s} ≤ ζ(s) < ∞; in particular every weak-component indicator lies in H_s, and S ↦ 1_S is injective.
(2) [Exact norm] F maps H_s boundedly into H_s; F*F is the diagonal operator (F*F a)_n = d_n a_n with d_n = W_n/w_n, where W_n = Σ_{m∈T^{-1}(n)} w_m, and explicitly d_n = ((n+1)/(2n+1))^s + [n ≡ 2 (mod 3)]·(3/2)^s. Moreover sup_{n≥0} d_n = κ(s) := (3/5)^s + (3/2)^s, attained uniquely at n = 2, hence ‖F‖_{H_s→H_s} = √κ(s) = √((3/5)^s + (3/2)^s), and the norm is attained (at the basis vector e_2). In addition ‖Fa‖² ≥ 2^{-s}‖a‖² for all a ∈ H_s, and 2^{-s} = inf_n d_n is sharp (not attained), so F is injective with closed range.
(3) [Fixed space] Fix(F|H_s) = ker(F − I) = { a ∈ H_s : a is constant on each weak component of G }. If {C_i}_{i∈I} are the weak components of G (I countable, |I| ≥ 2), then {1_{C_i}}_{i∈I} is an orthogonal family of nonzero vectors whose closed linear span equals ker(F − I), so the Hilbert-space dimension of ker(F − I) equals |I|, the number of weak components (when |I| is finite this is the ordinary algebraic dimension).
(4) [Program payoff] H_s is a separable Hilbert space, F is a bounded operator on it with the exact norm √((3/5)^s+(3/2)^s) and F*F diagonal, dim ker(F − I) ≥ 2 always, and: the Collatz conjecture holds ⇔ dim ker(F − I) = 2 ⇔ ker(F − I) = span{1_{{0}}, 1_{C_1}}, where C_1 is the component of 1.

## Proof

# L-9705 — Faithful weighted Hilbert setting for the Collatz pullback operator

**Standing notation.** s > 1 fixed; w_n = (n+1)^{-s}; H_s = ℓ²(w) with ⟨a,b⟩ = Σ_n a_n b̄_n w_n and ‖a‖² = ⟨a,a⟩. Standard basis e_n (1 in coordinate n, else 0); note ⟨e_n, e_k⟩ = δ_{nk} w_n (orthogonal, not normalized) and ‖e_n‖² = w_n > 0. "Component" means weak (undirected) connected component of G.

Throughout, coordinate functionals are continuous on H_s: |a_n|² w_n ≤ ‖a‖², i.e. |a_n| ≤ (n+1)^{s/2}‖a‖, so norm convergence in H_s implies coordinatewise convergence. **(C)**

## Lemma 1 (preimage structure)

For every n ∈ N_0:
- if n ≢ 2 (mod 3): T^{-1}(n) = {2n};
- if n ≡ 2 (mod 3), say n = 3k+2 (k ≥ 0): T^{-1}(n) = {2n, 2k+1}, where 2k+1 = (2n−1)/3, and the two preimages are distinct.

In particular T is surjective and every preimage set is nonempty and finite (size 1 or 2).

**Proof.** An even m satisfies T(m) = m/2 = n iff m = 2n; 2n is always even, so 2n ∈ T^{-1}(n) for every n (including n = 0: T(0) = 0). An odd m satisfies T(m) = (3m+1)/2 = n iff 3m = 2n−1 iff m = (2n−1)/3. This is a nonnegative integer iff 3 | 2n−1; since 2n ≡ −n (mod 3), this holds iff −n ≡ 1, i.e. n ≡ 2 (mod 3) (which forces n ≥ 2, so 2n−1 ≥ 3 > 0). Writing n = 3k+2 gives m = (6k+3)/3 = 2k+1, which is indeed odd — so the case assumption is consistent and this m is a genuine preimage. Distinctness: 2n is even and 2k+1 is odd. No other preimages exist since every m is even or odd. ∎

*Hand checks (required edge cases).* n = 0: 0 ≢ 2 (mod 3), so T^{-1}(0) = {0} and W_0 = w_0 = 1. n = 2: 2 ≡ 2 (mod 3), k = 0, so T^{-1}(2) = {4, 1}; W_2 = w_4 + w_1 = 5^{-s} + 2^{-s} and W_2/w_2 = (3/5)^s + (3/2)^s (for s = 2 this is 9/25 + 9/4 = 261/100). n = 1: T^{-1}(1) = {2} only (1/3 ∉ N_0).

## Lemma 2 (weak components = grand orbits)

Define m ≈ n iff T^j(m) = T^k(n) for some j, k ≥ 0. Then ≈ is an equivalence relation on N_0 and its classes are exactly the weak components of G.

**Proof.** Reflexive (j = k = 0) and symmetric (swap) are clear. Transitive: if T^j(m) = T^k(n) and T^p(n) = T^q(r), then T^{j+p}(m) = T^p(T^j m) = T^p(T^k n) = T^k(T^p n) = T^k(T^q r) = T^{k+q}(r) (iterates of a single map commute). So ≈ is an equivalence.

Each ≈-class is undirected-connected: if T^j(m) = T^k(n), the vertex sequence m, T(m), …, T^j(m) = T^k(n), …, T(n), n is a finite walk in the undirected graph (each consecutive pair is an edge of G, traversed forward then backward). Conversely, every undirected edge {m, T(m)} joins ≈-equivalent vertices (j = 1, k = 0), so by induction along any finite undirected path, each weak component is contained in a single ≈-class. Hence ≈-classes = weak components. (The loop 0 → 0 is harmless: it makes {0} ≈-closed once one checks no other vertex reaches 0 — see Part 3.) ∎

## Part 1: every subset indicator lies in H_s (faithfulness)

Let S ⊆ N_0 be arbitrary. Then
‖1_S‖² = Σ_{n∈S} w_n ≤ Σ_{n=0}^∞ (n+1)^{-s} = ζ(s) < ∞ because s > 1.
So 1_S ∈ H_s for **every** subset S, in particular for every component indicator. The map S ↦ 1_S is injective (by (C), or simply because indicators are distinct sequences). Thus H_s "sees" every subset of N_0 faithfully — no component indicator is excluded, which is the faithfulness requirement of the T-9701 framework. ∎

## Part 2: F is bounded, F*F is diagonal, and ‖F‖ = √((3/5)^s + (3/2)^s) exactly

**Step 2.1 (norm identity).** The sets {T^{-1}(n)}_{n∈N_0} partition N_0: every m lies in exactly one of them, namely T^{-1}(T(m)) (T is a totally defined function). For any sequence a, all terms below are nonnegative, so Tonelli's theorem for series (summation over a countable partition) gives
‖Fa‖² = Σ_m |a_{T(m)}|² w_m = Σ_n Σ_{m∈T^{-1}(n)} |a_n|² w_m = Σ_n |a_n|² W_n, where W_n := Σ_{m∈T^{-1}(n)} w_m (a finite sum by Lemma 1, and W_n ≥ w_{2n} > 0).

**Step 2.2 (the ratio d_n).** By Lemma 1,
d_n := W_n/w_n = w_{2n}/w_n + [n ≡ 2 (mod 3)] · w_{(2n−1)/3}/w_n.
Now w_{2n}/w_n = ((n+1)/(2n+1))^s, and when n ≡ 2 (mod 3), (2n−1)/3 + 1 = (2n+2)/3, so w_{(2n−1)/3}/w_n = ((n+1)·3/(2n+2))^s = (3/2)^s **exactly, independent of n**. Hence
d_n = f(n) + [n ≡ 2 (mod 3)]·(3/2)^s, with f(n) := ((n+1)/(2n+1))^s.

**Step 2.3 (sup of d_n).** Since (n+1)/(2n+1) = 1/2 + 1/(2(2n+1)) is strictly decreasing in n ≥ 0 with value 1 at n = 0 and limit 1/2, and x ↦ x^s is strictly increasing on (0,∞), f is strictly decreasing with f(0) = 1 and f(n) ↓ 2^{-s}. Therefore:
- for n ≢ 2 (mod 3): d_n = f(n) ≤ f(0) = 1 < (3/2)^s < (3/5)^s + (3/2)^s (the middle inequality because s > 0);
- for n ≡ 2 (mod 3) (so n ≥ 2): d_n = f(n) + (3/2)^s ≤ f(2) + (3/2)^s = (3/5)^s + (3/2)^s, with equality iff n = 2 (strict monotonicity of f).
Hence sup_n d_n = max_n d_n = κ(s) := (3/5)^s + (3/2)^s, attained **uniquely** at n = 2. Also inf_n d_n = 2^{-s}: every d_n > f(∞) = 2^{-s} (strictly, since f(n) > 2^{-s} for all finite n and the bracket term is ≥ 0), while along n ≡ 0 (mod 3), n → ∞, d_n = f(n) → 2^{-s}; so the infimum is 2^{-s} and is not attained.

**Step 2.4 (boundedness and two-sided bounds).** By Steps 2.1–2.3, for every a ∈ H_s:
2^{-s} ‖a‖² ≤ ‖Fa‖² = Σ_n d_n |a_n|² w_n ≤ κ(s) ‖a‖² < ∞.
So F maps H_s into H_s, is bounded with ‖F‖ ≤ √κ(s), is injective and bounded below by 2^{-s/2} (hence has closed range, by the standard fact that a bounded-below bounded operator has closed range: if Fa_k → y then (a_k) is Cauchy by the lower bound, a_k → a, Fa = y). The lower constant 2^{-s} is sharp because ‖Fe_n‖²/‖e_n‖² = d_n → 2^{-s} along n ≡ 0 (mod 3).

**Step 2.5 (F*F is diagonal — exact norm).** F is bounded, so the adjoint F* exists (Riesz). Fix a, b ∈ H_s. By Cauchy–Schwarz in ℓ²(w), Σ_m |a_{T(m)}| |b_{T(m)}| w_m ≤ ‖Fa‖ ‖Fb‖ < ∞, so the following double sum is absolutely convergent and may be regrouped over the partition {T^{-1}(n)}_n (Fubini for absolutely convergent series):
⟨F*Fa, b⟩ = ⟨Fa, Fb⟩ = Σ_m a_{T(m)} b̄_{T(m)} w_m = Σ_n a_n b̄_n W_n = Σ_n (d_n a_n) b̄_n w_n = ⟨Da, b⟩,
where D is the multiplication operator (Da)_n = d_n a_n, bounded on H_s since sup d_n = κ(s) < ∞. Since this holds for all a, b ∈ H_s, **F*F = D**: F*F is diagonal in the standard basis, with diagonal entries d_n. (Equivalently and more structurally: ⟨Fe_n, Fe_k⟩ = Σ_{m∈T^{-1}(n)∩T^{-1}(k)} w_m = δ_{nk} W_n because the preimage sets are pairwise disjoint; and one computes F*e_k = (w_k / w_{T(k)}) e_{T(k)} directly from ⟨e_k, Fe_n⟩ = [T(k) = n] w_k.)

By the C*-identity ‖F‖² = ‖F*F‖ = ‖D‖. For a diagonal operator on ℓ²(w) with nonnegative entries, ‖D‖ = sup_n d_n: "≤" is Step 2.4's computation applied to D, and "≥" from ‖De_n‖ = d_n ‖e_n‖. Hence
**‖F‖ = √κ(s) = √((3/5)^s + (3/2)^s).**
Attainment: ‖Fe_2‖² = W_2 = d_2 w_2 = κ(s) ‖e_2‖², so the operator norm is **attained** at e_2 (equivalently, e_2 is an eigenvector of F*F for its largest eigenvalue κ(s), and κ(s) is an attained maximum, not merely a sup, by Step 2.3). ∎

*Sanity values*: ‖F‖ = √κ(s) ≈ 1.4602 (s = 1.1), 1.5172 (s = 1.5), 1.6155 (s = 2, κ = 261/100 exactly), 1.8950 (s = 3). Note 1 < ‖F‖ always, consistent with 1 being an eigenvalue of F (Part 3).

## Part 3: Fix(F|H_s) = {a ∈ H_s constant on components}, of dimension = number of components

**Step 3.1 (characterization of fixed points).** For a ∈ H_s: Fa = a ⇔ a_{T(m)} = a_m for all m ∈ N_0.
(⇐, i.e. "constant on components ⇒ fixed") m and T(m) lie in the same component (they are joined by an edge), so if a is constant on each component then a_{T(m)} = a_m for all m, i.e. Fa = a.
(⇒) Suppose a_{T(m)} = a_m for all m. By induction, a_{T^j(m)} = a_m for all j ≥ 0. If m, n lie in the same component, then by Lemma 2 there are j, k ≥ 0 with T^j(m) = T^k(n), whence a_m = a_{T^j(m)} = a_{T^k(n)} = a_n. So a is constant on each component. (This is exactly where "component" — grand orbit — differs from "forward orbit": constancy propagates through common descendants, and Lemma 2 says that is enough to cover the whole weak component.)
Hence Fix(F|H_s) := {a ∈ H_s : Fa = a} = ker(F − I) = {a ∈ H_s : a constant on each component}. It is a closed subspace since F is bounded (Part 2).

**Step 3.2 (the components; |I| ≥ 2).** Let {C_i}_{i∈I} be the distinct components; they partition N_0, so I is countable (finite or countably infinite) and each C_i ≠ ∅. The set {0} is a full component: the undirected neighbors of 0 are T(0) = 0 and T^{-1}(0) = {0} (Lemma 1, n = 0), so no path leaves {0}. Since 1 ∉ {0}, the component C_1 of 1 (which contains the 2-cycle {1, 2}, as T(1) = 2, T(2) = 1, and is infinite: it contains 1, 2, 4, 8, …) is a different component. So |I| ≥ 2.

**Step 3.3 (orthogonal basis of the fixed space).** Each 1_{C_i} ∈ H_s (Part 1), is nonzero, is constant on every component (value 1 on C_i, 0 on each other component), hence lies in ker(F − I) by Step 3.1. For i ≠ i′, supp(1_{C_i}) ∩ supp(1_{C_{i′}}) = ∅, so ⟨1_{C_i}, 1_{C_{i′}}⟩ = 0: the family is orthogonal. Set μ_i := ‖1_{C_i}‖² = Σ_{n∈C_i} w_n ∈ (0, ζ(s)].

Conversely, let a ∈ ker(F − I), with constant value c_i on C_i (Step 3.1). By Tonelli over the partition {C_i}, Σ_{i∈I} |c_i|² μ_i = Σ_n |a_n|² w_n = ‖a‖² < ∞. Therefore the orthogonal series Σ_{i∈I} c_i 1_{C_i} converges in H_s (orthogonal series with square-summable norms converge, in any fixed enumeration of the countable set I; the sum is enumeration-independent by unconditional convergence of orthogonal series). Let b ∈ H_s be its sum. By continuity of coordinate functionals (C), for each n ∈ N_0 — say n ∈ C_{i(n)} — b_n = c_{i(n)} = a_n (only the single term i = i(n) contributes to coordinate n). Hence b = a, i.e. a ∈ closed-span{1_{C_i} : i ∈ I}.

Combining: **ker(F − I) = closed linear span of the orthogonal family {1_{C_i}}_{i∈I}**, so {1_{C_i}/√μ_i}_{i∈I} is an orthonormal basis of ker(F − I) and its Hilbert-space dimension equals |I|, the number of components. When |I| is finite, Hilbert dimension = algebraic dimension, and the closed span is the plain span. ∎

*Edge-case illustration (cycle ≠ component).* 1_{{1,2}} is NOT fixed: F1_S = 1_{T^{-1}(S)} for any S (since (F1_S)_m = 1_S(T(m))), and T^{-1}({1,2}) = {2} ∪ {4,1} = {1,2,4} ≠ {1,2}. Only the **full** component indicator 1_{C_1} is fixed. Meanwhile 1_{{0}} = e_0 is fixed: T^{-1}({0}) = {0}. This confirms Step 3.1's content at the two known cycles.

## Part 4: program payoff (record)

H_s is a separable Hilbert space (countable orthogonal basis {e_n}) in which:
1. every subset indicator lives (Part 1) — the setting is faithful: no component, including any hypothetical divergent-orbit tree component or exotic-cycle component, is invisible;
2. F is bounded with the **exact** norm ‖F‖ = √((3/5)^s + (3/2)^s), attained at e_2, F*F is the explicit diagonal operator diag(d_n), and F is bounded below by 2^{-s/2} (injective, closed range) — Part 2;
3. 1 is an eigenvalue of F, with eigenspace exactly the closed span of the component indicators, of Hilbert dimension = #components ≥ 2 — Part 3.
Consequently the Collatz conjecture transfers verbatim: **G has exactly the two components {0} and C_1 ⇔ dim ker(F − I on H_s) = 2 ⇔ ker(F − I) = span{1_{{0}}, 1_{C_1}}** (the ⊇ inclusion of the 2-dimensional span holds unconditionally; the conjecture is the equality). Any additional cycle or divergent orbit of T creates a new component, hence a new orthogonal direction in ker(F − I). The pair (H_s, F) — bounded, exact norm, F*F diagonal — is the natural home for a future essential-spectrum attack; nothing in this claim assumes the conjecture.
