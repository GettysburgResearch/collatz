# Universal polynomial identities from exact invariant rigidity

**IC1--IC3: PROPOSED, self-audited.** This is a further consequence of the
ring-valued theorem, not a claim that the actual Collatz convergence indicator
has a finite polynomial representation. It yields finite algebraic proof
certificates for a FIXED finite architecture.

## IC1. Every output difference is an exact ideal combination of edge defects

Fix the input base, finite state dimension and finite degree bounds of the
polynomial digit maps and output. Make every allowed coefficient and initial
coordinate a formal parameter theta_i, and work in A=Z[theta_1,...,theta_r].
For each positive n, symbolic digit evaluation produces a polynomial F_n in A.
Let

    E_n = F_{T(n)}-F_n,
    I = ideal generated by all E_n, n>0.

Then for every pair a,b>0,

    F_a-F_b is in I.                                (1)

In particular there are FINITELY many positive sources n_i and integer
polynomials Q_i(theta) with the polynomial identity

    F_a-F_b = sum_i Q_i(theta) E_{n_i}(theta).        (2)

This is exact ideal membership, not merely membership in the radical and
not an identity that only holds at generic coefficient values.

**Proof.** Reduce the universal machine over the commutative quotient ring
A/I. By definition every Collatz-edge defect is zero there. AR2 applies to
this ring, including its possible nilpotents and zero divisors, and makes
every output equal. Hence the image of F_a-F_b is zero, which is precisely
(1). An element of the generated ideal is a finite combination, giving (2).
This is why the theorem over arbitrary commutative rings is useful: a result
only over algebraically closed fields would not by itself justify this
nonradical conclusion.

One can also write J=(F_n-F_1:n>0). Always I is contained in J, since an
edge defect is a difference of two generators of J; (1) gives the reverse
inclusion. Thus I=J. Since A is Noetherian, there exists one finite list of
edge defects generating I. For this fixed architecture, vanishing of that
finite list is equivalent to constant outputs and to all-edge invariance,
under specialization to ANY commutative ring. No explicit uniform bound
for the needed source list is obtained here.

For a specified pair a,b, a terminating but potentially impractical search
can enumerate finite integer-polynomial combinations and compare coefficients
until (2) is found. Alternatively, over Q, enumerate finite edge prefixes and
perform exact polynomial-ideal membership tests. Membership is guaranteed by
(1). This is an existence/termination statement, not a complexity bound or
an implemented general-purpose Groebner solver in this packet.

## IC2. Quantitative consequences with bounded parameters

An explicit identity (2) gives a robust refutation on a bounded real parameter
box. If |theta_j|<=M, put C_M=sum_i ||Q_i||_M, where
||sum_alpha c_alpha theta^alpha||_M=sum_alpha |c_alpha|M^{|alpha|}.
Then

    |F_a-F_b| <= C_M max_i |E_{n_i}|.                (3)

Thus prescribed output separation delta>0 forces at least one named edge
to have defect >=delta/C_M. No rounding, extrapolation from random parameter
tests or model-fitting assumption is involved. The finite identity is the
certificate. Degree bounds, parameter bounds and a specified unequal pair
matter. The dimension-only counterexample in ROBUSTNESS.md is consistent
with (3): its architecture degrees and coefficients are not bounded as K grows.

## IC3. An explicit nonlinear-output family certified by four actual edges

For binary input, consider the rational/real two-parameter family

    initial x=0;  P_0(x)=a*x;  P_1(x)=b*x+1;  H(x)=x^2.

The scalar state is not itself the output; the quadratic readout can hide
state sign changes. Define e2=F_2-F_1 (the NEGATIVE of E_2), and use the
ordinary sign e3=E_3, e5=E_5, e11=E_11. Direct digit evaluation gives

    e2 = a^2-1,
    e3 = (ab+1)^2-(b+1)^2,
    e5 = a^6-(ab+1)^2,
    e11 = (a^3 b+1)^2-(a b^2+b+1)^2.

Write

    D = (a^2+a+1)((a^3+1)b+2)
        - b((a+1)b^2+2b+2),
    E = a^4+a^2+1-b^2,
    L = D+2(b^2+2).

The following identity holds as an INTEGER polynomial in a,b:

    8b = [2(b^2+2)E+b^2 L] e2
         - L e3 - 2(b^2+2)e5 + 2e11.               (4)

One derivation first notes (e3-b^2 e2)/2=(a-1)b and
-e5+E e2=b^2+2ab. Eliminate (a-1)b to obtain b^2+2b; subtract
D(a-1)b from e11 to obtain -b^4-2b^3-2b^2; the latter plus
(b^2+2)(b^2+2b) equals 4b. Multiplying out gives (4) with no
remaining denominators. The producer verifies its complete coefficient
array over Z, rather than assuming the division steps work in every ring.

Over Q or R, invariance at the FOUR sources 2,3,5,11 forces a^2=1 and b=0.
Conversely those parameter conditions make every positive-input output 1:
the first digit sets x=1, digit 0 sends x to plus/minus x, and digit 1
resets x=1. Thus these four edges decide the entire family, not just selected
parameter instances. This parameter classification is not asserted in
characteristic dividing 8, where dividing (4) would be invalid.

On |a|,|b|<=1 the sum of the absolute coefficients of the four multipliers
in (4) is 60. Therefore, if epsilon is the maximum absolute defect on those
four edges,

    |a^2-1| <= epsilon,   |b| <= (15/2) epsilon.      (5)

The packet also checks multiplier bounds 1122 and 109356 on boxes of
radius 2 and 4. These are convenient coefficient bounds, not optimal
condition numbers or claims about every polynomial architecture.

### Two genuinely different exact checks

The producer expands bivariate polynomials using sparse coefficient
arithmetic. The standalone verifier does not import those operations.
It evaluates the identity at a complete integer grid, using a proved
separate degree bound of at most seven in each variable. The 8-by-8 grid
therefore certifies the polynomial identity exactly: fix one variable,
use the univariate root bound, then repeat for the other. This is not an
arbitrary sample offered as evidence for a universal identity. A mutated
multiplier is rejected. No symbolic-library or formal proof-assistant
verification is claimed.

## Remaining boundary

These are algebraic certificates against candidate invariant models, not
certificates that all positive Collatz trajectories terminate. A finite
architecture and, for a practical robust bound, an explicit finite identity
are inputs. The theorem does not show the actual convergence indicator
belongs to one architecture or has parameters in a fixed compact box.
