# Pass 5: nonlinear algebraic rigidity, finite defects, and effective refutation

## Strongest additions

[ALGEBRAIC_RIGIDITY.md](ALGEBRAIC_RIGIDITY.md) proves that every finite-dimensional
polynomial digit-state Collatz invariant is constant, in EVERY integer base
and over EVERY commutative coefficient ring. The state may grow superexponentially;
no linearization or bounded-state assumption is used. Finitely generated
coefficient rings admit finite quotients separating an unequal output pair,
which reduces the problem to automatic rigidity. Nilpotents require finite
rings, not just finite fields. Standard commutative algebra inputs are cited.

[FINITE_DEFECT.md](FINITE_DEFECT.md) completely classifies these machines when
invariance is required only for sources n>=N. Put K=ceil(N/2). Outside powers
of two as input bases, the function is constant from K onward. In bases 2^r,
the only possible high exceptions are constant-valued truncated dyadic rays
with odd root m<N divisible by three. Values below K are unrestricted. All
listed possibilities are realizable. Polynomial AUTOMORPHISM machines have
no exceptions at all: eventual invariance already forces global constancy.
An invertible projective-state corollary is proved separately.

[CERTIFICATES.md](CERTIFICATES.md) supplies a complete arithmetic product-graph
checker for finite quotient models, including canonical digits, carry flushes,
and the source floor. A violation has an actual Collatz-edge source below
B^{8(S+1)^2(N+1)}. The bound uses finite quotient size S, not polynomial state
dimension. A one-variable degree-512 model is refuted at n=2^511 using 3,575
visited product states, without scanning that huge source interval.

[IDEAL_CERTIFICATES.md](IDEAL_CERTIFICATES.md) goes beyond numerical refutation:
for each fixed polynomial architecture, every output difference is an exact
finite polynomial combination of Collatz-edge defects. The proof uses the
universal coefficient ring modulo its defect ideal, retaining nilpotents.
A two-parameter quadratic-output family has an explicit integer-polynomial
certificate using only sources 2,3,5,11, with a quantitative bounded-parameter
error bound. Both implementations check that identity by different exact methods.

[ROBUSTNESS.md](ROBUSTNESS.md) proves the essential negative control: one-variable
rational polynomial models can have oscillation one and global invariance
error 1/K for arbitrarily large K. Their degrees grow. Thus exact rigidity
has no dimension-only numerical stability gap. A separate compact-state,
equicontinuous, fixed-margin theorem gives an automatic quotient and extends
the exact obstruction to that explicitly stable continuous model class.
