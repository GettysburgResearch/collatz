## Why the mass improvement stops at old sources

The recent-cohort result meets the *shape* of the proposed harmonic relative-loss target on its stated population. A fixed least bad source would eventually be principal and survive forever, while its age grows almost as fast as the clock. It lies outside those recent cohorts. Even including every other principal source of its own hypothetical component does not repair this: every sufficiently late first failure must occur at an exponentially large ordinary source, and the total available reciprocal mass has an exponentially decaying tail.

The first-entry law addresses a different issue. It proves tightness at an absolute ordinary landing height, so a bad component would force a positive atom at one specified permanently passing seed. At a nonperiodic permanent unit `z`, that atom is `d_z q_z`, where `d_z` is its ordinary predecessor density and `q_z` is the probability, under the original fixed-root inverse entrance law, of never making a nonnegative reverse-debt return. The identity is about the same ordinary target and the actual inverse law. It does not establish that `q_z` vanishes.

The newer pointwise theorem determines `d_z q_z=z^(-1+o(1))` at every nonperiodic ordinary unit. Along a hypothetical escaping ray its predecessor densities stay bounded below, so the conditional `q_z` has that same reciprocal-root exponent. Finite antichains of strict inverse words cannot beat this exponent by a fixed positive power. The first-entry law therefore narrows the admissible behavior of an escaping component rather than contradicting it.

At the critical slope a corrected-height minimum `m` of an escaping component has inverse no-return probability one. The basic source-qualified bounds allow `c/m ≤ d_m ≤ C_ε m^(-δ+ε)`, with `δ=1−H₂(log₃2)>0.05004`; M-6 adds an unspecified positive gain under its stronger input. These bounds leave a large quantitative gap. The critical law excludes periodic components from its finite labels, so additional integer cycles still require the full mass criterion or a separate cycle argument.

## Replay and scope

Run the finite controls with Python 3.11 or later:

```bash
python -X utf8 -B research/astra-diagonal-frontier-20261127/replay_controls.py \
  --receipt /absolute/path/outside-checkout/controls.json
```

This runs each declared finite checker normally and under `-O`, compares outputs, checks frozen JSON records where supplied, and verifies source stability. It does not infer an asymptotic theorem from a census.

The Lean replay requires Lean 4.34.1 and Mathlib source commit `d13f23b723b8a846827a245b89c10fc7d3f11612` with its dependency objects available:

```bash
python -X utf8 -B research/astra-diagonal-frontier-20261127/check_lean.py \
  --lean /absolute/path/to/lean-4.34.1/bin/lean \
  --mathlib /absolute/path/to/pinned/mathlib4 \
  --receipt /absolute/path/outside-checkout/lean.json
```

It creates a fresh project object directory, compiles every listed module with warnings as errors, then imports them into a fresh audit and prints the axioms of every public theorem. The allowed inventory is `propext`, `Classical.choice`, and `Quot.sound`. Private dependencies of those roots are included transitively; unrelated unused private constants are not claimed as a separate whole-module audit. Mathlib objects are reused. This is not an independent LeanChecker replay.

On a machine with a memory-backed copy of Mathlib objects, the optional `--cache-overlay /absolute/path` avoids loading a second disk-backed copy. The script links only Mathlib files whose bytes match the pinned cache into a private dependency directory; compiler and third-party packages keep their original import locations. Extra files without a pinned counterpart are not put on the search path. This is an I/O option, not a weaker mathematical check. The per-invocation wall-time limit is configurable with `--timeout-seconds`.
