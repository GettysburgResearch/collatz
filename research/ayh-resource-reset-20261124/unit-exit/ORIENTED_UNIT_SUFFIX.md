# Each ordered color change is required on suffix 57

**Status.** PROPOSED consequence of the written unit-exit estimate, the ordinary four-suffix routing, and the pinned PR 146 directed-cut and variation arguments. The predecessor exponent comes from the published Krasikov–Lagarias Theorem 6.1. The positive-density input M is unnecessary.

Take the basin-of-one indicator \(f\). Suppose a counterexample exists. For **each** ordered pair \((i,1-i)\), \(i=0,1\), let \(U_i(Y)\) count odd ternary units \(u\le Y\) with \(f(u)=i,\ f(3u)=1-i\). The unit-exit exponents apply to each \(U_i\) separately. In particular, at the explicit \(\sigma=2001/5000\),
\[
        \limsup_{Y\to\infty}\frac{U_i(Y)}{Y^{42021/70025}}>0.
\]
The same separate assertion holds for both signs with denominator \(Y^{3/5}(\log Y)^{3/4}\), using the native square root in the unit-exit estimate.

Indeed the actual-label variation and dyadic-limit argument gives \(cX^{.84}\) total odd tripling defects on infinitely many octaves. On an infinite subsequence at least half have the same orientation. PR 146's directed-cut inequality (3) sends them with bounded multiplicity to the opposite orientation on \([X/H,2HX]\), with \(H\) fixed. This interval has boundedly many dyadic octaves with sizes comparable to \(X\). Each sign thus separately reaches \(c'X^{.84}\) along an unbounded octave sequence. For clarity, inequality (3) comes from a positive directed return path from \(3x\) to \(x\) for every odd \(x\). Ordinary moves preserve the label, so an endpoint discrepancy forces a forward tripling of the opposite orientation somewhere on that path. The possible tripling sources belong to a fixed finite list of injective positive-slope affine functions of \(x\). This accounts for both multiplicity and comparable heights. No estimate on an eventual meeting clock enters this cut comparison.

At each such octave the actual unit exit preserves the **ordered** pair. Take \(Z=KX^{800/2001}\) with \(K\) sufficiently large in the unweighted-in-log tail \(O(XZ^{-\sigma})\). At least \(c'X^{.84}/2\) distinct terminal units of the designated orientation lie below \(CXZ\); the exponent follows from \(.84/(1+800/2001)=42021/70025\). Using \(Z=KX^{2/5}/(\log X)^{5/4}\) and the source-qualified native square root gives the displayed log correction at exponent \(3/5\).

Now fix a nonempty open head arc, a level residue modulo a fixed positive modulus, and a minimum number of initial even child steps. The unit routing with \(p=3,\ r=57\) sends \(u\) to a head \(z\asymp u\) on this schedule, of **parent color \(f(u)\)** and **child color \(f(3u)\)**. Its finite menu bounds the multiplicity uniformly. Therefore, for either chosen orientation, the number of matching heads on an unbounded sequence of scheduled levels \(R=81^j\) is at least \(cR^{42021/70025}\), and the analogous log-corrected lower bound holds on a possibly different sequence. Otherwise the sum of little-o counts over all geometric rows through \(CY\) would contradict the corresponding cumulative unit bound. In particular, proving a single fixed implication between the parent and child basin labels eventually on just this scheduled suffix would settle Collatz. The implication remains open.
