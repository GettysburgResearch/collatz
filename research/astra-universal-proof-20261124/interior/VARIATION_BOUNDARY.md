# Sharpness of the joint monotone variation test

**PROPOSED finite obstruction.** Consider the fixed feature list of PR 197, `7ad81ec56947146fac854d2586651ca0c934a536`, `research/ayh-resource-reset-20261124/directed-return/FIXED_TRIT_PATTERNS.md` and `SELECTED_COLOR_VARIATION.md`. Retain the actual ordinary coarse parameters, floor maps, disjoint physical windows and congruence restrictions. If one forgets Collatz invariance and color-dependent query legality, the total variation lower bound for the full list is exactly attainable, even when exponentially many physical arguments per pattern are required. This isolates precisely which hypotheses must enter a stronger argument.

Take a list of size k by truncating to the guaranteed order, so k=o(W). From one original realizing leaf choose its finite coarse parameter set M. On this set every coordinate lies in its own specified progression. Write its physical value as z_i(m)=floor(s_i m)+b_i, s_i>0. Choose a coordinate j of smallest slope. The source theorem gives at least T=exp(cW) distinct values of z_j on this leaf. Sort them and take alternate values, retaining one coarse parameter for each. Between consecutive retained parameters m<m', the floor difference on coordinate j is at least two. Thus s_j(m'-m)>1, and z_i(m')>z_i(m) in every coordinate. At least floor(T/2) parameters remain. All coordinates retain their original classes and windows.

Partition the retained increasing list into 2^k consecutive blocks differing in size by at most one. Assign the blocks the successive words of a reflected binary Gray code, starting from the all-zero word. Such a code follows by prepending zero to a shorter code in forward order and one to the same code in reverse order. In window i give each retained physical point the bit in coordinate i. Extend to the entire progression by copying the preceding bit, using the first bit before the first point; extend to all ordinary sites of the window in the same manner. Disjoint windows make this a single ordinary binary labeling. Every pattern has at least floor(floor(T/2)/2^k)=exp(Ω(W)) distinct ordinary arguments in each coordinate. Exactly one bit changes per consecutive block pair, hence the sum of fixed-gap variations on the full list is **exactly 2^k−1**. The sum of within-window unit-gap variations has the same value.

The new labels need not be constant along shortcut edges. Replaying the chronological search under the new labels may leave the chosen leaf. This calculation proves no counterexample to Collatz or to PR 197. It proves the exact arithmetic floor maps, fixed residues, abundant distinct arguments and shattering cannot alone force transition counts greater than 2^k−1 in aggregate. Each progression already contains exp(Ω(W)) sites. Converting a one-point native merger probability of inverse-polynomial order in W into a count by multiplying by its number of sites gives an upper scale exponentially larger than 2^k. An upper bound contradicting shattering must exploit additional structure, such as actual ordinary-orbit identifications on these ordered arguments. I have no such bound.
