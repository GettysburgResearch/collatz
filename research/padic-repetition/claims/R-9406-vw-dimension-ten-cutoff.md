## Refuted inference

The following inference is invalid:

> The Väänänen–Wallisser numerical condition fails at dimension ten, therefore
> a period-ten stack value may be rational or the source proves nothing useful
> about its native coefficient vector.

What actually fails is the theorem's sufficient condition for full rational
linear independence of

```text
1,f_R(y_0),...,f_R(y_9).
```

## Exact distinction

The source theorem targets every nonzero rational coefficient vector in an
eleven-dimensional family. PR #20 needs only exclusion of the single vector

```text
Theta(m;W^infinity)
 =sum_(j=0)^9 C_j f_R(y_j).                           (1)
```

whose coefficients and points are linked by one first-order skew
`q`-difference equation.

Thus

```text
full ten-phase independence
```

is strictly stronger than

```text
irrationality of the one native combination (1).
```

The source inequality

```text
gamma<Gamma(D)
```

holds through `D=9` and fails at `D=10`; this identifies the endpoint of that
particular full-independence theorem, not a rationality boundary.

## Productive consequence

The period-ten problem should be attacked by removing the cost of unused
coefficient directions. Concrete ways to do so are:

1. eliminate one phase using the quantitative nine-phase measure;
2. construct Padé orthogonality only against the native coefficient vector;
3. use the two-dimensional homogeneous `q`-difference system generated by
   `(1,Theta)`;
4. build a phase-sensitive Hermite–Padé or maximal-minor certificate.

These routes are frozen in `L-9414` and `Q-9413`.
