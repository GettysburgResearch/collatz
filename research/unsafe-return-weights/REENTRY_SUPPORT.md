# Exact support after re-entry, and moment loss on that support

**Status: PROPOSED.** Use the [unsafe return and radial moment spaces](README.md). For a fixed finite physical floor H>=1 let U_H be the unsafe states above H, retaining a return only if its entire physical path stays above H. The exact surviving image after any positive number of returns is

    J_H^m(U_H) = D_H = {u in U_H : 3 does not divide u}      (m>=1).   (1)

Every member of D_H even admits one compatible infinite backward chain of surviving returns. For any strictly positive summable full-support mass on U_H, the support of its transported distribution is exactly D_H after the first and all subsequent returns. This is an assertion about support. The pointwise masses on that support depend on the initialization.

The bounded-weight equivalence of the [original theorem](README.md) holds on l¹(D_H,phi(R)) with the same condition phi(t²)=O(phi(t)). The pure first-moment explosion of the fixed full-support input R^{-2} persists when initialized on D_H itself. There is also a different, explicitly constructed summable mass on the **terminating** part of D_H with finite pth rank moment and infinite pth moment after every positive return count, for each p>0.

## Characterizing the image

An even multiple of 3 has rank n²/3^{v3(n)}. Its maximal halving module preserves that valuation and decreases rank. Thus every unsafe multiple of 3 is odd. The first odd shortcut step enters the ternary units, and the units are forward invariant. This proves the inclusion in (1) already at m=1.

For an odd ternary unit z above H, graft a signed tower from the [termination construction](TERMINATING_TOWERS.md) with terminal even state Z=2^k z in place of 2^k. One period's first nine bits suffice. Impose 3^7|X_0 as there, and take k large. The last odd unsafe state Y occurs before Z. By the same fixed ternary rows R(Z) grows quadratically in Z. Since A(Z)=z, Z is safe for large k, and the whole halving path remains above H. Moreover Y is odd and a ternary unit. If z is unsafe, this gives J_H(Y)=z. Repeating the construction at each successive odd unsafe predecessor creates an actual infinite backward chain, with heights increasing if desired.

It remains to allow an even unsafe target y in D_H. The class y=2 modulo 3 has R(y)=(y-1)² and A(y)<=y/2, so it is safe. For y=7 modulo 9, the possible components are y², (y-1)²/3, (y+5)²/3. An even y in this class is at least 16, and R(A(y))<=y²/4<(y-1)²/3, again safe. The remaining unit classes at an even unsafe y are 1 and 4 modulo 9. Thus z=(4y-1)/3 is an odd ternary unit greater than y. Its path z -> 2y -> y is one maximal 10 module, since y is even. Graft to the odd unit z as above. If z is unsafe, J_H(z)=y. If z is safe, J_H(Y)=y with Z and z on the safe leg. In either case the resulting odd unsafe predecessor can be extended backward indefinitely, entirely above H. This proves (1), the infinite-chain assertion, and the support assertion by positivity of the source masses.

## The fixed-iterate weight classification on D_H

Use the same negative-cycle shadow but choose x=1+14*3^e, with e even in an arithmetic progression, and force x=-17 modulo 2^L at any required fixed precision L. This is equivalent to 9^{e/2}=-9/7 modulo 2^{L-1}. The right side belongs to the subgroup of residues equal to 1 modulo 8, which is generated by 9. Such x have bounded multiplicative gaps at any fixed L, and R(x)<=14(x-1) by the index-one component. The exceptional first Y phase now has ternary representative 73/16 modulo 3^7 because x=1 modulo 3^7. At that representative the candidates 0,1,2,4 have coefficients 1, 1/3, 1/9, 2401/243, respectively, and h=4. All subsequent Z, X, Y rows of the first proof are unchanged, since Z_0+68 and X_1+17 already contain 3^7. Every prescribed positive return thus has quadratic endpoint rank and remains above H, while x is an odd unit unsafe state in D_H. Interpolating between consecutive x as in the [necessity proof](README.md) gives phi(t²)=O(phi(t)); finite gaps remain bounded despite the added one. Sufficiency is inherited directly from the polynomial height bound. For the input f=1_{D_H} R^{-2}, the same Tonelli argument gives infinite first rank moment after every m>=1. This removes the transient nonunit stratum from both tests.

## An explicit exploding mass made entirely of terminating states with infinite pasts

Fix p>0. For b=1,2,... choose h_b>=7 so that (3^{h_b}/10)^p>=2^b. Complete a tower of b periods and the last nine bits to a pure power of two using source congruence x_b=1 modulo 3^{h_b}. Its initial rank is at most (x_b-1)²/3^{h_b}. By the altered first Y row just computed and the other three phase rows, all of its first b induced endpoints have rank >=x_b²/10 once x_b is sufficiently large. The sources are odd ternary-unit members of D_H, the entire prescribed tower stays above H, and the terminal halving run reaches 1. Choose the successive terminal exponents to place all towers above the initial heights of preceding ones and make the x_b distinct.

Give x_b mass 2^{-b} R(x_b)^{-p}. This is summable and its pth rank moment is one. For any fixed m>=1, every tower indexed by b>=m reaches its mth unsafe endpoint. It contributes at least 2^{-b}(3^{h_b}/10)^p>=1 to the output pth rank moment. Summing shows divergence, even though each individual source has a certified finite path to 1 and an infinite compatible backward return chain. Monotone superposition with any additional finite-moment mass preserves this counterexample.

Consequently removing transient support or restricting to a certified terminating basin does not make a distribution-free positive rank-moment propagation theorem possible. Bounds exploiting the actual weights of a genuinely specified input remain open.
