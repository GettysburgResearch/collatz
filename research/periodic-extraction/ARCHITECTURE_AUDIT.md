## 2. The exact inference repeatedly missing

For one fixed prefix-correct architecture, let

```text
S_n = positive ordinary seeds legal through depth n,
m_n = min S_n.
```

PRs `#56` and `#57` prove the elementary but load-bearing equivalence

```text
one ordinary seed survives every depth
  <=> (m_n) is bounded
  <=> (m_n) eventually stabilizes.
```

The invalid replacement is

```text
for every n there exists x_n
  !=>
there exists x for every n.
```

A compatible inverse-limit point repairs neither the quantifiers nor the archimedean bound.  PR `#56` goes further: arbitrarily strong exact odd-over-dyadic expansion can be attached to any chosen nonordinary nested completion while preserving infinitely many positive finite-prefix representatives.  Therefore no theorem using only the common affine/cylinder/refund skeleton can extract an ordinary seed.

Any positive proof must use architecture-specific information that forces bounded canonical representatives.

## 3. What `T-7401` adds

`T-7401` closes the exhaustive class in which the parity itinerary is eventually periodic.

For a period block `w` of length `L` with `s` odd branches,

```text
T_w(x)=(3^s x+C_w)/2^L,
x_w=C_w/(2^L-3^s).
```

Hence:

```text
supercritical period 3^s>2^L:
  x_w<0, so no positive ordinary realization;

subcritical period 3^s<2^L:
  positive ordinary realization
  <=> 2^L-3^s divides C_w
  <=> the tail is a positive integer cycle.
```

Thus eventual periodicity does not leave an ordinary-extraction problem. It leaves exactly the full-denominator finite-cycle problem.

This strengthens the explicit `(1110)^infinity` ghost from PR `#57` to every period and every finite preperiod.

## 5. Why the target is genuinely narrower than Collatz

The theorem eliminates only eventually periodic parity itineraries. A hypothetical divergent Collatz orbit could have a genuinely aperiodic itinerary, so the negative result does not prove Collatz.

For one fixed strict subsystem, proving its least roots tend to infinity eliminates that complete subsystem and is likewise narrower than Collatz.

The positive sides are sufficient conditions for a disproof rather than logically weaker propositions:

- a stabilized least root in a counterexample-complete subsystem yields a written divergent seed;
- a nontrivial positive full-denominator cycle yields a finite counterexample.

This asymmetry should be stated explicitly. The two-sided **decision problem** is narrower because its negative side closes only one prescribed class.
