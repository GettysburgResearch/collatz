# Pointwise import audit: factoring tools versus the ordinary Collatz profile

**Status (2026-11-28).** This is a source-level compatibility audit and a set of exact consumer specifications. It does not prove an ordinary mixing theorem or Collatz. Nine additional complete source files were read at immutable heads; their paths and blob identifiers are in [POINTWISE_SOURCE_INTAKE.json](POINTWISE_SOURCE_INTAKE.json). The earlier coverage, sampler and collision-extraction audit is [FACTORING_BRIDGE.md](FACTORING_BRIDGE.md).

There is a genuinely uniform pointwise estimate in the factoring work: PR #310's quaternionic representation bound. There are also exact algorithms that work at enormous exponents without an oracle, and an integer-vanishing theorem obtained from a real analytic branch. None currently supplies the joint real-height and ternary-residue estimate required by an ordinary Collatz orbit. The missing data below are part of the mathematical input, rather than implementation details.

## 1. The actual consumer

Use the shortcut map
\[
T(n)=
\begin{cases}
n/2&n\equiv0\pmod2,\\
(3n+1)/2&n\equiv1\pmod2.
\end{cases}
\]
For a chronological word \(w=(w_0,\ldots,w_{h-1})\), let \(a=|w|_1\) and write
\[
2^hT^h(n)=3^a n+A(w)
\]
when \(n\) has that actual parity word. Equivalently,
\[
A(w)=\sum_{\substack{0\le i<h\\w_i=1}}
       2^i3^{\,\#\{j:i<j<h,\ w_j=1\}}.
\]
For a prescribed positive endpoint \(y\), the exact inverse profile by odd grade is
\[
N_{h,a}(y;X)=
\#\left\{
\begin{array}{l}
w\in\{0,1\}^h,\ |w|_1=a:\\
A(w)\equiv2^h y\pmod{3^a},\\
0<2^h y-A(w)\le3^a X
\end{array}
\right\}.                                                    \tag{P1}
\]
Every word counted here supplies the integer
\[
n=(2^h y-A(w))/3^a.
\]
The full affine divisibility then forces every parity in the word, so (P1) counts actual positive sources, once each. This is the ordinary divisibility-to-parity interface already proved in the preceding packet. There is no independently resampled itinerary.

Thus a potential exponential-sum import must retain all of the following simultaneously:

1. the ordered carry \(A(w)\), with the actual powers of three attached to later odd dates;
2. a prescribed residue modulo the **full** \(3^a\);
3. a real interval of width \(3^aX\), located at \(2^hy\);
4. the range of \(h,a,y\) demanded by the intended collision or escape theorem;
5. a justified comparison to the relevant component/phase projection.

For example, the exact Fourier identity for the congruence in (P1) is
\[
N_{h,a}(y;X)=\frac1{3^a}
\sum_{\xi\bmod3^a}e(-\xi2^hy/3^a)
\sum_{\substack{|w|=h,\ |w|_1=a\\
0<2^hy-A(w)\le3^aX}}
e(\xi A(w)/3^a).                                           \tag{P2}
\]
The real cutoff remains **inside** the exponential sum. A bound for the unrestricted word sum, or for generic roots \(y\), is not (P2).

At depths \(h>\log_2X+O(1)\), the population \(1\le n\le X\) no longer supplies independent high binary digits. Its high digits are zero, and the new parity digits are generated by the actual integer \(3^a n+A(w)\). Neither a Haar tail nor independent CRT coordinates can replace that arithmetic.

A uniform estimate with an unspecified invariant projection can be valuable, but it does not evaluate the median collision constant. The preceding packet identifies that constant as
\[
\frac14\sum_C\frac{d_C^2}{P_C}.
\]
Proving rapid approach to this expression is different from proving that it equals \(1/8\).

## 2. PR #310: a real pointwise bound, with a geometric projection

Pinned source:
[cm-quaternion-mass-2026-11-27.md](https://github.com/gfreund123/factoring-in-p/blob/f0b23444dcdbaf48475919f3c903c5c1924913e9/notes/cm-quaternion-mass-2026-11-27.md).

For \(D\ge3\), \(D\equiv3\pmod4\), put
\[
Q_D(x,y,z,w)=x^2+y^2+xz+yw+\frac{D+1}{4}(z^2+w^2),
\]
\[
r_D(k)=\#\{v\in\mathbb Z^4:Q_D(v)=2^k\},\quad
F(D)=D\prod_{p\mid D}\left(1+\frac{\chi_{-4}(p)}p\right).
\]
The source states and proves
\[
\left|r_D(k)-\frac{24(2^{k+1}-1)}{F(D)}\right|
\le12(k+1)2^{k/2},                                        \tag{Q1}
\]
uniformly in \(D,k\), including non-squarefree \(D\).

The written mechanism is a definite quaternion order with reduced discriminant \(D\), a mass formula, local norm surjectivity, and a Brandt operator at the good prime two. Its constant row sum is \(2^{k+1}-1\). The nonconstant spectrum is bounded using the corresponding cuspidal/Deligne bound. In particular this is not merely a heuristic for cancellation.

Two separate limitations matter.

- **Representation is arithmetic input.** One needs an actual identification of the desired count with this positive quadratic shell or an appropriate Hecke correspondence. No such identification of (P1) is supplied.
- **The constant projection is already identified.** Single-genus/norm information determines the mass term \(24/F(D)\). An abstract spectral estimate for a Collatz transfer operator could instead converge to the unknown component/phase projection above.

The factoring algorithm then treats sufficiently precise shell counting as an acquisition problem; the note gives a numerical-\(D\) reference algorithm, not a polynomial-bit algorithm for arbitrary \(D\). The pointwise mathematical estimate itself is stronger than that algorithmic limitation. A future import should preserve this distinction.

**Precise potentially useful direction.** Construct an ordinary inverse-word operator with an independently evaluated mass formula and a correspondence to its actual full-residue/height trace. A claim of “Ramanujan mixing” without its invariant-space calculation leaves the Collatz question in the constant term.

## 3. PR #234: exact formal content at remote exponents

Pinned head: [5006ac6547cc0106909c31cea730de06baf2405a](https://github.com/gfreund123/factoring-in-p/tree/5006ac6547cc0106909c31cea730de06baf2405a).

- [uniform_multivariate_content.md](https://github.com/gfreund123/factoring-in-p/blob/5006ac6547cc0106909c31cea730de06baf2405a/research/semiprime-relations-2026-11-26/notes/uniform_multivariate_content.md).

### 3.1 What is unconditional in the source

For a supplied prime \(p\), the first note computes the formal coefficient gcd with \(p^2\) of
\[
F(X)=\sum_{\nu=1}^s f_\nu(X)\prod_{j=1}^r A_{\nu j}(X)^{m_j},
\]
in polynomial bit time with an absolute exponent in the listed input parameters, including the **numerical** signed base-\(p\) digit bound. It uses a bounded carry space, exact coefficient formulas for \(V^p\bmod p^2\), and common linear recurrences to compress all address-digit transition maps. This correctly distinguishes a zero polynomial from a polynomial that vanishes at every scalar residue.

For an arbitrary initially unfactored modulus, the ordered-matrix theorem computes
\[
\gcd\bigl(N,\operatorname{coefficients}
 L_X(P_1(X)^{m_1}\cdots P_r(X)^{m_r})\bigr)
\]
in polynomial bit time for **fixed width \(d\) and fixed number of powered blocks \(r\)**. It retains matrix order. Its joint splitting degree is bounded by \((d!)^r\), and its tuple space has size \(d^r\). Bounded exponent-relation rows, a finite row-growth argument, primary guards and simultaneous tensor moments handle exceptional characteristics and repeated prime powers.

The multivariate extension is polynomial for fixed numbers of variables and ordered blocks; its unfactored version also fixes the width. Generic-line arguments prove cancellation statements without identifying a pointwise scalar evaluation with the full coefficient content.

### 3.2 Why this does not yet evaluate (P2)

The outputs are exact divisibility/content statements. They are not a signed or positive estimate for the number of words in a moving real window.

The native affine matrices are
\[
M_0=\begin{pmatrix}1&0\\0&2\end{pmatrix},\qquad
M_1=\begin{pmatrix}3&1\\0&2\end{pmatrix};
\]
chronological composition gives the actual carry. Compressing runs gives a product of powered matrices, but an arbitrary parity calendar has a growing number of ordered blocks. Keeping width two does not keep the theorem's \(r\) fixed. Setting \(r=h\) does not retain a polynomial bound.

Moreover a linear observation of the matrix product recovers its affine numerator, not the indicator that this numerator lies in a particular residue **and** real interval. Encoding that indicator by all characters of \(3^a\), or by a full address automaton, introduces a growing state space that must itself be bounded. The content algorithm cannot be cited as though it had already compressed that space.

**Precise potentially useful direction.** Supply a uniformly bounded ordered-block or differential-rank representation of the *windowed* sum in (P2), with explicit control as \(a,h,\log y\) grow. If such a representation is found, the primary-content machinery may certify exact cancellations or exclude a proposed degeneration. The missing representation is presently the first unsupported step.

### 3.3 The simultaneous Weil lattice

The same head's
[uniform_simultaneous_weil_lattice.md](https://github.com/gfreund123/factoring-in-p/blob/5006ac6547cc0106909c31cea730de06baf2405a/research/semiprime-relations-2026-11-26/notes/uniform_simultaneous_weil_lattice.md)
is a genuine simultaneous real/algebraic smallness argument.

It assumes a hidden Weil number \(\beta\), all conjugates on one known circle, and actual integral divisibilities \(\beta\mid N^u\), \(\Phi_s(\beta)\mid M\). An integer-polynomial lattice enforces these divisors. If a weighted LLL bound makes every conjugate of the resulting integral quotient smaller than one, its norm vanishes. The multi-polynomial version charges resultant overlap and requires a **common** residual bound.

For Collatz, the carry is already an ordinary integer and its known legality gives the one full congruence in (P1). It does not automatically provide several independent divisors or a hidden Weil spectrum. An LLL import must display the exact integral quotient, all conjugate bounds, and a capacity inequality strong enough for the actual word family. Calling the real interval an “archimedean place” does not supply those missing divisors.

## 4. PR #294: moment recovery needs a common geometric spectrum

Pinned source:
[MOMENTS.md](https://github.com/gfreund123/factoring-in-p/blob/9a8f091b1f1a4c957aed1132e8312e37a66b496d/research/powered-moment-recovery/MOMENTS.md).

The note expands primitive-component errors through power traces \(S_m\) of a reciprocal Weil spectrum and Ramanujan coefficients. Comparing two carefully chosen squarefree indices isolates the first different prime moment. Exact Ramanujan cancellation and a controlled geometric tail then give, for the displayed setup, \(|S_\ell|\le8g\). Further moments feed a fixed-dimension elimination argument.

This is useful algebraic cancellation with a uniform consumer **inside its common-spectrum hypothesis**. Different actual parity calendars do not presently come with one fixed-dimensional Weil spectrum whose traces are the windowed sums in (P2). Applying the moment conclusion to unrelated calendars would discard that hypothesis.

The global-geometry and elliptic-exponent notes at #234 also retain a common curve/primitive-component framework. They neither prove arbitrary-exponent success on every semiprime nor manufacture a Collatz spectrum.

## 5. PR #313: analytic interpolation gives an integer zero

Pinned source:
[ANALYTIC.md](https://github.com/gfreund123/factoring-in-p/blob/deef3316388f54912624f99e51c2a8202e9d1b5e/research/analytic-weil-branches/ANALYTIC.md).

The supplied geometric equation, public trace intercept and real size bounds reduce the unknowns to two integers \(x,b\) on a holomorphic branch. Rouché bounds give a controlled analytic radius; Taylor coefficients are computed with certified rational error. A weighted rank-169 lattice, using monomials \(x^i b^j\) with \(i+2j\le24\), produces an auxiliary integer polynomial smaller than one at the true point. Hence it vanishes. A separate irreducibility/degree argument ensures that the eliminant is nonzero.

This is a valid model for a proof-producing interpolation consumer: the analytic radius, integer height, lattice determinant and nonzero eliminant must all be present. It does not require an oracle once its geometric promise is supplied.

For a general Collatz calendar, no two-variable analytic branch containing all legal carries has been identified, with a radius and height budget uniform in the calendar length. Introducing one variable for each run loses the fixed-rank determinant estimate. A future import should first produce that low-dimensional branch, rather than reproduce the lattice calculation on formal variables without its geometric input.

## 6. The exact joint-law source does not fill the diagonal gap

The primary source
[Joint Collatz affine law, paper 19/v2](https://rstation.ai/problems/collatz/papers/19/v2)
and its [corrected discussion manuscript, §9.2 and §10](https://rstation.ai/r/collatz/posts/33)
give a useful, sharply delimited interface. For every fixed positive odd unit \(a\),
\[
\frac1N\sum_{k=1}^N
3^k\nu\bigl(dR\times(a+3^k\mathbb Z_3)\bigr)
\Longrightarrow h(a)\mu_a.                              \tag{J1}
\]
The averaging and the real-coordinate measure are essential. The source explicitly supplies neither a depthwise limit nor a rate uniform in the root.

It also proves a uniform joint ball bound and full product dimension. These are ambient estimates. They do not provide a lower trace at an escaping prescribed integer. There is a concrete reason not to replace the missing statement by arbitrary diagonal flatness: at every **nonperiodic** positive integer \(a\), including the known convergent integer \(5\), the canonical real fibre has a fixed relative gap below \(a\). Periodic roots have a different endpoint law. A proposed uniform estimate must respect that distinction.

This source is therefore compatible with the earlier packet's ordinary Lebesgue-point and moving-trace audit. It gives no new authorization to exchange a fixed-root limit with the root sequence selected by an actual escaping orbit.

## 7. A useful positive bridge and its measurable cost

[FACTORING_BRIDGE.md](FACTORING_BRIDGE.md) states an exact sufficient condition for an orbit-preserving sampler: a doubly stochastic integer kernel with gap \(\gamma_X\), and total transition weight \(\epsilon_X\) lacking actual merger certificates, would force component-label variance at most \(\epsilon_X/(2\gamma_X)\).

That conditional route remains substantive. It requires \(\epsilon_X=o(\gamma_X)\), not merely a high success percentage. Two new checks constrain how to build it:

- [MULTIPLIER_CERTIFICATE_RIGIDITY.md](MULTIPLIER_CERTIFICATE_RIGIDITY.md) proves that a fixed prime multiplier outside \(\{2,3\}\) cannot have two distinct ordinary source mergers within the same pair of word charts, and its entire two-adic merger set is Haar-null.
- [FINITE_AFFINE_GAP.md](FINITE_AFFINE_GAP.md) gives explicit gap bounds when the public modular sampler is restricted to uniformly bounded Haar-compatible affine charts. Large modular exponentiation remains cheap for factoring, while its unreduced ordinary realization carries the full exponent/height cost.

These statements do not exclude a sampler with genuinely growing native certificates, a new joint diagonal estimate, or a different arithmetic construction. They specify what such a construction must overcome. The current positive semiprime coverage theorem has already removed the need for a general-purpose factoring improvement on its thin family; actual orbit closure and the median collision projection remain the load-bearing consumers.
