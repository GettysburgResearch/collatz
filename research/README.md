# Research stage

This directory contains the mathematical work of the repository.

## Integrated knowledge

[`integrated/`](integrated/README.md) contains the curated proof-bearing packets accepted for repository-wide reference. Each packet states its exact scope, proof, provenance, review evidence, common misreadings, and next missing step.

Integrated does **not** mean “proves Collatz.” It means the repository has selected the narrow result as a stable reference and preserved its status honestly.

## Exploratory research

The other subdirectories are active or historical research programs. They may contain:

- proposed theorems;
- source-qualified reductions;
- exact finite experiments;
- countermodels and refutations;
- partial proofs;
- literature interfaces;
- abandoned or superseded approaches;
- broad multi-pass research notebooks.

Exploratory work is welcome and need not conform to the integrated-packet format. It must still make status, scope, and finite-versus-global boundaries visible.

## Choosing a program

Start from:

- [`../CURRENT_KNOWLEDGE.md`](../CURRENT_KNOWLEDGE.md) for the synthesis;
- [`../FRONTIERS.md`](../FRONTIERS.md) for exact missing lemmas;
- [`../AGENTS.md`](../AGENTS.md) for agent workflow;
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md) for submission and review guidance.

Search the repository and open PRs before duplicating an active line. A new connection between programs should be labeled **PROPOSED** until reviewed.
