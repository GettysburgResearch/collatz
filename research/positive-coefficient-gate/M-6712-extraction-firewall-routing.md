## Proposed connection

Three independently reconstructed no-go theorems constrain different attempted substitutes for ordinary extraction.

### One compatible path

PR #56 `R-7801` proves that one nested nonordinary residue path can be decorated with arbitrarily strong exact positive affine expansion while retaining infinitely many positive roots at every finite depth. Therefore expansion and refund on one compatible path do not imply an ordinary source.

### Many compatible paths

PR #60 `R-7401` proves that a compact perfect raw-Collatz parity forest may have positive aligned-prefix entropy, positive `2`-adic Hausdorff dimension, uniform supercritical block density, and infinitely many positive finite-prefix roots, while containing no signed ordinary parity sequence. Therefore branching, entropy, dimension, and drift do not imply an ordinary source.

### Bounded controller state

PR #57 `R-7602` proves that when a finite-state or zero-tail-tame foundry does have a nonnegative ordinary point, its eventual-zero binary input forces eventual periodic output, hence an actual Collatz cycle. A uniformly supercritical such controller has no positive ordinary point.

## Routing rule

Taken together, these results suggest the following project routing discipline.

```text
bounded zero-tail state
+ ordinary point
    -> eventual cycle
    -> route to full-denominator cycle closure;

claimed divergent schedule-first architecture
    -> must retain genuinely unbounded state on a zero input tail
    -> and must separately prove Archimedean source tightness;

large path family / entropy / dimension / expansion
    -> discovery information only unless it bounds or forces escape
       of canonical least sources.
```

Thus finite-state foundries should not remain in the divergent-orbit portfolio. Their only possible positive payoff is a finite cycle, which must meet the entire-denominator and replay obligations.

Conversely, an unbounded-state foundry is not validated merely by escaping `R-7602`: `R-7801` and `R-7401` show that unbounded controller complexity, large path families, and strong drift still do not establish ordinary realization. The load-bearing theorem remains source-specific stabilization or source escape.
