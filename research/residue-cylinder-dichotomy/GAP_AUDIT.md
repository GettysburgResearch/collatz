# Ordinary-integer gap audit

## What is proved

For the frozen direct dyadic boundary class of `D-9701`:

1. every finite type prefix has one exact initial residue cylinder;
2. the exact new residue block is computed by `L-9701`;
3. every infinite type directive has infinitely many nonzero blocks;
4. its unique `Z_2` completion is not any signed ordinary integer;
5. no positive high-tail initialization exists for the whole infinite class;
6. all statements quantify the full directive class, not sampled schedules.

## Every ordinary-integer assumption exposed

### 1. Finite compatibility

A member of a finite cylinder proves only a finite exact replay. The proof never
uses finite compatibility as an infinite initialization.

### 2. Completion versus integer

Nested cylinders give one `Z_2` point. `T-9702` assumes that point is an
ordinary integer only for contradiction and then derives an infinite integer
trajectory. It does not identify the completion with a finite word by
compactness.

### 3. Least representatives

Eventual zero blocks characterize nonnegative integer completion. Negative
integers have nonstabilizing least nonnegative residues. The contraction proof
excludes all signed integers, so this convention causes no hidden exception.

### 4. Positivity

The negative theorem does not assume future positivity. It excludes even a
signed infinite integer high-tail path. Finite certificates use an explicit
nonnegative member of each finite cylinder only to validate physical replay.

### 5. Marked physical state

The physical state is

```text
x=A_i(t)+2^(K_i(t))*h-34.
```

`X-9701` replays this state directly through every committed finite tower
block. No infinite marked state is claimed because `T-9702` proves none exists
in the frozen class.

### 6. Logarithm digits

No digit of `-(7/4)log_2(3)` is part of the initialization or proof. The
logarithm interface is recorded only to distinguish this packet from PR #3's
control compiler.

### 7. Entropy and surplus

No branch count, entropy surplus, or bit-length estimate is treated as residue
membership. The theorem uses exact divisibility plus an exact real bound.

### 8. External theorem status

The proof of `T-9702` uses only elementary integer inequalities after the exact
PR #3 tower formulas are frozen. `LIT-KTHM-0030`, `LIT-KTHM-0033`, `L-9310`,
`L-9503`, `T-9409`, and `T-9601` are comparison interfaces, not promoted proof
dependencies.

## What remains open

### A. The composed 256-transition stage

The main unresolved ordinary channel in PR #3 is

```text
S_m + 3^(A_m)Y_m
 = R_(m+1) + 2^(D_(m+1))Y_(m+1).
```

Its stage slope is positive, so the finite-trap contraction of `T-9702` does
not apply. Proving nonzero blocks for this class requires a new invariant.

### B. Counter-prefix isometry

PR #3 `T-0028`/`T-0029` routes finite low connector prefixes with the padding
counter, and `L-0029` peels that exact logarithmic prefix. The remaining
connector obligation is still `Theta(t)` bits, so this does not prove that one
ordinary residual supplies the full-depth block or that cumulative initial
residues stabilize.

### C. Ordinary bulk generator

PR #3 `T-0030` supplies a positive finite sequence

```text
V_(m+1)=V_m+2^(m+1)V_m^2
```

that generates the quadratic control bulk without a preloaded `Z_2` oracle. It
remains an auxiliary word until an exact theorem puts it, or an affine transform
of it, in every residual Montgomery cylinder.

### D. Symbolic router

A Krieger/MacDonald router would still need a stationary legal stage graph,
periodic-point checks, and an arithmetic realization theorem. It would not by
itself initialize one positive integer.

### E. Positive branch

No eventually-zero directive is constructed. No finite positive initialization
is claimed. Therefore no `K-####` identifier is created.
