# An explicit 25/12 inverse compiler

**Collatz remains open.** This packet improves PR #147's explicit inverse
compiler from slope `13/6` to `25/12`, with exponent cap ten and an independently
checked finite strategy. The theorem builds predecessors of arbitrary targets;
it does not prove forward descent.

For the shortcut map `T(n)=n/2` for even `n`, `T(n)=(3n+1)/2` for odd `n`,
every `t>=1` and every ternary unit tail `0<c<3^t` admit a parity word with
exactly `t` odd events and

\[
T^k(2^k x+r)=3^t x+c\quad(x\ge1),\qquad0<r<2^k,
\]

\[
\boxed{k\le\left\lfloor\frac{25t+120}{12}\right\rfloor.}
\]

The same word works for every positive prefix `x`. The stronger bound using
the supplied tail's credit is `floor((25t+W(c)-13)/12)`.

## What changed

Instead of separately optimizing many possible odd gaps, the construction
uses only the physical inverse actions `E(z)=2z` and `O(z)=(2z-1)/3`.
Their integer credit inequalities retain every possible hidden ternary digit.
The class-one identity `W(z)=12+W(2z)` halves the stored state space and
improves the terminal refund. The resulting explicit table has
`0<=W<=133` on the units modulo `3^17`.

A chosen action costs one bit at each state where `O` is legal. The published
strategy is a 1,872,249-byte gzip file. Its potential is regenerated by a fixed
202-iteration maximum recurrence; regeneration performs no optimization or
search. The compact strategy reproduces the independently checked full table
exactly. [Full statement, encoding, proof, and forward boundary](PROOF.md).

| Quantity | Exact value |
|---|---:|
| Unit residues checked | 86,093,442 |
| Stored reduced credits after regeneration | 43,046,721 |
| Selected strategy bits | 28,697,814 |
| Full potential maximum | 133 |
| Actual selected odd-gap maximum | 10 |
| Directly checked collapsed gap lifts | 258,280,326 |
| Maximum terminal refund | 12 |
| Affine cone replays | 740 |
| Independent ordinary forward replays | 2,220 |

The actual gap maximum ten is an exhaustive result; the generic credit
argument alone gives twelve. The arithmetic theorem is universal because
the finite inequalities cover every residue and every hidden lift, followed
by the symbolic proof. The finite cone replays test the implementation.

## Reproduce

Run from the repository root, with Python 3 and a C++17 compiler:

```sh
python -B research/inverse-escape-20261120/verify.py research/inverse-escape-20261120/certificate.json
```

The command checks the compressed strategy's length, padding and digest,
compiles the fixed-strategy reconstructor in a temporary directory, rebuilds
the potential, authenticates every output byte, checks every selected reduced
inequality, and replays the affine cones. It rejects zero credit and truncated
data as negative controls. Four OpenMP threads are used by default; pass
`--no-openmp` for a portable single-thread compilation, or `--threads N` to
choose a thread count. The standard Python library is sufficient; NumPy is
not required by this verification path.

`--values PATH` reuses previously reconstructed raw credit bytes, with their
digest and every inequality still checked. It does not skip mathematical
verification.

The independently authored scalar checker, ordinary replay, encoding check,
and precise receipts are in
[`reports/inverse-physical-review-20261120/`](../../reports/inverse-physical-review-20261120/).
The reference full table used there is identified by its digest in
[`certificate.json`](certificate.json). It is reconstructed from the small
published strategy; no large binary potential needs to be fetched separately.

## Search and dependencies

[`search_physical.cpp`](search_physical.cpp) is the original two-action search.
[`search_reduced.cpp`](search_reduced.cpp) uses the one-class reduction and
optional parallelism. These programs propose tables. The fixed-strategy
reconstructor and the independent checks establish the delivered certificate;
the optimizer is not part of their trust boundary.

The search also found `15/7`, `17/8`, and `21/10` certificates, independently
checked before the final improvement. Their large tables are superseded by
the published `25/12` artifact. Two slope-two runs at precisions 18 and 19 did
not produce a certificate; their exact stopping observations and limited
scope are recorded in [SEARCH.md](SEARCH.md). Those failures concern specified
finite games and do not preclude a larger or different certificate.

This result uses no external ergodic or stationary-law theorem. It extends the
explicit construction at PR #147, frozen at
`b74b2d466f58844a742a6ed6bcdf06844269f361`. It does not claim to improve the
earlier packet's source-qualified existential `2t` inverse-prefix statement,
which has a different alphabet and onset and was not independently reviewed
here. The unresolved task remains an ordinary-source
forward descent or complete merger argument.
