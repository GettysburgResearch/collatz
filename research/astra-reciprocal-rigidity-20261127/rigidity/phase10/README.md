# Computing finite crossing budgets

[FIRST_CROSSING_BUDGET.md](FIRST_CROSSING_BUDGET.md) refines the escape-count characterization. A program parameterized by a proposed integer component count computes its finite gate sets without a list of representative sources. The resulting envelope is total precisely when the proposed budget is at least the actual count. At the true finite count it attains the exact logarithmic cost. The refinement is a written proof using the first-passage and finite path comparisons of [phase 9](../phase9/README.md).
