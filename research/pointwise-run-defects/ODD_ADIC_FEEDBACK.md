# Algebraic concentration and decision boundaries at every odd prime

**PROPOSED.** Let b_j=x_j mod 2 for a positive ordinary shortcut trajectory and record the pairs (j,x_j) in the p-adic integers for any finite list of odd primes p. In any stationary subsequential empirical limit of the shifted process, an ergodic component whose parity process is nonperiodic assigns zero mass to every algebraic curve

    P(t,x)=0,     P a nonzero polynomial over Q_p,                     (1)

at every one of these places. A periodic component here means its parity process is supported on the shifts of a single finite periodic word; the full joint law may have additional coordinates. The conclusion holds also for any stationary extension of the same clock and affine dynamics with p-adic clock marginal Haar.

Consequently, in the [real threshold prediction theorem](HEIGHT_FEEDBACK.md) one can give the machine additional finite-valued observations at finitely many odd primes: at each p, any fixed functions of (j,x_j) locally constant away from closed subsets of finitely many curves (1). This includes the signs of finitely many p-adic semialgebraic membership tests. On an infinite simple ordinary orbit the resulting inequality for every empirical limit is

    h₂(b) ≤ h₂(e) ≤ H₂(ε),                                            (2)

where e denotes the error bits and ε their limiting frequency. In particular a positive-entropy parity component cannot have exact prediction by such arithmetic data on that component. Combined with the polynomial-height occupation estimate, the same unconditional tradeoff δ/A≤H₂(ε) holds, and 1/A≤H₂(ε) for an ergodic parity limit with positive occupation below N^A. This extension makes an entropy claim; the polynomial envelope argument for exact real prediction does not automatically extend to singular odd-adic tests.

## Why the exceptional algebraic components are periodic

Work on a stationary ergodic component. The clock t advances by 1 on Z_p, so its unique invariant probability is Haar (each fixed residue ring is a single cycle). The height coordinate follows E(x)=x/2 or O(x)=(3x+1)/2 according to its recorded bit. These maps are continuous on Z_p, making the equations valid under weak convergence. The clock has no atoms.

Suppose an irreducible factor C of a curve (1), taken over an algebraic closure if needed, has positive probability. A positive return of this event at some lag d has positive probability by recurrence. Among its finitely many binary branch words one word w accounts for positive probability. Thus C and its inverse image under (t,x)↦(t+d,λx+a) have infinitely many joint points: the clock projection of a positive-probability set is infinite. Here λ=3^p_w/2^d, with p_w the number of ones in w and a rational offset. Two distinct irreducible plane curves can have only finitely many common points, so these curves coincide. A vertical component is already impossible by the clock marginal.

One has λ≠1. Center the second variable at the rational fixed point ξ=a/(1−λ). The irreducible defining polynomial B(t,Y) for C then obeys B(t+d,λY)=cB(t,Y) for some nonzero constant c. In the expansion Σ b_l(t)Y^l, comparison of the top t coefficient of every nonzero b_l forces c=λ^l. The positive rational λ is not a root of unity, so only one index l occurs; translation by d then forces b_l constant. Irreducibility leaves the horizontal line x=ξ.

In particular there is an atom at ξ. Almost every sample in the event x=ξ returns to that same event repeatedly. Every one of its return words fixes ξ exactly. Each cyclic phase of such a word is a rational with odd denominator, since its fixed point denominator divides 2^d−3^p_w. For adjacent phases y,y' and bit b the identity 2y'=3^b y+b then implies y≡b mod 2. All returns must therefore follow the unique true dyadic parity sequence of the same rational ξ, which is already periodic because one return exists. On a positive-probability event this periodic tail persists forever. Ergodicity and stationarity force the parity factor to be supported on its periodic shift orbit. This proves (1).

## Recovering predictions to vanishing information cost

For any fixed p, test values are decidable from (t,x) modulo p^k outside the union B_(p,k) of residue cells on which any test takes multiple values. These sets are clopen and decreasing in k. Their intersection lies in the specified closed exceptional sets, by local constancy and compactness of each cell. For usual semialgebraic predicates, p-adic quantifier elimination describes them as Boolean combinations of polynomial zero sets and conditions that polynomial values lie in a specified group of nonzero powers. The latter groups are clopen in Q_p^×, so only polynomial zeros can form boundaries. Equivalently the input tests can be stipulated directly with the stated boundary property.

Extend the empirical law to include the actual finite observations and machine state. On each nonperiodic ergodic component of this joint law the probability δ_k of the union of the B_(p,k) tends to zero by (1). In simulations at fixed precision k one stores the starting clock and height residues. Division by two is a unit operation at every listed prime, so the true bits update both registers through an arbitrarily long window without further residue information.

At a time falling in B_(p,k) at any place, supply the tuple of all true local test outcomes as a correction symbol c. At other times use one special blank. These symbols are functions of the joint path at that precision, with entropy rate at most H₂(δ_k)+δ_k log₂ M, where M bounds the number of corrected tuples. Given the initial registers, real threshold cells and machine state, a true word can now be simulated from its error and correction words, with the same bounded number of real-boundary ambiguities as in the real proof. For fixed k the extra initial register size is constant in the simulated word length m. The real polynomial word count, and then the entropy-rate argument, give h₂(b)≤h₂(e)+h₂(c). The counting bound applies on every component of the empirical support: any finite word in the support can occur on arbitrarily late ordinary samples, and membership of B_(p,k) is clopen. Letting k grow proves (2) componentwise when the parity factor is nonperiodic. On periodic parity components h₂(b)=0. Averaging conditional entropy rates over ergodic components gives (2) for the original stationary law, using the affinity of entropy rate for stationary processes.

The exclusion of the prime two from the observation set is necessary. At that place the clopen test of x modulo two recovers the true bit on every orbit. At an odd place the Borel set of ordinary positive odd integers would also recover that bit on the integers, but its boundary is all of Z_p. The null-boundary hypothesis on positive-entropy components has mathematical content.
