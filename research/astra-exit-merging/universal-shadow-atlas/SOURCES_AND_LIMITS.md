## What this pass does and does not establish

The all-gap theorem quantifies: for each fixed gap, there EXISTS a nonempty
explicit merging residue class. The all-prefix theorem similarly constructs
a SUBFAMILY in each finite parity cylinder. Neither quantifies over every
input in those cylinders. The atlas is complete only for its declared
shifts, synchronous tail clocks and finite horizon. The countable grammar
has unbounded state parameters and no proved global rank. The strict escape
theorem proves a genuine extension of the selected parent procedure, not
an extension of every certificate ever proved elsewhere in the repository.

Generator/verifier diversity is same-author implementation diversity.
The finite checks do not prove the unbounded theorems. Repository validation
would not do so either. The local archive and patch are publication material;
remote publication must be separately confirmed before it is claimed.
