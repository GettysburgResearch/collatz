# Periodic changes that also force the particular terminal cycle

**Theorem.** For every rational tolerance \(\epsilon>0\), one can compute a period \(2^L\) and a collection of odd classes of proportion at most \(\epsilon\) whose removal makes the residue graph uniformly descending and every positive integer orbit reach \((1,2)\). Consequently the minimum proportion with both properties tends to zero along all dyadic periods. The sharp two-sided rate in [the uniform-descent theorem](SHARP_PERIODIC_REMOVALS.md) applies to the residue graph condition. The period required for the stronger conclusion here can be much larger.


Start with any fixed \(k\ge2\) and the periodic removal \(R_k\) above. The base map \(F\) retains the cycle \(1,2\) (the two-step original word from 1 has multiplier \(3/4\)). From the strictly contracting block decomposition there exist a fixed horizon \(h\) and \(\lambda<1\) such that the multiplier of **every** base path of \(h\) steps is at most \(\lambda\): the incomplete terminal piece costs at most \((3/2)^k\) and the number of full blocks tends uniformly to infinity. Additive errors on \(h\) steps are bounded, so all sufficiently large integer starts descend within \(h\) steps. All orbits from a fixed finite set have a common finite height bound, by considering blocks of \(h\) steps and their intermediate growth.

The set \(E\) of starts \(e>1\) whose base orbit never visits a smaller integer is finite and computable. Each \(e\in E\) uses an upstep. Removing only these particular positive integers from the base up set gives a map \(F_*\) under which every start reaches \((1,2)\), by the same first-true-descent argument with no time cutoff. For \(L\ge k\), define \(F_L\) by additionally removing the entire class of each \(e\in E\) modulo \(2^L\) from the base up set. If \(E\) is empty there is nothing further to prove.

Consider positive integer paths from \(E\) following \(F\) except that a downstep is **optional** at every encounter with an element of \(E\). All such paths live in a common finite set \(J\): after an optional change the new source is one of the finitely many \(D(e)\); till the next change the path is a base orbit from one of these sources or from \(E\). Finitely many such base orbits are bounded. In the resulting finite graph, every directed cycle has strictly subunit homogeneous multiplier. Indeed a cycle's positive starting state satisfies \(x=Mx+c\) with \(c\ge0\); \(M=1\) is impossible by multiplicative independence of 2 and 3, and \(M>1\) is impossible at \(x>0\). Thus finite graph cycle decomposition gives a common \(j_0\) so large that **all** \(j_0\)-edge optional paths from \(E\) have multiplier less than \((3/2)^{-h}/2\).

If a positive lifted start is congruent to \(e\in E\) modulo \(2^L\), its next \(j_0\) choices under \(F_L\) shadow one of these optional finite paths when \(L\) is sufficiently large. After \(i\) matched choices, states agree modulo \(2^{L-i}\). Choose \(L-j_0\ge k\) and \(2^{L-j_0}>\max J+\max E+1\). Base decisions agree. If a new periodic switch occurs, the finite companion state must equal that element of \(E\), by the congruence and separation. At a companion point in \(E\), a lift can miss the particular periodic switch, which is why the finite graph includes the base option as well. This proves the claimed shadow.

From any origin, if no extra switch occurs in the first \(h\) steps, the base \(h\)-block contracts by \(\lambda\). Otherwise use the at most \(h-1\) preceding steps and then the \(j_0\)-step shadow after the first switch. Their total multiplier is less than \(1/2\). Hence for **all** sufficiently large \(L\) every origin has a contracting block of length at most \(h+j_0\), multiplier at most \(\max(\lambda,1/2)<1\). Additive errors through this bounded duration give a common cutoff \(B'\), independent of \(L\), above which each block truly lowers the starting integer. Below \(B'\) there are finitely many actual \(F_*\)-paths to \((1,2)\). Choose \(L\) larger again so all their states and all of \(E\) are smaller than \(2^L\). The maps agree on every state of these paths. This proves global convergence for \(F_L\), and the contracting blocks prove uniform residue-graph descent by lifting repeated paths.

The additional removed density is at most \(|E|/2^L\), arbitrarily small for each fixed \(k\). Now let \(k\to\infty\). The least density of periodic removals having **both** uniform descent and actual convergence to \((1,2)\) therefore tends to zero as the allowed dyadic modulus tends to infinity. The property persists when a given rule is represented at a larger power-of-two modulus. All choices are effective. Given \(\epsilon\), enumerate the explicitly computed survivor counts until \(|R_k|/2^k<\epsilon/2\), take an integer \(h\) guaranteed by the displayed block decomposition, and compute the true-descent cutoff as the additive-error bound divided by \(1-\lambda\). Enumerate the finitely many lower starts until each descends or repeats, which identifies \(E\). Enumerate the finite optional graph and use exact rational path products to find \(j_0\) by a terminating search. Compute \(B'\) the same way, run the finitely many specified \(F_*\)-paths to one, then choose \(L\) meeting the congruence, path, and density bounds.
