# Public-launch gates

Integration into main is not a visibility change, license selection, security clearance or mathematical promotion. These are the remaining decisions and receipts, not another research dashboard. [Issue #96](https://github.com/GettysburgResearch/collatz/issues/96) tracks their disposition.

| Gate | State and required receipt |
|---|---|
| Text/code/data terms and third-party provenance | **MIT CHOSEN — THIRD-PARTY REVIEW REMAINS OPEN.** Project code and original research materials use the [MIT License](../LICENSE). Third-party material retains its existing terms and notices; redistribution rights for external fragments and legacy data still require review. The external dossiers remain source-qualified references; no Mazur PDFs are redistributed. |
| Privacy, security and repository protections | **PARTIAL.** The [bounded security receipt](SECURITY_REVIEW_2026-09-05.md) covers its exact earlier commit and stated text/history scope. Binary material, discussions and attachments were excluded; historical attribution metadata remains an owner privacy decision. Confirm current visibility, team access, code-owner resolution and enforceable branch rules before launch. |
| Complete final-checkout validation | **OPEN — NO FULL RUN RECEIPT YET.** The single [validation entry point](REPLAY_POLICY.md#one-checkout-one-receipt) runs the preserved structural checks, D follow-up and optional bounded replays. Retain the exact commit/tree, stdout, stderr and exit codes. Local fixtures and API readback do not satisfy this gate. |
| GitHub-hosted validation | **PREPARED; EXECUTION NOT ESTABLISHED.** The read-only [workflow](../.github/workflows/validate-repository.yml) is ready. Actions was disabled in the administrative snapshot and no run was observed during final preparation. The connected tools do not expose the setting to enable it. An owner can enable the reviewed workflow, or supply a complete-checkout receipt from another trusted execution environment. Do not mark a missing run successful. |
| Contributor walkthrough | **PREPARED, NOT END-TO-END TESTED.** Complete the fresh-user [phone acceptance test](PHONE.md#maintainer-acceptance-test) before describing mobile publication as tested. |
| Exact replacement/synthesis promotion | **INTENTIONALLY QUALIFIED.** The existing periodic synthesis, bridge, four reference assemblies and exact replacement wording retain their pending/source-qualified statuses. E-D corrections are visible with their own identities. Honest publication does not require solving all open questions or promoting these statements. |
| External and historical computation | **EXPLICIT EVIDENCE CEILINGS.** Unperformed Lean builds, large payload replays and historical corpora remain labeled. A decision to cite an external result is distinct from independently verifying all its computation. |

The current readiness pass supplies contributor navigation, a nonmutating validation command, a portable mode check and a least-privilege workflow. It does not grant a license, rewrite history, change membership, make the repository public or override an owner's Actions/branch-policy settings. Read the [final preparation receipt](../reports/readiness-2026-09-06/README.md) for the actual tests and scope.
