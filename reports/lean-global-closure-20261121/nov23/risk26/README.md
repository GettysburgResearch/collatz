## Publication boundary

The checkpoint's file manifest binds the science, reports, source
ledger and parent entry-point update; it excludes itself. The complete
checkout gate is run on the exact GitHub-created commit, with a clean
index and worktree, before updating our PR175 branch. That commit's
full gate receipt and receipt hash are recorded in the PR publication
body, where they do not create a self-referential commit hash.

The gate checks repository integrity. It does not upgrade the written
theorems to formal proofs, establish the remaining hypotheses, or
prove Collatz. Remote branch, commit tree, parent, and PR description
are read back after publication.
