## 5. Adversarial findings

**G1 — statement-level erratum with explicit witness (`s = 0` / all-zero word).**
Theorem 1 item 3's boxed claim "If `3^s < 2^L`, then `x_w > 0`; it is a positive
ordinary realization exactly when `2^L − 3^s ∣ C_w`" is **false as literally
quantified**. Witness `w = (0)` (any `w = 0^L`, `L ≥ 1`): `3^0 = 1 < 2 = 2^L`; (10)
holds vacuously (`|2^L − 1|` divides `C_w = 0`); yet `x_w = 0/(2^L − 1) = 0` — not
positive and not on a positive cycle. The proof paragraph itself concedes the case
("the all-zero case gives only `x_w = 0`"), so this is a missing hypothesis (`s ≥ 1`,
i.e. "`w` contains a `1`"), not a broken argument — but the same unguarded phrasing
recurs in the PR body's classification block, the packet `README.md` "Main theorem"
block, and §4 of the session report. Item 2 needs no guard (supercriticality forces
`s ≥ 1`). Downstream harmless: Theorem 2 is unaffected because no positive integer has
an all-zero tail (`2^k ∣ y` for all `k` forces `y = 0`; Check 8c). Our packet's
L-9904.5(ii) states the split (`a ≥ 1` vs `a = 0`) correctly and is the drop-in fix.

**G2 — compressed induction in Lemma 1.** Display (6) presupposes the two lifts follow
common branches through step `j`, while the parity agreement that guarantees this is
being derived *from* (6): the correct argument proves the difference formula and the
bit equality **simultaneously** by induction on `j`. This joint induction is exactly
L-9902.1(b) (PROVED, spelled out); rigor compression only, no mathematical damage.

**G3 — unproved framing fact in Corollary 2.1.** "Any autonomous finite-state machine
emits an eventually periodic parity word" is classical (finite state space ⟹ the
autonomous state sequence revisits a state ⟹ periodic tail) but is asserted without
proof and silently assumes **determinism**; a nondeterministic autonomous machine can
emit aperiodic words. One sentence plus the word "deterministic" repairs it.

**Quantifier / bookkeeping audit (all clean).** (a) Purely-periodic (Thm 1) vs
eventually-periodic (Thm 2) are correctly separated, and Thm 2 quantifies over *every*
decomposition `u w^∞` — sound, since only `V(T^{|u|} x_0) = w^∞` is used. (b) `w`
nonempty is required and needed: `L = 0` would make `2^0 − 3^0 = 0` and (8) undefined;
our L-9904.5(ii) likewise requires `K ≥ 1`. (c) Denominator bookkeeping is right: odd,
nonzero, `Z_2`-unit; `|·|` in (9) correctly handles negative denominators (e.g.
`w = (1)`: `|2 − 3| = 1 ∣ 1`, `x_w = −1`, an integer, and item 2 — not item 3 —
applies). (d) "Period divides `L`" is correct including non-primitive words
(`1^L ↦ −1`, least period 1; `(1,0,1,0) ↦ 1`, least period 2 ∣ 4; Checks 6–7).
(e) The file does **not** overreach: aperiodic itineraries, divergence, and Collatz are
explicitly left open (§8), the trivial necklace is audited (§5), and "a finite
preperiod still requires exact positive preimage replay" correctly flags that a
prescribed `u w^∞` need not have a positive-integer realizer at all. (f) §5's example
values are exact: `(110)^∞ ↦ −5`; `(1110)^∞ ↦ −19/11` (Check 5).

**Refutation attempts that failed (evidence of robustness).** Exhaustive Theorem-1
verification over all 510 nonempty words `|w| ≤ 8` (fixed point, itinerary,
integrality ⟺ (9), signs for `s ≥ 1`, least-period divisibility) plus the `K = 11`
word of the `−17` cycle and all 11 of its rotations; five positive-integer
eventually-periodic seeds and one non-integer rational seed; no discrepancy anywhere.
The only "hit" is the G1 boundary witness, which the PR's own proof text anticipates.

```python
#!/usr/bin/env python3
# Adversarial finite verification for the review of PR #61 claim T-7401
# (eventually-periodic dichotomy / full-denominator divisibility).
# Reviewer: fable-02-r1, 2026-07-27.  Exact arithmetic only (int, Fraction).
#
# Cross-checked against fable-02 packet notation:
#   PR C_w  == rho(w)   (L-9903.2 closed form == recursion == PR formula (4))
#   PR (5)  == Lemma A of L-9904 / L-9903.1:  2^L T^L(z) = 3^s z + C_w
#   PR (6)  == L-9902.1(b) with m=1:  T^j(r+2^n) - T^j(r) = 3^{a_j(r)} 2^{n-j}
#   PR Thm 1 (8) == L-9904.5(ii):  x_w = rho_w/(2^L - 3^s), T^L(x_w) = x_w
#   PR Thm 1 (9)/(10): integrality <=> |2^L-3^s| | C_w ; sign classification
#   PR Thm 2: eventually periodic positive integer -> tail seed x_w

from fractions import Fraction

FAIL = []
def chk(cond, label):
    if not cond:
        FAIL.append(label)
        print("FAIL:", label)

def T(x):
    """Shortcut map on Z_(2) (rationals with odd denominator), exact."""
    x = Fraction(x)
    assert x.denominator % 2 == 1, "not in Z_(2)"
    return x / 2 if x.numerator % 2 == 0 else (3 * x + 1) / 2

def word_of(x, k):
    """First k parity bits of x in Z_(2)."""
    x = Fraction(x); w = []
    for _ in range(k):
        b = x.numerator % 2
        w.append(b)
        x = x / 2 if b == 0 else (3 * x + 1) / 2
    return tuple(w)

def rho_rec(w):
    """L-9903 recursion: r_{i+1} = 3^{w_i} r_i + w_i 2^i."""
    r = 0
    for i, wi in enumerate(w):
        r = 3**wi * r + wi * 2**i
    return r

def rho_closed(w):
    """L-9903.2 closed form: sum over ones of 3^{#ones strictly after} 2^i."""
    L = len(w)
    return sum(3**sum(w[i+1:]) * 2**i for i in range(L) if w[i] == 1)

def C_pr(w):
    """PR #61 formula (4): C_w = sum_j eps_j 2^j 3^{s - s_{j+1}}, s_j = sum_{i<j} eps_i."""
    L = len(w)
    S = [0]
    for e in w:
        S.append(S[-1] + e)
    s = S[L]
    return sum(w[j] * 2**j * 3**(s - S[j + 1]) for j in range(L))

def all_words(L):
    return [tuple((n >> i) & 1 for i in range(L)) for n in range(2**L)]

# ---------- Check 1: C_w (PR eq. 4) == rho recursion == rho closed form, |w| <= 12
n1 = 0
for L in range(0, 13):
    for w in all_words(L):
        a, b, c = rho_rec(w), rho_closed(w), C_pr(w)
        chk(a == b == c, f"C_w formulas disagree at w={w}: {a},{b},{c}")
        n1 += 1
print(f"Check 1 PASS: C_w == rho_rec == rho_closed on all {n1} words |w| <= 12")

# ---------- Check 2: PR Lemma 1 eq. (6) == L-9902.1(b), m=1: exhaustive n <= 10
n2 = 0
for n in range(1, 11):
    for r in range(2**n):
        wr = word_of(r, n)
        x, y = Fraction(r), Fraction(r + 2**n)
        for j in range(n + 1):
            aj = sum(wr[:j])
            chk(y - x == Fraction(3**aj * 2**(n - j)),
                f"(6) fails n={n} r={r} j={j}")
            n2 += 1
            if j < n:
                chk((y.numerator % 2) == (x.numerator % 2), f"parity split early n={n} r={r} j={j}")
                x, y = T(x), T(y)
        # at j=n difference is odd => opposite next bits
        chk((x.numerator - y.numerator) % 2 == 1, f"flip fails n={n} r={r}")
print(f"Check 2 PASS: lift-difference identity (6) on {n2} triples (n<=10, all r, all j)")

# ---------- Check 3: PR Lemma 1 bijection (== L-9902.2 / L-9904.2), n <= 12
realizer = {}   # length -> {word: residue}
for n in range(1, 13):
    m = {}
    for r in range(2**n):
        m[word_of(r, n)] = r
    chk(len(m) == 2**n, f"pi_{n} not injective/surjective")
    realizer[n] = m
print("Check 3 PASS: word -> residue mod 2^n bijection, n = 1..12")

# ---------- Check 4: PR eq. (5) == Lemma A: 2^L T^L(z) = 3^s z + C_w on the cylinder
n4 = 0
for L in range(1, 9):
    for w in all_words(L):
        s, C = sum(w), C_pr(w)
        r = realizer[L][w]
        for z in (Fraction(r), Fraction(r) + 2**L * 7, Fraction(r) - 2**L * 9,
                  Fraction(r) + 2**L * Fraction(4, 5)):
            chk(word_of(z, L) == w, f"cylinder membership fails w={w} z={z}")
            y = z
            for _ in range(L):
                y = T(y)
            chk(2**L * y == 3**s * z + C, f"(5) fails w={w} z={z}")
            n4 += 1
print(f"Check 4 PASS: affine composition (5) on {n4} (word, point) pairs, |w| <= 8")

# ---------- Check 5: seed formula anchors (known cycles)
anchors = [
    ((1, 0), Fraction(1)),                                  # trivial cycle, seed 1
    ((0, 1), Fraction(2)),                                  # rotation, seed 2
```
