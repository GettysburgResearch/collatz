## Exact missing inference

For any fixed infinite control path in an odd-affine dyadic machine, exact
integrality through depth `N` gives one least initial residue

```text
R_N mod 2^(D_N).
```

The residues are nested.  Writing

```text
R_(N+1)=R_N+a_N*2^(D_N),
```

one ordinary nonnegative initial integer exists exactly when

```text
a_N=0 eventually.
```

This is `T-0043`.

The repository repeatedly establishes the left side of the following invalid
inference:

```text
all finite prefixes are compatible
  -> one infinite completion exists
  -/-> one ordinary finite integer exists.
```

The right conclusion requires eventual stabilization of the least pulled-back
representatives.  Compactness, branch count, pressure, modular SCCs, complete
projection, and local `Z_2` isometries do not imply that stabilization.

## New scope theorem for selectors

`L-0039` corrects an over-optimistic reading of the all-precision collision
compiler.

A code with `2^b` branches of length `L` and complete projection modulo `2^b`
occupies exactly one full residue modulo `2^L` above each low `b`-bit cell.  A
low-bit request chooses a candidate branch, but the current integer is legal for
that branch only if its remaining `L-b` source bits also match.

Therefore:

```text
complete correction coverage != causal source orientation.
```

This does not refute a top-boundary-carrying selector.  It proves that the top
boundary is the missing mathematical state rather than an implementation detail.

## Genuinely weaker global target

For any fixed restricted refund machine `M`, prove one side of:

```text
positive:
  one explicit ordinary state is defined forever;

negative:
  every infinite legal directive has infinitely many nonzero pulled-back high
  blocks, equivalently every ordinary state eventually exits M.
```

The positive side yields a `K`-candidate through the machine's existing physical
replay and growth theorem.  The negative side eliminates the entire strict
architecture and is therefore genuinely weaker than Collatz.

A common negative theorem for the four refund machines listed in PR #38 would
close the repository's current direct-divergence portfolio without claiming a
global Collatz proof.
