## Reproduce the packet

From a complete clean checkout:

```sh
python -X utf8 -B reports/2026-11-21-global-certificate-closure/verify_packet.py --receipt /tmp/global-certificate-science.json
python -X utf8 -B tools/validate.py --regressions --receipt /tmp/global-certificate-repository.json
```

The frozen manifest includes the research files, deterministic expected
reports, source snapshot, and runner. It excludes itself and the mutable
publication documentation and receipts, avoiding a circular hash claim.

Receipts must be outside the checkout. The first command checks the frozen
manifest, executes author and independent programs in both modes, compares
complete reports, and confirms the checkout remained clean at the same
head and tree. `--manifest-only` omits executions when checking a later
documentation-only child. The second is the repository's required
integrity and bounded-regression gate. Neither proves the conjecture.
