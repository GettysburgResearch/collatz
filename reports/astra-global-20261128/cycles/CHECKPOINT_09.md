# Complete ordinary source fibres and parity pairs to critical time

For uniform $n\in[X,2X)$ and $2^N=o(X)$, [the complete fibre theorem](../../../research/astra-global-20261128/cycles/ORDINARY_SOURCE_FIBRES.md) counts every $m$ in the same octave having the same genuine date-$j$ endpoint as $n$. At once for all $j\le N$, the log count is $j\log2-k_j(n)\log3+O_{\Pr}(\log N)$. For a fixed list of affine inputs $A_i n+b_i$, require a single $m$ to preserve all endpoints at the same date. The formula then uses the **largest** of the actual odd counts across the list. The shared physical parameter constrains the complete joint endpoint vector to a small neighborhood of a line at each fixed grade tuple. One typical common fibre has $\exp((\log(4/3)/2)N+o(N))$ ordinary starts. Under the previous pairwise nonsmooth grade invariance principle, its centred path fluctuates as the negative maximum of independent Brownian motions with scale $(\log3)/2$. For two such sources the conditional Shannon entropy of the second true endpoint given the first is $(\log3)/(2\sqrt\pi)\sqrt N+o(\sqrt N)$ when $\sqrt N2^N=o(X)$. The one-coordinate fibre theorem is elementary apart from the standard fair-walk invariance principle.

[The paired parity-word theorem](../../../research/astra-global-20261128/cycles/PRECRITICAL_PAIR_WORDS.md) proves that every prescribed pair of length-$k$ words at two nonsmooth ordinary affine sources has synchronous frequency $4^{-k}$ in probability through **the full critical time** $2\log X/\log(4/3)$. The real common parameter after an epoch is the integer part of $3^{\min_i k_i}n/2^s$; subexponentially many possible intercepts retain the actual endpoints. A quantitative dyadic incidence/entropy bound beats this number of parameter choices. This conclusion concerns complete empirical pair words. It also passes to a random physical clock asymptotic to the critical time, including the true first-minimum clock under its separately stated scalar input. A joint Brownian invariance principle beyond the direct binary horizon remains unproved.

[The affine overlap law](../../../research/astra-global-20261128/cycles/TILTED_FUSION.md) uses the exact common part of nonfair tilted parity measures on their genuine affine fusion cylinders. PR 215 already proves the corresponding same-bias classification for arbitrary two-adic affine maps. For true upper-grade tails, the asymptotic intersection relative to one tail is the mass of the greatest common submeasure of the affine pullbacks. This gives finite-dimensional relative counts for actual simultaneous nondecrease at the tested ordinary clock, using the physical critical tilt. Among translated sources a nonzero fixed shift has synchronization probability strictly between zero and $1-|2p-1|$ inclusive at the upper endpoint, under the counted-fusion input used for strict positivity. On a nonsmooth pair the coefficient vanishes. This addresses the tested native endpoint size; it leaves eventual fates unrestricted.

[The translation-class bounds](../../../research/astra-global-20261128/cycles/FUSION_GEOMETRY.md) give expected occupancy $O(H^{\log_2(1+2\sqrt{p(1-p)})})$ on every length-$H$ shift interval for nonfair $p$. Above $p=\log_3 2$ the entire true integer-translation fusion class is finite almost surely, by a finite real affine boundary and the measure-preserving translations within classes. In the separate range $H(p)>p\log3$ it is infinite with exponential finite-stage growth. The critical class can still be finite or infinite. For an exact near-critical grade $k$ the conditional chance of a nonfused equal grade at moving displacement $h$ is at most $C\exp[-ct/(\log(2+|h|)+|k-t\log_3 2|+t^{2/3})]$.

[The ordinary endpoint information theorem](../../../research/astra-global-20261128/cycles/TERMINAL_INFORMATION.md) identifies a clipped Gaussian for the sampled log reciprocal endpoint mass divided by $\sqrt{\log X}$ at the full critical clock window. For any tested date later than the critical clock by $\gg\sqrt{\log X\log\log X}$ in the ratio-to-infinity sense, the Shannon entropy of the entire true endpoint distribution divided by $\frac12\log\log X$ tends exactly to the total escaping-component density. The inputs are PR 215's stopped native endpoint law and PR 213's uniform nonperiodic atom bound and periodic total-variation law. In particular an independent $o(\log\log X)$ entropy upper at $(\log X)^2$ would exclude every escape by positive predecessor density. Such an independent upper remains open.

[The smooth-multiplier path theorem](../../../research/astra-global-20261128/cycles/COALESCING_GRADE_PATHS.md) treats a finite family $A_i3^{e_i}n+b_i$ with fixed normalized odd bases, $e_i/\sqrt N\to u_i$ and $\log(2+|b_i|)=o(N)$. The adjusted grade paths converge to coalescing Brownian motions started at $2u_i$ within each common base and independent systems between bases. This holds on each fixed bounded time interval for a common Haar source and through date $sN$ on ordinary intervals of length $X$ when $2^{\lceil sN\rceil}=o(X)$. PR 214 already proves the scalar two-source merger profile, with uniform full-horizon ordinary interval transfer. The path theorem identifies the joint trajectories and physical synchronization at the diffusive grade crossing.
