# Broad track checkpoint 2 · 2026-11-28 00:25 UTC

**Full Collatz remains open.** The pointwise pin criterion now has an end-to-end Lean proof. The written arithmetic results below constrain particular forms of a hypothetical counterexample. They do not provide the required uniform linear bound on all greedy pin depths.

| Result | Status and boundary |
|---|---|
| [Exact pointwise pin criterion](../../../research/astra-global-20261128/broad/PinCriterion.lean) | Strict Lean 4.34.1 compile passed. For each positive source, bounded discounted rank at its greedy pin clocks is equivalent to hitting 1. No boundedness premise is discharged. Three former private lemmas in PinClock are exposed to this bridge. |
| [Uniform arithmetic-gap bound](../../../research/astra-global-20261128/broad/QUADRATIC_CLOCK_PADE.md) | Elementary, written proof using Padé forms. A physical prefix of $1^a0\,1^b0\,1^{b+h}0\cdots$ has $L\le1000\log_2(x+1)$ for all $a,b\ge0$, $h\ge1$, uniformly even as the number of even events grows. Root independently reconstructed the height, valuation and physical cutoff. The published dyadic irrationality and an explicit prior Collatz ray are credited, as is repository PR 48 for a different run-core model. |

The physical bound is $L\le20\,000\log_2(x+1)$. With the zero-slope exception and increasing case this forces at least logarithmically many changes of gap slope with physical time on a nonperiodic positive orbit. No Lean verification of either Padé argument at this checkpoint. |
| [Macroscopic odd mass](../../../research/astra-global-20261128/broad/MACROSCOPIC_ODD_MASS.md) and [signed rational matches](../../../research/astra-global-20261128/broad/RATIONAL_MATCH_MASS.md) | Written proofs invoking Evertse 1984 Theorem 2. ## Replays

The new [transport checker](../../../research/astra-global-20261128/broad/check_transport.py) gave identical results under ordinary Python and optimized Python, using explicit runtime guards. It checked 384 signed five-term transport families with 1,536 odd carries and 11,904 nonzero subsums, 6,656 ordinary correction edges and 1,983 same-endpoint cofactor comparisons including 1,044 exact zero forms, 80 increasing Padé forms, 240 positive quadratic prefix cylinders, and 12 decreasing forms with 60 strictly higher physical tails.

The [alternant and real-path checker](../../../research/astra-global-20261128/broad/check_schur.py) passed 800 Schur cases and 1,200 prescribed real steps under both modes. Its real path had 1,037 odd instructions and final reduced denominator $2^{1194}$. No finite replay is used as evidence that a divergent ordinary orbit exists or that all examples are covered.

A further endpoint would require a growing-arity argument on irregularly changing gaps, or an amplification forcing an orbit to contain one of the now-forbidden long windows. All present estimates are compatible with microscopic, nonperiodic, irregular gap schedules.
