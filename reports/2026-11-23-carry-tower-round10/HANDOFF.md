# Remaining construction obligations after round ten

The actual odd map, infinite real scalar, exact tails, and the
equivalence between reaching one and triadic scalar arithmetic now
have an actual-map Lean proof. This fulfills the scalar-formalization
item in the round-nine handoff. The universal arithmetic input is
still absent.

## 1. Control changes of return type at one ordinary source

Every prescribed expanding word has a full affine center, and its
binary distance to that center can bound consecutive repetitions.
For R=L^11P, the exact rank drops by 38 per repetition. A different
paid word changes that center. The next decisive lemma would control
those changes without discarding the preceding unpaid expansion.

The growth theorem restricts m_j to a source-dependent envelope,
and an actual 7/8 tail requires a cumulative unpaid mean of at least
the exact theta in RETURN_TOWER.md. Both inequalities permit slowly
changing schedules. Repeating the one-return algorithm alone is not
a terminating universal decision procedure.

## 2. Use the general phase transformer with a genuine global rank

GENERAL_PHASE_RETURN.md constructs an actual finite return or a
sound rejection for every supplied rational canonical phase. Its
budget bl(q)+2v_2(|Dq+C|) is explicit. The returned phase can differ
from the starting phase, and its physical source can exceed the
original source after a long zero-carry prefix.

A next theorem must compare the full returned state, including the
phase and the paid expansion cost, in a well-founded order or an
equivalent bounded accounting argument. The sharp 1456 W/V family
shows why a per-excursion contraction by itself is insufficient.

## 3. Extend rational-height obstructions beyond sparse scripts

The elementary 2-adic proof excludes all paid-position schedules
with limsup 8^(t_(r+1))/9^(t_r)=infinity. Four explicit automatic
families satisfy it and have linear finite mismatch budgets for
every positive ordinary source.

Automaticity and bounded carries do not imply that hypothesis.
The displayed k=5 family already lies outside this particular gap
test. A stronger arithmetic argument must retain the actual rational
numerator and all additive terms while handling denser or less
regular paid schedules. Real and 2-adic series values must remain
separate.

## 4. Construct the triadic value, rather than assuming one is supplied

ActualScalar.converges_iff_triadic proves an equivalence. It does
not construct a and r with scalar(q)=a/3^r for every positive odd q.
The prior source law, rational approximation, complete denominator
caps, and present return obstructions do not establish that
universal membership assertion or rule out every irrational value.

The high-value formal target is to connect a genuinely new
ordinary-source arithmetic lemma to the existing actual scalar
module. Inserting the universal triadic assertion as an axiom
would leave the original problem unchanged.

## Preserved source qualifications

The pressure maximum, the global least source on a scalar level,
the supplied source of a candidate procedure, and a changing
finite-cylinder representative are different objects. The
round-ten results do not identify them. Future arguments using
several of these constructions must explicitly prove any transfer
between their sources and preserve each source's hypotheses.
