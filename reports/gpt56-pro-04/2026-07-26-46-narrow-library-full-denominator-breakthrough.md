## 2. New theorem — `L-9608`

Let a finite accelerated-block library share one summary

\[
P=3^k,
\qquad
Q=2^A,
\qquad
Q>P,
\]

and let its affine constants lie in an interval of width

\[
W< Q.
\]

For an arbitrary ordered word of `R` library blocks, the composite numerator is

\[
C_{\mathbf s}
=\sum_{j=0}^{R-1}P^{R-1-j}Q^jC_{s_j}.
\]

If the entire cycle denominator divides this numerator,

\[
Q^R-P^R\mid C_{\mathbf s},
\]

then

\[
C_{s_0}=C_{s_1}=\cdots=C_{s_{R-1}}.
\]

The resulting pure constant class is a divisor hit exactly when

\[
Q-P\mid C_s.
\]

Thus no narrow equal-summary library can create a new full-denominator cycle by mixing block types, changing their order, or increasing repetition length.

## 3. Proof mechanism

Put

\[
C_s=C_*+\delta_s,
\qquad 0\le\delta_s\le W,
\]

and

\[
G_R={Q^R-P^R\over Q-P}.
\]

Full denominator divisibility implies

\[
G_R\mid
H=\sum_{j=0}^{R-1}P^{R-1-j}Q^j\delta_{s_j}.
\]

Because every weight is positive,

\[
0\le H\le WG_R,
\]

so `H=tG_R` for one integer `0<=t<=W`. Subtracting gives

\[
\sum_{j=0}^{R-1}P^{R-1-j}Q^j
(\delta_{s_j}-t)=0.
\]

Modulo `Q`, only the first coefficient remains. Since `P` is odd and

\[
|\delta_{s_0}-t|\le W<Q,
\]

that coefficient is zero. Divide by `Q` and repeat. Every coefficient is zero.

This is a full-denominator carry theorem, not a proper-factor sieve. The associated carry recurrence is

\[
Qc_{j+1}=Pc_j+\delta_{s_j}-t,
\qquad c_0=c_R=0.
\]

The diameter bound kills the first nonzero carry and therefore all later carries.

## 4. Sharp architecture boundary

The theorem proves that a genuinely mixed equal-summary repair circuit must satisfy at least

\[
\boxed{
\max C_s-\min C_s\ge2^A.
}
\]

For a family generated by pairwise disjoint same-summary replacements with signed corrections `Delta_j`, the sufficient rigidity condition is

\[
\sum_j|\Delta_j|<2^A.
\]

This remains exact when the local corrections are the pure `{2,3}`-unit Christoffel/Farey commutators of `L-9606`.

Accordingly, simply adding a third, fourth, or thousandth equal-summary block type does not escape the earlier aligned binary obstruction. The library must span at least one complete dyadic radix, change summaries with scale, or use genuinely overlapping/nonaligned structure outside one fixed block alphabet.
