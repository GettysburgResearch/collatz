# Validation identities and execution scope

Repository validation and mathematical verification are different events.
The repository command checks structure, frozen identities and eleven
selected bounded regressions. The six new scientific commands replay the
finite cores, modular certificates, affine merger identities, interval
bounds and guarded rewriting corpus described in the proof packet.

Each frozen JSON report was generated by an actual completed execution.
The review reports separately identify independent reconstructions and
their limits. In particular, the second cap-four core enumeration is not
represented as a second cap-six enumeration; the modular independent
checker verifies maxima, not the first scanner's ordered digests.

Clean-checkout receipts are attached with the exact tested content commit
and tree. A later documentation commit can attach those receipts without
changing their historical execution scope. An execution on a parent is
not described as an execution on its child, and no self-referential final
head receipt is asserted.

No proof-assistant build, external peer review, unrestricted Collatz
termination test, or successful all-source descent selector is claimed.
