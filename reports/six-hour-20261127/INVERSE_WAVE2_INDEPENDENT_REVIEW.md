**Independent finite evidence.** `proof_controls.py` followed one positive pool for all \(h\), applied the exact slope separately to each candidate, and stopped each signed path at an actual mark or repeat. It tested 150 distinct signed inputs. The counts of successful \((s,w,D)\) tuples for \(h=0,\dots,6\) are \(0,0,0,1,3,10,21\). It reconstructed an ordinary CRT solution for all 35 tuples on all seven phases and directly replayed all 245 concatenations. The resulting rank sets are respectively empty, empty, empty, \(\{1\}\), \(\{1,2,3\}\), \(\{1,2,3,4,7,9\}\), and \(\{1,\ldots,9,25,27\}\). Normal and optimized Python produced identical bytes, SHA-256 `4cf9b8406c343c485ca48e24fd5c704888c172e0f12f50c3a1e2b64ba7615ba2`. A minor receipt description in the source says its replay “gives all successful triples”; its code computes them but its frozen JSON prints the rank sets and last-rank examples. It forwards one tuple per rank to all phases. These different coverage claims should remain explicit.

**Prior comparison.** Weaver's Paper 108 explicitly proves a bounded eventual negative-cycle dictionary and restricts its ordinary/signed correspondence to the original rank. Paper 1 and the accompanying discussion already contain the identical four-extra affine source **and** its ternary residue, on a different binary cylinder; the new result decides exactly which of these specific seven-phase cylinders can bypass the principal ancestor. Paper 178 has the earlier negative-five obstruction. Paper 180 already uses a second *positive* reference source, positive distortion and remaining ternary rank in a different delayed-first-meeting construction. Its Section 5 turns recurrent divergence in a different exceptional set into a nonvanishing failure estimate. The broad technique of a second positive anchor or an escape-recurrence criterion therefore cannot be claimed as new. This review compares these specific sources; it gives no exhaustive priority verdict.
