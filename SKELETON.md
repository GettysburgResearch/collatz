## 1. Setting: the skeleton normal form

Fix coprime radices `M < N` (all our charts: `M = 2^L`, `N = 3^a`,
multiplicatively independent) and a finite digit alphabet
`D ⊂ {0,…,M−1}`, inducing `H_D(MB+d) = NB+d`. The run-length skeleton
(the normal form introduced on the PR #3 branch, its T-0004): any
induced orbit decomposes into maximal constant-digit phases
`d + M^u C ↦ d + N^u C`, and an infinite orbit is equivalent to an
infinite chain

    (⋆)   d_k + N^{u_k} C_k = d_{k+1} + M^{u_{k+1}} C_{k+1},
          d_k ∈ D,  d_{k+1} ≠ d_k,  u_k ≥ 1,  M ∤ C_{k+1}.

Cross-verification: `skeleton_rigidity.py` Part 1 extracts phases from
exact coded orbits of all four verified charts (64→81, 512→729,
2¹⁷→3¹¹, 2²²→3¹⁴) and confirms every phase identity and chain link
exactly — 1021 links, zero failures.

Writing `δ_k = d_k − d_{k+1}` (so `|δ_k| < M`), (⋆) is the
bounded-difference identity

    (⋆′)   N^{u_k} C_k − M^{u_{k+1}} C_{k+1} = −δ_k,   |δ_k| bounded.

## 2. Theorem (skeleton rigidity; T-0020)

**Definitions.** A *finite cyclic exp-poly schema family* for a chain
(⋆) consists of: a period `m ≥ 1` such that, for all large `k`, writing
`k = jm + i` (`0 ≤ i < m`),

* `u_{jm+i} = α_i j + β_i` with integers `α_i ≥ 0, β_i` (*affine
  exponent schedules*), and
* `C_{jm+i} = E_i(j)`, where `E_i(j) = Σ_r P_{i,r}(j) ρ_{i,r}^j` is an
  exponential-polynomial with real polynomial coefficients and
  distinct positive real ratios `ρ_{i,r}` — **no arithmetic hypothesis
  on the ratios**.

(The digits `d_k` need not be schema-determined; only boundedness of
`δ_k` is used. The `C_k` are positive integers — used critically.
This class contains the RLE/geometric cofactor schemas — the skeleton
analogue of the certificate class killed by T-0013 — *and* the
Pisot-substitution schemas with algebraic ratios.)

**Theorem.** Let `M < N` be coprime and multiplicatively independent.
No infinite skeleton chain (⋆) of a nontrivial induced orbit is
generated by a finite cyclic exp-poly schema family, except chains
with bounded state `(d_k, u_k, C_k)` — and a bounded-state chain is
eventually periodic, hence corresponds to an eventually periodic digit
itinerary, which for a nontrivial orbit is impossible (T-0003 of the
PR #3 branch; equally the coding theorem T-0002 here: periodic codes
are explicit rationals, never a nontrivial positive integer).

**Proof.** Write `V_k := N^{u_k} C_k`.

*Step 1 (telescoping).* (⋆′) gives exactly
`V_{k+1} = (N/M)^{u_{k+1}} (V_k + δ_k)`, `|δ_k| < M`.

*Step 2 (nontrivial ⟹ V → ∞).* For a nontrivial orbit,
`A_t = c(N/M)^t + O(1)` with `c > 0` (T-0003, real form). At the end
of phase `k` the orbit value is `d_k + N^{u_k} C_k = d_k + V_k`, so
`V_k → ∞`.

*Step 3 (affine growth of `u` is impossible).* By Step 1, the growth
factor of `V` over the period starting at `k = jm` is
`(N/M)^{U_j} (1 + o(1))` with `U_j = Σ_i (α_i j + β_i)` (the bounded
`δ`'s are absorbed since `V → ∞`). If some `α_i > 0` then `U_j → ∞`
and the per-period factor diverges; but `V` restricted to class `i`
equals `N^{α_i j + β_i} E_i(j)`, an exponential-polynomial in `j`,
whose consecutive-period ratio tends to its finite dominant ratio.
Contradiction. Hence **all `α_i = 0`**: `u_{jm+i} = β_i`, every
exponent bounded.

*Step 4 (bounded `u` ⟹ bounded state, by integrality/Fatou).* With
all `α_i = 0`, Step 1 telescopes to per-period factor
`λ = (N/M)^U`, `U = Σ_i β_i ≥ m ≥ 1`: if `V → ∞` it grows
geometrically with ratio exactly `λ`, so `λ` is the dominant ratio of
the exp-poly `N^{β_i} E_i(j)` — i.e. one of the ratios of `E_i`.
Now use `E_i(j) ∈ ℤ` for large `j`: an integer-valued sequence
satisfying a real linear recurrence has a rational generating
function with integer coefficients, which by Kronecker's criterion is
rational over `ℚ`, and by **Fatou's lemma** the reciprocals of its
poles — i.e. all ratios actually present in `E_i` — are algebraic
integers. But `λ = N^U/M^U` is in lowest terms (`gcd(M,N) = 1`) with
denominator `M^U > 1`: a rational non-integer, hence not an algebraic
integer. So `λ` is not available, `V` cannot grow — contradicting
Step 2 — unless the chain has bounded state. A bounded-state chain
takes finitely many values `(d, u, C)`, so it is eventually periodic;
its digit itinerary is eventually periodic; excluded for a nontrivial
orbit as above. **∎**

**Remark 1 (what survives).** Exactly as in T-0013, T-0003/T3, T4:
chains whose exponent schedule is *non-affine* — Sturmian/Ostrowski
schedules along CF(log_M N) — are untouched. The skeleton search
space is now provably S-adic or nothing.

**Remark 2 (strength).** No arithmetic hypothesis on the cofactor
ratios is needed: integrality of the `C_k` plus Fatou replaces any
smoothness assumption, so Pisot/substitution-type schemas with
algebraic ratios are killed by the same argument. (An earlier draft
assumed M,N-smooth ratios and closed the bounded-`u` case by composing
leading-coefficient identities around the cycle; that closing argument
was **wrong** — the composed identity is consistent, not
contradictory — and was replaced by the Fatou argument, which is both
correct and stronger. Recorded per the dead-end norm. External
imports: Fatou's lemma, Kronecker's rationality criterion — flagged
for P1.)

## 3. Lemma (periodic chains; L-0015)

A period-p skeleton pattern `(d_i, u_i)_{i<p}` composes (⋆) into an
affine map `C_0 ↦ αC_0 + β` with `α = (N/M)^{Σu} ≠ 1` (multiplicative
independence), so it has the **unique** rational fixed point
`C_0 = β/(1−α)`; a periodic chain exists iff that fixed point lifts to
integers satisfying the divisibility and digit constraints along the
cycle. `skeleton_rigidity.py` Part 2 enumerates all patterns with
`p ≤ 3, u ≤ 5` over all four chart alphabets — 636,350 patterns —
and finds **zero** integral chains of any sign. (Consistent with, and
stronger in range than, the theorem's bounded-state exclusion.)

## 4. Proposition (free bridges are exactly null; T-0021)

Let a chart have exit lattice `{Nq + t : q ∈ ℤ}` with `N` odd. For any
`j`, the map `q mod 2^j ↦ Nq + t mod 2^j` is a bijection, so by the
Terras coordinate bijection the free parity words of length `j` leaving
the lattice are **exactly uniform** over `{0,1}^j` — the
supercritical-word fraction from any chart exit equals the binomial
tail exactly, for every chart and every `j`. (Verified to the last
digit at `j = 16` for all four charts: fraction 0.10506 = null
0.10506.)

**Corollary (relay economics).** A relay cycle spending `n_i` blocks in
chart `i` (per-block designed cost `cost_i = L_i − log₂|D_i|` bits)
has per-step cost `(Σ n_i cost_i + bridge costs)/(Σ n_i L_i + …)` ≥
`min_i cost_i/L_i`, and by the Proposition bridge words contribute
*exactly generic* fuel — no free supercriticality from any exit
lattice. All four verified single-fiber rungs cost ≥ 0.81 bits/step,
against the pooled-atlas floor `1 − H(log₃2) = 0.05004` (T-0014).
**The chart groupoid adds reachability, never economy**; the offense
frontier is therefore fiber *width* (see `LADDER.md`), not chart
*transitions*.
