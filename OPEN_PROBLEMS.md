## Q-0001 — Finite-boundary regeneration

Status: `IDEA` / central target

Construct one ordinary finite positive state whose Collatz trajectory remains inside an exact expanding grammar forever.

Equivalent current formulations include:

1. a finite aperiodic vertical macro-grammar with one finite moving boundary;
2. finitely many positive run-length/cofactor schemas closed under
   \[
   d_k+N^{u_k}C_k=d_{k+1}+M^{u_{k+1}}C_{k+1};
   \]
3. a signed rational-base return chain
   \[
   Nq_t=Mq_{t+1}+a_t
   \]
   generated by negative templates;
4. an infinite but finitely generated renewal code or a finite multi-target return graph satisfying `T-0009`.

Finite experiments, adic points, large alphabets, arbitrary precision, complete modular projection, and narrow stationary windows are insufficient by themselves.

## Q-0010 — Growing complete dyadic projection

Status: `PROPOSED RESOLUTION` by `L-0009`, `L-0010`, `T-0007`

For every `b >= 1`, there is a mildly supercritical collision fiber with `2^b` branches whose offsets meet every residue modulo `2^b` exactly once.

The construction uses:

1. all low binary patterns embedded into fixed-weight prefixes;
2. one-hot suffixes that correct every prefix to a common inverse signature;
3. a finite CRT-selected odd tail that supplies supercritical drift without changing offsets.

## Q-0012 — Infinite regular negative-template renewal code

Status: `IDEA` / primary new route  
Dependencies: `T-0008`, `T-0009`

Fix a small negative target or negative cycle. Construct a regular infinite language of finite negative return templates such that:

1. every selected word returns to the designated target or next target;
2. the return cylinders define a deterministic selector on a nonempty ordinary positive quotient set;
3. the selected quotient set is forward invariant;
4. grouped macro-returns increase every quotient in the set;
5. one explicit finite quotient belongs to the set.

`T-0009` proves that a finite one-target all-supercritical code cannot cover every sufficiently large quotient: the all-even 2-adic boundary point forces a contracting branch. Viable mechanisms include:

- an infinite regular code whose only omitted 2-adic path is the zero shadow;
- a proper non-dense survivor set;
- several negative targets with graph transitions;
- compensated cycles containing both expanding and contracting local returns.

A successful construction would be a direct finite-grammar counterexample certificate.

## Q-0013 — Macroscopic aspect-ratio collision systems

Status: `IDEA` / primary chart-design target  
Dependencies: `T-0010`, `L-0011`, `O-0006`

For a chart define

\[
\Delta=
\frac{\operatorname{diam}D}{N-M}.
\]

Construct an infinite family, or a finite graph-directed cycle, for which the effective normalized displacement windows remain macroscopic while branching and expansion remain sufficient.

Promising directions:

1. near-critical pairs of powers `2^L` and `3^a` with collision fibers built before a long post-merger tail;
2. negative preimage trees of a small target or cycle, ranked by displacement diameter rather than cardinality;
3. multi-target cycles whose graph-directed windows overlap even when each stationary chart is narrow;
4. variable tails inserted between return decisions rather than after all branching has merged.

`L-0011` shows that a long common odd tail with expansion margin bounded away from zero compresses `Delta` exponentially. The objective is therefore to co-design branching, drift, and real-window width rather than optimizing them sequentially.
