## Q-0001 — Finite-boundary regeneration

Status: `IDEA` / central target

Construct one ordinary finite positive state whose Collatz trajectory remains inside an exact expanding grammar forever.

Equivalent current formulations include:

1. a finite aperiodic vertical macro-grammar with one finite moving boundary;
2. finitely many positive run-length/cofactor schemas closed under
   \[
   d_k+N^{u_k}C_k=d_{k+1}+M^{u_{k+1}}C_{k+1};
   \]
3. a signed rational-base return chain
   \[
   Nq_t=Mq_{t+1}+a_t
   \]
   generated by negative templates;
4. a graph-directed renewal language over finitely many negative phases;
5. a finite phase plus a cycle-padding stack, with one ordinary accepted boundary.

Finite experiments, adic points, large alphabets, arbitrary precision, complete modular projection, and complete renewal coverage are insufficient by themselves.

## Q-0012 — Infinite regular negative-template renewal code

Status: `IDEA` / principal route  
Dependencies: `T-0008`, `T-0009`, `T-0013`--`T-0016`

Construct a finitely generated language of negative return templates such that:

1. every accepted word gives an exact phase return;
2. the cylinders define a deterministic selector on a nonempty ordinary positive quotient set;
3. the set is forward invariant;
4. every realizable grammar cycle has positive net growth;
5. one explicit finite quotient belongs to the language.

The code need not cover every quotient. In fact `T-0016` shows that a positive-growth language inside a complete renewal system must be an entropy-thin, Haar-null exception.

Promising models:

- a regular subshift with small fair pressure and positive tilted pressure;
- a finite phase graph with cycle-padding counters;
- a pushdown renewal automaton;
- a multi-target system that compensates local contraction.

## Q-0013 — Macroscopic aspect-ratio systems

Status: `IDEA`  
Dependencies: `T-0010`, `L-0011`, `O-0006`, `O-0007`

For a chart define

\[
\Delta=\frac{\operatorname{diam}D}{N-M}.
\]

Construct an infinite family or graph-directed cycle whose effective normalized displacement windows remain macroscopic while expansion and symbolic branching remain sufficient.

A long common post-merger odd tail can collapse `Delta` exponentially. Expansion should instead be inserted along the return grammar or supplied by negative-cycle padding.

## Q-0014 — Finite phase plus cycle-padding stack closure

Status: `IDEA` / primary next construction target  
Dependencies: `T-0014`, `T-0015`, `O-0008`

The negative eleven-cycle yields finitely many mismatch phase types and one unbounded padding counter \(t\). Each type has an exact return tower with

\[
\lambda_t=\lambda_0(2187/2048)^t.
\]

Construct a finite substitution, pushdown rule, or affine counter update such that:

1. every accepted high-padding cylinder maps to another accepted cylinder;
2. padding remains above the edge-specific supercritical threshold;
3. descent to the negative fixed phase is avoided or compensated;
4. one ordinary finite quotient initializes the stack;
5. the grammar generates infinitely many deterministic Collatz blocks.

The key challenge is to make the output quotient's next exact valuation equal a controlled new padding level.

## Q-0016 — Multi-mismatch complement automaton

Status: `IDEA`  
Dependencies: `T-0014`, `T-0015`, `O-0008`

`O-0008` follows one mismatch only when the subsequent synchronized recovery congruence holds. If it fails, a second mismatch occurs.

Build the complete finite-state control automaton obtained by:

1. applying the complementary phase map at every mismatch;
2. following the negative phase while the difference remains even;
3. recording the next mismatch type and valuation;
4. grouping periodic cycle circuits into padding counters.

Determine whether this iterated mismatch automaton closes on finitely many negative basins and whether one accepted component has positive graph pressure and an ordinary finite survivor.
