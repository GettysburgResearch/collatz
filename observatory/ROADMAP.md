# Delivered investigation preview and the remaining roadmap

Version **0.3.0-preview.1**, not a claim that every original v0.2/v0.3 requirement is complete. The [original v0.1 roadmap](ROADMAP-v0.1.md) and [programme #118](https://github.com/GettysburgResearch/collatz/issues/118) remain the broader charter.

## This pass's principal acceptance test

A human or computer-using agent can choose a bit perturbation/neighbor, compare independently clocked trajectories, inspect **actual** arithmetic carries, identify an exact shared value with both arrival times, test a candidate motif on a bounded family that retains counterexamples and unfinished work, and save/recompute all of it in a fresh workspace. The exported meeting has a separate arithmetic replay checker. This end-to-end path takes precedence over completing a menu of symbolic rewriting tools.

## Next release: harden the paired research desk

**P0 — publication and ordinary-machine validation.** Land the reviewed patch on a feature branch, run the full repository validator, and obtain genuine served-browser/Windows receipts. Exercise normal module loading, response CSP, native file export/import, local shelf, cancellation and keyboard access. Do not promote the narrower DOM harness into a platform validation claim.

**P0 — structured observation work.** Add composable exact predicates and compare an observation across disjoint source constructions. A proposed statistical split must account for shared trajectory suffixes. Keep target horizons and future-event alignment explicit. Include the strongest counterexamples in exported observations, not only positive screenshots.

**P1 — deeper rank/merger coupling.** Attach the two-source arrival record to one specified rank comparison, add bounded least-witness searches and source-121 examples, and verify both paths independently. Explicitly distinguish a successful finite diagram from a complete lower-rank selector.

**P1 — broader symbolic mechanisms.** Add faithful published rewriting as its own versioned system with independent encoders and rule fixtures; add proper QCA boundaries/clocks separately. Carry inspection is not a substitute for these semantics, and these laboratories must not break the existing paired investigation.

**P1 — measured durability.** Use the benchmark scenarios to separate arithmetic, retained exact digits, serialization and drawing. Add process workers and checkpoints when justified, keeping partial-result semantics and a one-command local launcher. Persist recipes and computed artifacts as different object types.

Exit gate: another contributor performs the complete paired investigation with native browser interactions, replays every included recipe, checks an exported meeting independently, and reproduces a counterexample without knowing how the implementation was authored.

## Completing v0.3 research scope

Build explicit adapters around the pinned repository definitions rather than renaming generic plots. Add first-crossing displacement and prefix-constraint experiments; general ordinary-root families; physical rank-merging witnesses; actual unsafe-return population studies. Prepare at least three reproducible studies with negative controls and precise inherited source/review scope. Observations remain empirical until independently proved; an interesting visualization does not change theorem status.

## v0.4 — larger scale and separately secured sharing

Out-of-core artifacts, indexed exact traces, per-observable pyramids, asynchronous refinement, compressed grammar queries and restart-safe jobs. Each reduction declares what it preserves and loses. A coarse graph path must carry compatible witnesses before being treated as a lifted integer path.

A public bounded viewer of curated artifacts is separate from unrestricted compute. Authenticated shared workers require a production API, process/container isolation, durable queue, ownership, quotas, cost ceilings, cancellation and monitoring. Do not expose the preview loopback server.

## v1.0 — stable research infrastructure

Stabilize schemas and trusted plugin compatibility; independently validate certificates; publish repeatable benchmarks, accessibility/agent workflows and local packaging. Share reusable workspace/provenance components with Riemann Observatory without identifying different mathematics or delaying useful local tools for a universal framework.

Success means a reliable instrument repeatedly turning visual questions into exact, falsifiable and shareable investigations—not a promise to solve a conjecture on a release schedule.
