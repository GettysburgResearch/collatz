## Statement

Extend the shortcut map to all integers by

\[
T(n)=
\begin{cases}
n/2,&n\equiv0\pmod2,\\[1mm]
(3n+1)/2,&n\equiv1\pmod2.
\end{cases}
\]

For a positive phase magnitude \(v\), define the ordinary negative-phase map

\[
P(v)=
\begin{cases}
v/2,&v\equiv0\pmod2,\\[1mm]
(3v-1)/2,&v\equiv1\pmod2,
\end{cases}
\tag{1}
\]

so that \(T(-v)=-P(v)\). Define also the complementary phase map

\[
C(v)=
\begin{cases}
3v/2,&v\equiv0\pmod2,\\[1mm]
(v+1)/2,&v\equiv1\pmod2.
\end{cases}
\tag{2}
\]

Let \(q\in\mathbb Z\), \(v\ge1\), and write the physical Collatz state as

\[
n=q-v.
\tag{3}
\]

Put

\[
p=q\bmod2,
\qquad
r=v\bmod2,
\qquad
e=p\mathbin\oplus r.
\tag{4}
\]

Thus \(e=n\bmod2\). Define

\[
\boxed{
q'=\frac{3^e q+p}{2},
}
\tag{5}
\]

and

\[
\boxed{
v'=\frac{3^e v+(2p-1)r}{2}.
}
\tag{6}
\]

Then the following hold.

### 1. Exact synchronous coupling

Both quantities in (5)--(6) are integers and

\[
\boxed{
T(q-v)=q'-v'.
}
\tag{7}
\]

If \(q>v\), then \(q'>v'\); positivity of the physical state is preserved.

### 2. Shadow and mismatch branches

If \(q\) is even, the difference has the same parity as the negative phase and

\[
\boxed{
v'=P(v),
\qquad
q'=\frac{3^{v\bmod2}q}{2}.
}
\tag{8}
\]

Thus the phase follows its genuine negative Collatz orbit while the positive difference is scaled by the same linear branch.

If \(q\) is odd, the physical state has parity opposite to the negative phase and

\[
\boxed{
v'=C(v),
\qquad
q'=\frac{3^{1-(v\bmod2)}q+1}{2}.
}
\tag{9}
\]

An odd value of the difference is therefore exactly a **shadow mismatch**: the phase takes the complementary Collatz branch.

### 3. Exact valuation acceleration

Let \(q>0\), put

\[
k=\nu_2(q),
\qquad
q=2^k m,
\qquad m\text{ odd},
\tag{10}
\]

and define

\[
v_j=P^j(v),
\qquad
A_v(k)=\sum_{j=0}^{k-1}(v_j\bmod2).
\tag{11}
\]

Then the first \(k\) coupled steps remain synchronized with the negative phase:

\[
\boxed{
q_k=3^{A_v(k)}m,
\qquad
v_k=P^k(v).
}
\tag{12}
\]

The next step is the first mismatch, and the accelerated map is

\[
\boxed{
(q,v)
\longmapsto
\left(
\frac{3^{G_v(k)}m+1}{2},
C(P^k(v))
\right),
}
\tag{13}
\]

where

\[
G_v(k)=A_v(k)+1-(P^k(v)\bmod2).
\tag{14}
\]

Equation (13) is a countable but complete renewal partition indexed only by the ordinary valuation \(k=\nu_2(q)\).

## Proof

There are four parity cases.

- If \(p=r=0\), then \(e=0\), so \(q'=q/2\), \(v'=v/2\), and
  \[
  q'-v'=(q-v)/2=T(q-v).
  \]
- If \(p=0,r=1\), then \(e=1\), so
  \[
  q'=3q/2,
  \qquad
  v'=(3v-1)/2,
  \]
  and
  \[
  q'-v'=(3(q-v)+1)/2=T(q-v).
  \]
- If \(p=1,r=0\), then \(e=1\), so
  \[
  q'=(3q+1)/2,
  \qquad
  v'=3v/2,
  \]
  and the same odd-branch identity holds.
- If \(p=r=1\), then \(e=0\), so
  \[
  q'=(q+1)/2,
  \qquad
  v'=(v+1)/2,
  \]
  and
  \[
  q'-v'=(q-v)/2=T(q-v).
  \]

This proves (7), and (8)--(9) are the same four cases grouped by the parity of \(q\). If \(q>v\), then \(q-v>0\), so its shortcut image \(q'-v'\) is positive.

For (12), the first \(k\) values of \(q\) are even. Repeated use of (8) sends the phase through

\[
v,P(v),\ldots,P^k(v)
\]

and divides the factor \(2^k\) from \(q\), multiplying by three once for every odd phase. This gives (12). The resulting value of \(q_k\) is odd. Applying (9) at phase \(P^k(v)\) gives (13)--(14). ∎

## Interpretation

The variable \(q\) is the exact difference between a physical orbit and a moving ordinary negative reference orbit:

\[
q=n+v.
\]

Even values of the difference preserve parity alignment and let the reference follow its negative orbit. The first odd difference is a finite carry event that switches the reference to the complementary branch.

Thus the negative-template renewal language is not an externally imposed encoding. It is the natural accelerated dynamics of the difference between an ordinary orbit and a negative Collatz phase.

## Gap audit

- The two-dimensional system is exactly conjugate to the original physical trajectory under the projection \((q,v)\mapsto q-v\); it is not by itself a simplification proving divergence.
- The complementary phase map need not preserve a finite phase set.
- A negative cycle gives periodic control while \(q\) is even, but mismatches can leave that cycle.
- The complete valuation partition still needs a finite or finitely generated invariant grammar containing one ordinary positive initial state.
