## Statement

### Real Schottky system

A finite set \(\mathcal{S}=\{w_1,\ldots,w_k\}\) of chronological parity words
is a **real Schottky system** of gap \(\gamma>0\) on a closed interval
\(I=[A,B]\subset(0,\infty)\) if:

1. each inverse branch maps \(I\) into itself:
   \[
   g_{w_i}(I)\subseteq I\qquad(i=1,\ldots,k);
   \]
2. the images are pairwise disjoint and \(\gamma\)-separated:
   \[
   \mathrm{dist}\bigl(g_{w_i}(I),g_{w_j}(I)\bigr)\ge\gamma\qquad(i\neq j);
   \]
3. each branch is a uniform contraction on \(I\):
   \[
   \sup_{x\in I}|g_{w_i}'(x)|=\mu_{w_i}^{-1}\le\kappa<1.
   \]

Then the semigroup generated by \(\{g_{w_i}\}\) is free on \(k\) letters, and
the attractor

\[
\Lambda_{\mathcal{S}}(I)=\bigcap_{n\ge1}
\bigcup_{i_1,\ldots,i_n}
g_{w_{i_1}}\circ\cdots\circ g_{w_{i_n}}(I)
\]

is a nonempty compact Cantor set (for \(k\ge 2\)) of continuum cardinality.

### Integer port system

A finite set of **ports**

\[
P_j=\{\,M_j q+r_j:q\ge q_j\,\},\qquad j=1,\ldots,m,
\]

together with a finite set of labeled transitions

\[
\bigl(j\xrightarrow{w}j',\; q\mapsto \alpha q+\beta\bigr)
\]

is an **integer Schottky certificate** if:

1. each transition word \(w\) is a genuine shortcut parity word of length
   \(L=\mathrm{val}_2(M_j)\) (or a multiple compatible with the port modulus);
2. for every \(q\ge q_j\),
   \[
   n=M_j q+r_j
   \]
   follows \(w\) and
   \[
   T^{|w|}(n)=M_{j'}(\alpha q+\beta)+r_{j'}
   \]
   with \(\alpha q+\beta\ge q_{j'}\);
3. every transition expands a height function \(h(j,q)\) by a definite factor:
   \[
   h(j',\alpha q+\beta)\ge \lambda h(j,q),\qquad\lambda>1;
   \]
4. the directed graph of ports has a strongly connected component supporting
   at least two distinct infinite walks that are not eventually identical
   (so periodic digit lock-in is not forced at the certificate level).

An infinite walk in an integer Schottky certificate, started at a finite
admissible \((j_0,q_0)\), determines a positive integer \(n_0=M_{j_0}q_0+r_{j_0}\)
whose shortcut orbit visits the ports forever and satisfies
\(h\to\infty\), hence never reaches the trivial cycle.

## Definitions

### Height

The default height used in experiments is

\[
h(j,q)=\log(M_j q+r_j)=\log n,
\]

or the discrete proxy \(\lfloor\log_2 n\rfloor\).

### Free semigroup obstruction

A real Schottky system yields free inverse semigroups automatically by
ping-pong. An integer port system may still have relations; freeness is not
required for a counterexample — only infinite height growth from one finite
seed.

## Motivation

Carry-tile regeneration inside one fiber is blocked by moving-boundary /
fixed-geometry tension. Ping-pong relocates the difficulty: build a free
(or at least height-expanding) semigroup of affine blocks first, then demand
an integer point realizing an infinite word.

## Proof or construction

The real Cantor-set claim is standard iterated-function-system theory under
hypotheses (1)–(3). It is **not** a Collatz counterexample by itself.

The integer port implication “infinite expanding walk ⇒ divergent positive
orbit” is elementary once (1)–(4) are granted: the orbit is defined for all
forward block times, \(n\) stays positive, and \(h\to\infty\) prevents entry
into \(\{1\}\).

No nontrivial example with \(k\ge 2\) and an ordinary integer seed is provided
in this definition file.

## Gap audit

- Real Schottky systems routinely produce only transcendental/real points;
  integrality is a separate, currently open bridge.
- Integer port systems can accidentally encode eventually periodic digit
  itineraries; condition (4) weakens but does not eliminate that risk —
  any future `K-####` must prove aperiodicity or otherwise avoid `N-0004`-type
  obstructions.
- Height expansion on blocks does not automatically give expansion on every
  shortcut step; that is acceptable for divergence.
- Hidden assumption: ports cover the exact residue needed for each word.

## Adversarial tests

- Attempt to build a real Schottky system from supercritical inverse branches
  on a positive interval (`X-0102`).
- Attempt to build a 2-port integer certificate among short words (`X-0103`).
- Check whether any “certificate” secretly collapses to a single cyclic port
  sequence with bounded height.
